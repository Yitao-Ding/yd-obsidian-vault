# 今週のAI研究トップ10 (2026-W30)

## 今週の流れ
Claude Code の自動続行設計批判を筆頭に、エージェント「実運用」のインフラ・安全設計が主戦場に移行しつつある。企業側では MCP 経由のデータ漏洩を監視する Traceforce (YC S26) が登場し、AI セキュリティが産業課題として立ち上がり始めた。もう一方で、Agentty (C++26, 11MB) や Always-On Agent マシン構築ガイドなど、個人が自走エージェント環境を整えるプラクティスが急速に充実している。

## YDが今週試すべき1つ

**スペアMacを Always-On Agent マシンとして立ち上げる。** SSHパスワードレス認証 → LaunchAgent で tmux 自動起動 → Tailscale 接続まで通せば、スマートフォンからも Claude Code を遠隔操作できる状態になる。半日で morning_briefing のバックグラウンド処理をオフロードできる常時稼働環境が手に入る。着手順: `brew install tmux` → LaunchAgent plist 作成 → Tailscale インストール → SSH 接続確認。

## 既存プロジェクトとの接続

- **lecture_hub**: Claude for Teachers の実装思想（全50州の学習指標マッピング）は lecture_hub のカリキュラム設計に直接転用できる。OSS AI 論の「説明可能性」議論も、学習者への根拠提示機能に繋がる。
- **vidkit**: Always-On Agent マシンが実現すれば、vidkit の重い処理（書き起こし・カット生成）をスペアMacにオフロードできる。Agentty のサンドボックス実行モデルも、ファイル操作を伴うツール設計の参考になる。
