# 今週のAI研究トップ10 (2026-25)

## 今週の流れ
Claude Fable 5 / Mythos 5 のリリースを軸に、エージェントAIの実用化が一気に加速した週。OpenAI は Ona 買収でコード生成インフラの競争を激化させ、一方 AWS Bedrock の Anthropic データ共有必須化でプライバシー vs 性能のトレードオフが顕在化した。「エージェントが自律的に動ける」ことと「それを商用プロダクトに乗せられるか」の間に、今週から新しい壁が立ち始めた。

## 必読1本

**AWS Bedrock、Mythos/Fable 5利用にデータ共有を必須化**

Bedrock 経由で Anthropic の最新モデルを使う場合、30日間の利用データが Anthropic に送信される。安全調査・法的要件では削除が猶予される点が要注意。lecture_hub や task_hub のようにユーザーデータを扱うプロダクトでは、利用規約とプライバシーポリシーの見直しが即刻必要になる。「ローカルモデルで代替できる処理かどうか」の判断基準を今週中に整理しておくと後が楽になります。

## YDが今週試すべき1つ

**Claude Fable 5 の無料枠で、lecture_hub の「授業ノート → 要約 → 小テスト生成」をエージェント1本で完走させるプロトタイプを半日で作る。**

6月22日まで無料クレジット付き。数百万トークンのコンテキストを活かして複数授業分を一括処理する設計を試す。コストは実験規模なら数百円以内に収まるはず。うまくいけばそのまま lecture_hub のマルチエージェント設計の叩き台になる。

## 既存プロジェクトとの接続

- **lecture_hub**: Fable 5 の長文コンテキスト対応が複数授業の一括処理に直結。同時に AWS Bedrock のデータ共有ポリシー変更により、ユーザーデータの取り扱いを利用規約に明記する対応が必要になった。
- **task_hub**: Paca の「人間とAIエージェントを等価なチームメンバーとして扱う」設計思想は Salamat Task Hub の次フェーズ設計の参考になる。Bedrock のデータポリシー変更も影響範囲に含まれるため確認を。
