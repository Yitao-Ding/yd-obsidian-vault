# 今週のAI研究トップ10 (2026-24)

## 今週の流れ

エージェントの「記憶・継続学習・本番稼働」の三層が一気に論文化された週。静的ベンチマークの限界を突く実運用評価フレームワーク（RAMP・AutoLab）が相次ぎ登場し、「動くけど本番で壊れる」AIへの警戒感が高まっている。一方でPerplexityの Search-as-Code、NVIDIAのCosmos 3、JetBrainsのMellum2と、即実用できるアーキテクチャ発表も続き、研究と実装の距離が縮んでいる。

---

## 必読 1 本

**Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads**
[arxiv](http://arxiv.org/abs/2606.06448v1)

long-horizon agentを「動かす」だけでなく「スケールさせる」ための記憶システムを初めて体系的に測定した研究。Flat retrieval / LLM-mediated extraction / fact store consolidation など設計パターンを分類し、write/readコストの実測値と10個のシステム推奨を提示している。lecture_hub・task_hub の記憶設計を見直す直接的な根拠になる。architecture を選ぶ前にこれを読まないと後悔する。

## トップ10

1. **Agent Memory: Characterization and System Implications** — long-horizon agentの記憶システムを初めて実測・体系化、設計パターンのtaxonomyと10推奨を提示 (arxiv, 10.0) [リンク](http://arxiv.org/abs/2606.06448v1)

2. **Rethinking Continual Experience Internalization for Self-Evolving LLM Agents** — 継続学習で起きる「能力の段階的崩壊」を発見し、原則的経験を段階的注入する安定進化設計を提案 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2606.04703)

3. **RAMP: Runtime Assessing of Agentic Models in Production Systems** — 従来の孤立benchmarkでは見えないタスク完了率の段階劣化（初期100%→最終20%）を本番環境で定量化 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.27492)

4. **AutoLab: Can Frontier Models Solve Long-Horizon Auto Research and Engineering Tasks?** — 36の実タスクで「粘り強く繰り返し改善する」能力を測定、Claude Opus 4.6が最高評価 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2606.05080)

5. **Cosmos 3: Omnimodal World Models for Physical AI** — NVIDIA製、言語・画像・動画・音声・アクションを単一モデルで処理するworld modelをOSS公開 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2606.02800)

6. **Mellum2 Technical Report** — 2.5B活性パラメータのMoEでコード生成特化、128Kコンテキスト・Apache2.0でローカル実行可能 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.31268)

7. **Rethinking Search as Code Generation** — 検索パイプライン自体をAIがコード生成で制御、WANDRベンチマークで次点の2.5倍・トークン85%削減 (hn, 4.5) [リンク](https://research.perplexity.ai/articles/rethinking-search-as-code-generation)

8. **Token Budgets: 63 LLM-Agent Budget-Overrun Incidents** — 21フレームワーク63件の予算超過をRustのaffine型でコンパイル時静的防止、実験でゼロオーバーシュート達成 (hf_papers, 4.5) [リンク](https://huggingface.co/papers/2606.04056)

9. **AffordanceVLA: A Vision-Language-Action Model** — 物体認識→2D位置→3D幾何学推論の3段階でロボット操作の構造的隔たりを解消 (hf_papers, 4.5) [リンク](https://huggingface.co/papers/2606.06155)

10. **Linear Ensembles Wash Away Watermarks** — 3〜5モデルの出力平均でAI透かしが除去できることを理論・実験で証明、z-scoreが300→2以下に (hf_papers, 4.5) [リンク](https://huggingface.co/papers/2605.30501)

## YDが今週試すべき1つ

**Search-as-Code パターンを lecture_hub の検索層に部分実装する**

Perplexity の論文が示す「固定パイプラインを捨て、モデルが動的にクエリを生成・調整する」設計を lecture_hub のドキュメント検索に適用する。具体的には、現在の固定RAGクエリを「1回の推論セッション内で複数クエリを生成→取得→絞り込みをコードとして実行する」フローに置き換える試作を作る。Pythonで100〜200行、半日で動作確認まで到達できる。精度改善とトークン削減が同時に見込める。

## 既存プロジェクトとの接続

- **vidkit**: Cosmos 3 が Text-to-Image / Image-to-Video でOSS最高評価を達成、vidkit の映像生成パイプラインのバックエンド候補として評価する価値がある
- **lecture_hub**: Agent Memory の設計taxonomy がlecture_hubの会話履歴・知識蓄積アーキテクチャ見直しに直接適用できる。Mellum2（Apache2.0・ローカル実行）は lecture_hub のオンデバイス補助モデル候補
- **project_agent_application**: RAMPとAutoLabが示す「本番でのタスク完了率の段階劣化」はproject agent applicationのQA設計に即適用すべき知見。Token Budgets論文も並走エージェント設計のリファレンスとして参照推奨
