# 今週のAI研究トップ10 (2026-W23)

## 今週の流れ

ベンチマークの再定義が加速した週だった。FastKernels・DeepSWE・VitaBench 2.0 はいずれも「既存の評価が実運用とずれている」という問題意識から設計されており、評価の信頼性がAI開発の次の律速になりつつある。
エージェントの自己改善も本格化し、SkillOpt はスキルドキュメントをパラメータとして扱って人手なしに+20ポイント超の性能向上を実証、Trajel はマルチエージェントの中間ステップ幻覚を最終出力より先に検出する枠組みを示した。
基盤モデル側では Gemini Embedding 2・StepAudio 2.5・MobileMoE が「統合・マルチモーダル・オンデバイス」の三方向に拡張し、インフラ層の厚みが一段増した。

## 必読 1 本

**SkillOpt: Executive Strategy for Self-Evolving Agent Skills**

`.claude/` にスキルファイルを置いて運用しているなら直接刺さる。スキルドキュメントを「凍結したプロンプト」ではなく「テキスト空間の最適化可能なパラメータ」として扱い、スコア付きロールアウトから有界な追加・削除・置換編集を生成→検証→採用するループを回す設計。Claude Code 環境で平均+19.1ポイント、GPT-4.5 では+23.5ポイントという数字は実用域に入っている。「CLAUDE.md を育てる」という今の手動サイクルを、次のフェーズに引き上げる直接的なロードマップがここにある。推論時に追加モデル呼び出しゼロで運用できる点も実装コストが低い。

[論文リンク](http://arxiv.org/abs/2605.23904v1)

2. **Gemini Embedding 2: A Native Multimodal Embedding Model from Gemini** — ビデオ・オーディオ・画像・テキストを単一表現空間に統合、MSCOCO 62.9 R@1・MTEB Code 84.0でマルチモーダルRAGを実用域に引き上げ (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.27295)
3. **VitaBench 2.0: Evaluating Personalized and Proactive Agents in Long-Term User Interactions** — 長期ユーザーインタラクションでのパーソナライズ評価、SOTAモデルでも実世界ニーズとの大きなギャップを実証 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.27141)
4. **Claude Code as a Daily Driver: Claude.md, Skills, Subagents, Plugins, and MCPs** — 「短いCLAUDE.md + 繰り返しミスをSkillsに落とすサイクル」が核心の実装ガイド、MCPは厳選統合を推奨 (hn, 10.0) [リンク](https://arps18.github.io/posts/claude-code-mastery/)
5. **MobileMoE: Scaling On-Device Mixture of Experts** — 0.3〜0.9Bパラメータでモバイル上のMoE推論を実現、dense比prefill 1.8〜3.8倍・decode 2.2〜3.4倍高速 (arxiv, 10.0) [リンク](http://arxiv.org/abs/2605.27358v1)
6. **Beyond Final Answers: Auditing Trajectory-Level Hallucinations in Multi-Agent Industrial Workflows** — マルチエージェント中間ステップの幻覚を5分類で検出するTrajel、最終出力チェックより段階的検証が有効と実証 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.24219)
7. **SkillOpt: Executive Strategy for Self-Evolving Agent Skills** — スキルドキュメントをテキスト空間で自動最適化、Claude Code環境で+19.1ポイント向上・推論時ゼロ追加コスト (arxiv, 10.0) [リンク](http://arxiv.org/abs/2605.23904v1)
8. **StepAudio 2.5 Technical Report** — ASR・TTS・リアルタイム音声対話を単一基盤モデルに統合、3タスク全でSOTA達成 (hf_papers, 10.0) [リンク](https://huggingface.co/papers/2605.23463)
9. **DeepSWE: A contamination-free benchmark for long-horizon coding agents** — 113タスク・91リポジトリで汚染ゼロのコーディングエージェント評価、GPT-5.5が70%・Claude Opus 4.7が54%でモデル差を明確に分別 (hn, 9.0) [リンク](https://deepswe.datacurve.ai/blog)
10. **Soap2Soap: Long Cinematic Video Remaking via Multi-Agent Collaboration** — マルチエージェント検証で数百ショット全体のキャラクター同一性を保ちながら映像スタイル変換、商用API比で長期一貫性が大幅上回る (hf_papers, 7.5) [リンク](https://huggingface.co/papers/2605.17423)

## YDが今週試すべき1つ

**Gemini Embedding 2 API で lecture_hub のクロスモーダル検索プロトタイプを組む**

lecture_hub に取り込んだ講義スライドPDFや動画に対して、テキストクエリで意味検索するパイプラインを半日で試せる。Gemini Embedding 2 はビデオ・画像・テキストを同一空間に埋め込むため、「"確率的勾配降下法" というテキストクエリ → 関連スライド画像・動画クリップが返る」という統合検索が一つのAPI呼び出しで動く。Google AI Studio で API キーが即取得でき、既存の faiss インデックスと並べて精度比較するところまで半日以内に着手できる。既存の単一モダリティ埋め込みをそのまま置き換えるか、サイドバイサイドで試すかはスケール次第。

## 既存プロジェクトとの接続

- **vidkit**: Gemini Embedding 2 でビデオクリップの意味埋め込みを生成し、類似シーン検索・コンテンツタグ付けに応用できる。Soap2Soap の格子ベースキーフレーム一貫性生成は、長尺動画編集パイプラインで参照する価値がある。
- **lecture_hub**: Gemini Embedding 2 がマルチモーダルRAGのコア埋め込み基盤の有力候補。VitaBench 2.0 のパーソナライズ評価設計から、学習履歴に基づく動的コンテンツ推薦の実装パターンが参考になる。
