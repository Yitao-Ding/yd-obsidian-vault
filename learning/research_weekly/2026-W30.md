**「The new rules of context engineering for Claude 5 generation models」**

## YDが今週試すべき1つ

lecture_hub の既存システムプロンプトを「Context Engineering」記事の3原則（段階的開示・ツール説明への責務統合・リッチリファレンス化）に沿って半分以下に削減し、応答品質が維持されるか比較テストを走らせる。Claude Opus 5 の API を使えばコスト変動なしで試せる。設定変更→テスト実行→結果記録まで半日以内で完結する規模感。

## 既存プロジェクトとの接続

- **vidkit**: Flux 3 X Mimic の「映像×動作統一学習」アーキテクチャは、vidkit の映像理解・カット判定ロジックの精度向上ヒントになる。また Claude Opus 5 のコーディング精度向上により、vidkit の実装スピードが上がる可能性が高い。
- **lecture_hub**: Context Engineering の新標準が直撃する。現行プロンプト設計の見直しと、Claude Cookbook の RAG・ツール統合パターンの取り込みが優先課題。Claude Opus 5 の視覚化品質向上も lecture コンテンツ生成に効く。
