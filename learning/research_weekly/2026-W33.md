## YDが今週試すべき1つ

Claude Code を Auto Mode に更新して、lecture_hub か morning_briefing の既存バッチスクリプトを一本、許可プロンプトなしで頭から末尾まで通す。具体的には `claude --auto` で流して、どのステップが自動通過しどのステップでブロックが発動するかを記録する。30分以内に挙動の全体像が把握でき、今後の自動化設計の前提条件が固まる。

## 既存プロジェクトとの接続

- lecture_hub: Auto Mode のデフォルト化で長時間バッチを夜間ノータッチ実行できるようになる。Ante も MCP 対応のためローカル代替エージェントとして検証価値がある。
- vidkit: GPT-5.6 Sol の14倍速はリアルタイム動画処理パイプラインのボトルネック診断に使える可能性がある。Ante のヘッドレスモードをスクリプト連携に組み込む検討も半日で着手できる範囲。
- morning_briefing: Auto Mode でバッチ実行の中断を減らせる。マルチエージェント失敗パターン論文の Conformity failures は、並列サマリー生成で同一出力が量産されるリスクとして直接該当する。
