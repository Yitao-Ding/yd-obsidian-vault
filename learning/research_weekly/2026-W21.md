## 今週の流れ

Anthropic が SpaceX との GPU 提携で計算容量を急拡大し、Claude Code のレート制限が全プランで2倍になった。エージェント実装の主戦場は「長時間・複雑タスクの信頼性」に移りつつあり、deer-flow や RAGFlow など実用寄りのハーネスが牽引役になっている。一方、Constraint Decay 論文が指摘する「制約の忘却問題」は、エージェントを本番投入する際の根本的なリスクとして今週最大の警告材料になった。

## 必読 1 本

**Constraint Decay: The Fragility of LLM Agents in Back End Code Generation**
(arxiv, score 10.0)

LLM エージェントは生成が進むにつれて最初に与えた制約を忘れる——というシンプルかつ深刻な事実を実証した論文。「動いた」ではなく「正しく動き続けた」を保証するには、制約を繰り返し注入するか、チェックポイントで検証する構造が必要になる。自分でエージェントを組んでいる場合は設計の前提が変わる可能性がある。deer-flow や task_hub の長時間タスク設計にそのまま刺さる内容。

## YD が今週試すべき1つ

**RAGFlow を lecture_hub のドキュメント検索レイヤーに差し込んでみる。**

`docker compose up` で立ち上がるため半日以内に動作確認まで届く。現状の lecture_hub が持つ講義資料の検索を RAGFlow に移管し、エージェント呼び出しとの接続を確認する。スコープは「1つの講義PDFを取り込んで質問に答えさせる」だけで十分。deer-flow や Constraint Decay の知見と合わせると、検索→要約→制約付き回答という一連のパイプラインの評価軸が見えてくる。

---

## 既存プロジェクトとの接続

- **lecture_hub**: RAGFlow がそのまま検索レイヤーの代替候補。ERA の自動コード生成フローは講義内容の演習自動生成にも転用できる。Constraint Decay の知見から、長い要約タスクには中間チェックポイントを挟む設計が推奨される。
- **morning_briefing (task_hub)**: deer-flow のサブエージェント＋メッセージゲートウェイ構成が、現在の朝ブリーフィング生成パイプラインの参照アーキテクチャになる。LangChain の統合レイヤーを使えば Anthropic API との接続コストを下げられる。Claude Code のレート制限2倍は、長時間バッチ処理の実験コストを実質半減させるので、今週がタイミングとして良い。
- **ai_learning_sprint**: anthropics/skills リポジトリが SKILL.md 形式の実装例を大量に提供しており、Anthropic Academy の内容を手を動かして確認する素材として直接使える。LlamaFactory はローカルファインチューニングの実験環境として有力。
