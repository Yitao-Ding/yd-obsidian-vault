## 🎯 YD への推奨ポイント

### 廃人化中の Claude Code ユーザー視点

- **Day 3, 7 が一番リターン高い**: 既に毎日使っている Skills / Subagents / Claude Code を「体系化」できる
- **Day 4-6 (API + MCP) は Lecture Hub / Task Hub の AI機能強化に直結**: 受講後すぐ実装に活かせる
- **Day 8-9 (Cloud) は急ぐ必要なし**: 個人用途では Anthropic 直叩きで十分。Google AI Professional 資格に向けた助走として Day 9 だけ重要
- **Day 10-12 (各業界向け Fluency) は「証明書消化」目的**: Salamat (NPO) / Arte Grow (SMB) への転用視点で読めば学びはある

### 各コースの「YDへの引き寄せ角度」を学習ログに必ず書く

各コース個別ファイルの「📌 YDへの引き寄せ」セクションに、自分の現場 (Salamat / vidkit / Lecture Hub / Task Hub / 平成たち祭 / Arte Grow) との接続を1-3行でメモ。
これが Vault の知識化 = 「ただ受講した」ではなく「自分のプロジェクトに転用できる」ナレッジになる。
