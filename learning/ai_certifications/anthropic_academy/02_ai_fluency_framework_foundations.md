# 02. AI Fluency: Framework & Foundations (AIフルエンシー：枠組と基礎)

## コース情報

- **公式URL**: https://anthropic.skilljar.com
- **カテゴリ**: AI Fluency
- **難易度**: Beginner
- **所要時間**: 受講後に記録
- **修了証明書**: あり
- **概要**: AIシステムと「効果的・効率的・倫理的・安全に」協働するためのフレームワーク。

## 📌 YDへの引き寄せ

- Anthropic公式の「AI協働フレームワーク」を体系で押さえれば、教科書システム (textbook/) の「03_ai_engineering」コンテンツの土台になる
- 「倫理的・安全に」の章は Salamat の写真・個人情報を AI で扱う際の判断基準として使える

## 🎯 学習目標

- AI Fluency の 4D Framework (Delegation / Description / Discernment / Diligence) を自分の言葉で説明できる
- 自分の作業フロー (Claude Code 4並列) を 4D Framework で再評価できる
- 後輩メンバーに AI 協働ルールを伝える資料の原型を作れる
