# Show HN: Ante, a coding agent in a single binary that runs offline

> https://github.com/AntigmaLabs/ante

## 要約 (日本語5行)

Ante は Rust 製の単一バイナリ型コーディング AI エージェントで、ローカルオフライン実行に対応しています。Claude Code や Copilot と異なり、外部依存ゼロで ~15MB の実行ファイルのみで動作します。Terminal-Bench 2.1 では DeepSeek V4 Flash を用いて 82.7% の成功率を達成し、Claude Code 比で 7 倍のメモリ効率を実現しています。12+ の LLM プロバイダ（Anthropic、OpenAI、Gemini、Local GGUF）に対応し、TUI モード、ヘッドレス実行、サーバモード、Slack/Discord ボット化が可能です。MCP 対応、マルチエージェントオーケストレーション、カスタムスキルの拡張機能を備えています。
