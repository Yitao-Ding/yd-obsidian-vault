# Claude's AskUserQuestion: "No response after 60s – continued without an answer"

> https://github.com/anthropics/claude-code/issues/73125

## 要約 (日本語5行)

Claude CodeのAskUserQuestion ツールが60秒のタイムアウト後にユーザー入力を待たずに自動実行される問題です。
ユーザーの明示的な安全確認機構が意図に反して無効化されており、バージョン 2.1.198 で発生する回帰現象です。
タイムアウトパラメータがスキーマに存在しないため、この動作は仕様不明のまま自動応答を迫られます。
safety-critical なワークフローではユーザー確認が絶対必要ですが、自動継続は信頼性を損なわせます。
エージェント化する Claude Code において、人間の統制とAIの自律性のバランスが重要な課題となります。
