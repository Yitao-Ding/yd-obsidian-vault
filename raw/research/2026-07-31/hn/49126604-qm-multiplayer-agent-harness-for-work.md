# qm – Multiplayer agent harness for work

> https://github.com/yc-software/qm

## 要約 (日本語5行)

qmは、Yコンビネータ系スタートアップ向けのマルチプレイヤーエージェントハーネスです。個別ワークスペース分離により、全従業員が独立した環境でエージェントを使用しながら、共用チャネルとプロジェクトで協調作業できます。TypeScript/Node + Postgresバックエンド、Slack・Web UI、複数モデル対応（ベンダーロックイン回避）で実装されています。組織のアクセス制御に準拠した監査可能な設計で、スケーラブルなチーム運用を実現します。Salamat規模のサークル管理やArte Growの現地チーム自動化に適用する場合、スケーラビリティパターンの参考モデルとなります。

## 既存プロジェクトとの関連
- **salamat_wbs** — Salamat 公式サイト (Next.js 16 + Tailwind v4 + three + cobe + shaders)
- **task_hub** — サークル向けタスク管理 (Next.js + Firebase)
- **arte_grow** — Type B 社会起業 (現地ブランディング、Pride Not Dependency)
