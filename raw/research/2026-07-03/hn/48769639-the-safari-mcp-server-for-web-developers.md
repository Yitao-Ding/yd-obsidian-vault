# The Safari MCP server for web developers

> https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/

## 要約 (日本語5行)

WebKit チームが Safari MCP サーバーを発表しました。これは AI エージェントが Safari ブラウザに接続して、ウェブ開発・デバッグを自動化できるツールです。DOM・ネットワーク・スクリーンショット・コンソール出力にアクセスでき、互換性テスト・パフォーマンス分析・アクセシビリティ検査に利用できます。Safari Technology Preview 247 以降で利用可能で、MCP 互換のどのクライアントからも接続可能です。エージェントベースの開発フローを Safari 環境へ統合する重要な基盤です。
