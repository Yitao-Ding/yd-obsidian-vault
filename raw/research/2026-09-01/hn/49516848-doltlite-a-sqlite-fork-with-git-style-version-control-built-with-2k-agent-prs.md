# DoltLite: A SQLite fork with Git-style version control, built with 2k agent PRs

> https://www.dolthub.com/blog/2026-08-31-doltlite-beta/

## 要約 (日本語5行)

DoltLiteはSQLiteをベースに、Prolly Treeに置換されたB-tree層により、Git風のバージョンコントロール機能を完全統合したデータベースです。\nブランチ・マージ・リベース・チェリーピック・リセットといった完全なVCS機能をローカルおよびDoltHubリモートで提供し、従来のSQLiteにはない柔軟性をもたらします。\n2000個のエージェントPRsによる自動開発プロセスで実装され、ストレージフォーマット安定性、SQL互換性、完全なVCS機能、本番性能に関する4つの約束を掲げたBeta版として公開されています。\nsqllogictest 580万クエリで100%、TCL試験で99.46%合格し、SQL互換性が高いレベルで実証されました。\n書き込み性能は60%程度の遅延がありますが、バッチ処理時は10%程度に改善され、本番環境での実用化が視野に入っています。
