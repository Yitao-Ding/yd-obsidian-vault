# Keenable SELECT: an agent that searches the web in SQL

> https://keenableai.github.io/select-showcase/

## 要約 (日本語5行)

WebをSQLで問い合わせできるエージェント、言語モデルがSQLクエリを書きMCPサーバーが1000ページ超を効率的に検索・フィルタ・抽出します。
従来のWeb検索は全ページをLLMで処理するため高コスト、SELECTはWHERE句の絞り込みとSEM_EXTRACTで抽出を分離してトークン消費を大幅削減します。
ResearchエージェントがSQL生成してMCPサーバーで実行し、ReportエージェントがPython処理してHTML出力する2段階体制です。
MCPサーバーのセマンティックSQL演算子（WEB_SEARCH/WEB_FETCH/SEM_EXTRACT/SEM_MATCH/SEM_NORM）がデータ取得の効率化を担当します。
agentic AI + MCP重視のYDスタックに合致＝morning_briefing や lecture_hub 拡張の参考パターンとなります。
