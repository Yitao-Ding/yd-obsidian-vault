# DeepSWE: A contamination-free benchmark for long-horizon coding agents

> https://deepswe.datacurve.ai/blog

## 要約 (日本語5行)

DeepSWEはSWE-Benchの後継ベンチマークで、113タスク・91リポジトリで長期水平的なコーディングエージェント評価を行います。タスクは平均668行を追加・7ファイル修正が必要で、既存commit非依存のオリジナル問題により汚染リスクをゼロにしました。検証器は振る舞いベースで偽陽性0.3%・偽陰性1.1%の高精度を達成し、モデル間の性能差（70%スプレッド）も明確に分別できます。TypeScript/Go/Python/JavaScript/Rust 5言語対応で、frontier モデル（GPT-5.5: 70%、Claude Opus 4.7: 54%）の客観的ランキングが可能です。
