# Bend – A language that blocks AI mistakes via proof and runs on GPUs

> https://bend-lang.com/

## 要約 (日本語5行)

Bend はプルーフシステムを統合した言語で、AI エージェントが生成したコードの正確性を数学的に保証します。C 並みの速度とデフォルトの CUDA 並列化により、単一バイナリが CPU と GPU 両対応です。LAWS.bend ファイルで不変条件を宣言すると、AI が書いたコードはその条件に対する形式的な証明を自動で要求され、定理的に要件を破ることが不可能になります。自動型チェック (最大1秒) と GPU ランタイムにより、手動カーネル記述なしにスケーラブルなコード実行が可能です。AI エージェントとの協働開発やバグなしコード生成に革新的なアプローチを提供し、next-gen AI assistant 文化の定着期に極めてタイムリーです。
