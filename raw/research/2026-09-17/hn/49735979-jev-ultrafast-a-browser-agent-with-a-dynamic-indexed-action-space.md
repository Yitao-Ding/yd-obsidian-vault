# Jev Ultrafast: A browser agent with a dynamic, indexed action space

> https://github.com/browser-use/jev-ultrafast

## 要約 (日本語5行)

TypeSafe の Jev エージェントを使った動的アクションスペース型ブラウザ自動操作フレームワークです。操作と対象要素を 1 リクエストで LLM が選択し、テキスト入力は必要な時だけ小さな LLM が生成します。Google Flights での Zürich → London 検索が 7.1 秒で完了する実績があります。サイト固有のロジックやハードコード値を一切排除し、自然言語ゴール 1 つで異なるウェブタスクに対応できます。ブラウザの状態管理、待機最適化、DOM 検証に工夫があり、エージェント型オートメーションの実装パターンとして参考になります。
