# Universal Memory Protocol – a shared format for agent memory

> https://universalmemoryprotocol.io/

## 要約 (日本語5行)

Universal Memory Protocol は、異なるエージェント・プラットフォーム・ストレージ間でメモリを可搬性のあるフォーマットで標準化するアプリケーション層の仕様です。タイプ付き JSON・W3C PROV・DID 標準採用で、改ざん防止と署名検証を内蔵しており、ベンダーロックイン回避を実現します。MCP サーバー・TypeScript SDK・HTTP 経由で段階的に導入でき、既存メモリシステム (note app・vector db・JSON ファイル) との相互運用を目指しています。個別エージェントが独立にメモリを管理するのではなく、ポータブルなメモリレイヤーを共有することで、セッション・エージェント・ベンダー横断のナレッジ継続を実現します。
