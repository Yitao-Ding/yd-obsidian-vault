## 要約 (日本語5行)

iOS 27 と macOS Golden Gate のコード内から、Siri が Claude や ChatGPT に置き換え可能である証拠が発見されました。Model Delegation Protocol と Inference Provider in Model Manager Services という 2 つのプロトコルが、LLM バックエンド切り替えを実現しています。現在のリリース版では macOS Golden Gate で ChatGPT のみが "Ask..." メニューを通じて利用可能です。Claude のコード実装は存在していますが、エンドユーザーにはまだ公開されていません。EU の Digital Markets Act が Apple に第三者への API アクセスを要求したことが、このモジュール設計の背景にあります。
