# Message your other Claude Code sessions

> https://code.claude.com/docs/en/cross-session-messaging

## 要約 (日本語5行)

Claude Codeの複数セッション間で非同期メッセージを送受信できる機能を説明しています。同じマシン上のセッション間ではローカルソケットで、異なるマシン間ではAnthropicサーバー経由で配信されます。メッセージは送信方が許可チェック後に自動で最適なタイミングで配信され、受信方は設定に基づいて承認・保留・拒否できます。セッション間での情報共有を効率化し、複数プロジェクトの並列作業中の調整コストを削減できます。
