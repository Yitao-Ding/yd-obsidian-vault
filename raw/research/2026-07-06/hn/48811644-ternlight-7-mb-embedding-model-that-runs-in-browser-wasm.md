# Ternlight – 7 MB embedding model that runs in browser (WASM)

> https://ternlight-demo.vercel.app/

## 要約 (日本語5行)

Ternlight は 7MB の埋め込みモデルを WebAssembly で実行し、ブラウザの IndexedDB やローカルメモリ内のテキストに対して意味的検索を可能にします。サーバー通信不要で低遅延、プライバシー配慮された semantic search が実現でき、lecture-hub / morning-briefing / Project Agent App のクライアント側 RAG 強化に活用できます。オフライン環境でも関連ドキュメント検索が動作する、YD のオンデバイス志向に適合した技術です。
