# Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

> https://arxiv.org/abs/2609.09153

## 要約 (日本語5行)

LLMエージェントが長い行動軌跡で目標を見失う問題に対し、手続き知識をグラフ構造で組織化するフレームワークです。グラフは失敗と成功の軌跡を対比させながら自動改善し、トポロジーと属性を動的に編集します。ガイダンスモデルが生成されたサブグラフからエージェント行動を示唆し、強制せず自由度を保ちます。メモリベースラインを上回る性能を示し、自己進化によって手動エンジニアリングを不要にします。最小限のスケルトングラフから開始して、手設計された代替案相当まで自動収束させることを実証しました。
