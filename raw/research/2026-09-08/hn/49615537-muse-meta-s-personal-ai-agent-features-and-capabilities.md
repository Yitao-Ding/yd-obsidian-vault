# Muse: Meta's personal AI agent, features and capabilities

> https://ai.meta.com/muse/

## 要約 (日本語5行)

Meta の Muse はアクション可能なパーソナル AI エージェントで、Secure VM 上で web ブラウジング・予約・フォーム入力を自動化します。WhatsApp や専用アプリで会話型で指示でき、メール送信や購入は承認後のみ実行される仕様です。ログインは Secure Credential Store で暗号化管理、購入時は一時的なカード番号生成で実カード非公開、Meta 広告との data 共有なしという堅牢な privacy 設計です。目標追跡と進捗管理を自動で行い、Email・Calendar・Instagram 等と連携可能、必要ならツールも自動生成します。Android・iOS 両対応で即試用可能です。
