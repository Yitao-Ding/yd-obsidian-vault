# The VMs Powering Mobile Agents (Instinct, Claude Code)

> https://rohanadwankar.github.io/posts/platforms.html

## 要約 (日本語5行)

Claude Code と Instinct の2つのモバイルエージェントプラットフォームのVM実行環境を比較した記事です。両者ともFirecracker軽量microVMを基盤としていますが、アーキテクチャが大きく異なります。Claude Codeはカスタムinit (process_api) と324MB Bun harness でローカル実行、推論はリモートSSE/HTTPS2で行います。Instinct はフル Ubuntu + systemd のサンドボックスで、永続状態（Markdown vault + browser profiles）をすべてS3で管理し、認証情報をサーバー側に保管します。エージェント実行環境の「ステートフル vs ステートレス」設計アプローチの違いが浮き彫りになる比較です。
