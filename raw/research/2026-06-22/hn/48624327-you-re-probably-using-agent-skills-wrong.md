# You're probably using Agent Skills wrong

> https://notes.ansonbiggs.com/youre-probably-using-agent-skills-wrong/

## 要約 (日本語5行)

Agent Skills は「困った問題を解く手段」ではなく「既に解いた知見」を記録するものです。アンチパターンは、エージェントが苦手な問題に対して即座にスキルを作らせること（思考ブロックより悪い）。正しい用途は3つ：プロジェクト固有の知識（テスト実行方法など）、頻繁な繰り返しワークフロー、やっと解けた難問の手続き化です。Skills はスキップできない本物の学習ギャップを埋めるべきで、考える代わりになってはいけません。
