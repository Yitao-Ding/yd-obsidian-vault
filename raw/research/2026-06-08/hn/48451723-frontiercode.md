# FrontierCode

> https://cognition.ai/blog/frontier-code

## 要約 (日本語5行)

FrontierCode は Cognition が開発したコーディングベンチマークで、AI モデルが本番レベルのコード品質を達成できるかを評価します。従来のベンチマークとは異なり、動作の正確性だけでなく、回帰安全性、テスト品質、スコープ規律、コード品質の6次元を総合評価することで実運用のマージ可能性を判定します。20人以上のオープンソース保守者が各タスクに40時間以上投資して定義した基準により、SWE-Bench Pro 比で誤検出率を81%削減し、より正確な品質評価を実現しています。Reverse-Classical Testing や Code Scope Validation などの革新的な採点方法を導入し、短いプロンプトながらも高い難易度を保つ設計になっています。こうした厳格な基準により、最先端のコーディングモデルですら大幅な改善が必要な現状を明らかにする評価ツールとして機能しています。
