# GLM-5.2 is a step change for open agents

> https://www.interconnects.ai/p/glm-52-is-the-step-change-for-open

## 要約 (日本語5行)

GLM-5.2 は Zhipu AI がMIT ライセンスで公開したオープンウェイト言語モデルです。Opus 4.8 相当の性能をアリーナベンチマークで実現し、著者は「コーディングハーネスで実際に機能するエージェント」として評価しています。Fireworksの API 経由で Claude Code 環境での運用実績があり、複数モデルを使い分けるエージェンティックワークフロー（計画・実行・調整）の先駆けと位置づけられます。オープンウェイト配布によりローカル展開の道が開かれ、閉鎖AIに依存しないシステム構築が現実的になりました。記事の著者はこれを「オープン系 LLM の段階的変化」と評価しており、業界の転換点を指摘しています。
