# OpenAI just open-sourced Codex Security

> https://github.com/openai/codex-security

## 要約 (日本語5行)

OpenAI が公開した Codex Security は、コード内のセキュリティ脆弱性を自動検出・評価する OSS の CLI/SDK ツールです。
Node.js + Python で実装でき、差分スキャン・リポジトリ一括走査・カスタム脅威モデル統合が可能です。
JSON/SARIF/CSV 形式で出力でき、CI/CD パイプラインの組み込みや pre-commit hook での活用が想定されます。
gpt-5.6-sol など高度な推論モデルを活用し、本番環境での脆弱性洗い出しの自動化が実現できます。
YD の lecture_hub や salamat_wbs などの自社プロジェクトのセキュリティスキャンを現地ブランディング前に装備できる手段です。

## 既存プロジェクトとの関連

- **salamat_wbs** — Salamat 公式サイト (Next.js 16 + Tailwind v4 + three + cobe + shaders)
