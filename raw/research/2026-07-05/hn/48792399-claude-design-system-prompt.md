# Claude Design System Prompt

> https://github.com/Trystan-SA/claude-design-system-prompt

## 要約 (日本語5行)

LLMをデザイン協力者に変えるシステムプロンプト＋スキルライブラリです。AIスロップを排除し、アクセシビリティと規律あるデザイン原則を20章体系で実装します。ワイヤーフレーム・プロトタイプ・デックス生成から設計監査まで、14個の手続き型スキルで構成されています。MIT ライセンスで無属性提供されており、Claude・ChatGPT・ローカルモデル・Figmaプラグイン対応です。通用的なUI陳腐さ（グラデーション多用、絵文字装飾、角丸など）を徹底的に排除し、意図的で洗練された設計を追求しています。
