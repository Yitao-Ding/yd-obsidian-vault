# Mouse: Precision Editing Tools for AI Coding Agents

> https://hic-ai.com

## 要約 (日本語5行)

HIC Mouseはエージェント向け精密ファイル編集ツール群で、座標ベース操作（INSERT/DELETE/ADJUST等）を提供します。従来の文字列置換の限界を超え、原子性ロールバック機能により危険な編集を段階的に検証・改善できます。VS Code拡張として利用可能です。AIコーディングエージェントが提案変更を事前確認でき、リスク管理が飛躍的に向上します。Tool Response Engineeringを通じて文脈的ガイダンスをエージェントに埋め込み、より安全な自動コード編集を実現します。
