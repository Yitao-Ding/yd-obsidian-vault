# Six Months of Writing Code Exclusively with Agents

> https://blog.exe.dev/engineering-with-ai

## 要約 (日本語5行)

6ヶ月間エージェントのみでコード作成を行う実験から得た知見をまとめた記事です。Claude Codeなどの高性能LLMでも、単純にコード生成だけでは不十分であり、複数エージェントの管理・隔離・設計の先行が必須であることを実証しています。exe.devのVM基盤を使って各エージェントに独立環境を与え、マイグレーションと設計フェーズこそが真の課題であることが分かります。YDのプロジェクト（lecturte_hub、vidkit等）で即座に応用できるアーキテクチャパターンを多数提示しており、特に「機械学習的な反復（write→run→fail→fix）を設計層に拡張する」概念は、決定論的なシステム構築に最適です。

## 既存プロジェクトとの関連
- **lecture_hub** — 個人ナレッジハブ (Next.js + Supabase Postgres + pgvector + BlockNote + AI SDK)
- **vidkit** — Final Cut Pro 用の動画前処理 CLI (FCPXML 1.13, autocut, tighten, tutorial, dance)
- **morning_briefing** — 毎朝の音声+PDFブリーフィングパイプライン (Vault raw/ を読みに来る)
