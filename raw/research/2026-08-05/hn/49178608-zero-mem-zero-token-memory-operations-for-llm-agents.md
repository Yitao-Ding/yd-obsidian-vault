# Zero-Mem: Zero-Token Memory Operations for LLM Agents

> https://arxiv.org/abs/2607.29377

## 要約 (日本語5行)

LLMエージェントのメモリ操作を無トークンで実現するZero-Memシステムを提案しています。元の対話トレースを保持しつつ、エンティティグラフと時系列階層の二重構造で情報を組織化し、クエリに応じて検索を切り替えることで、最終QA段階のみLLMを呼び出します。メモリ操作時間を57.6%削減しながら長文脈ベンチマークで競争力のある性能を達成しています。中間表現生成を完全に排除することで、エージェントシステムの効率を大幅に改善しています。
