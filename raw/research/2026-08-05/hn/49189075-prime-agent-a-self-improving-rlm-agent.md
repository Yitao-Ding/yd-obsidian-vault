# Prime Agent: A self-improving RLM agent

> https://www.primeintellect.ai/blog/prime-agent

## 要約 (日本語5行)

Prime Agentは、Recursive Language Model (RLM) 抽象化とContinual Harness により、エージェントが自走中にプロンプト・スキル・メモリを動的に改善する仕組みを実現しています。従来のツール呼び出しスキーマの制約を排し、IPythonカーネルをREPLとしてサブエージェント委譲を関数呼び出し化し、セッション履歴の追記専用JSON保存で長期タスク対応を可能にしました。実装上、エージェント間の直接通信と背景デーモン管理により、トークン効率を保ったまま ARC-AGI で95.5%の成績を達成し、Rust emulator構築やGPU kernel最適化など複雑な長期作業に対応できることを実証しました。RLM の反復改善機構は、Claude Code の Agent SDK ループと相補的で、session_handover 運用モデルへの応用が見込まれます。
