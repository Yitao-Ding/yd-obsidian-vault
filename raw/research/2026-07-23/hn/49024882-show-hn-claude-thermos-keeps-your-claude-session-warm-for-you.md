# Show HN: Claude-thermos – keeps your Claude session warm for you

> https://github.com/izeigerman/claude-thermos

## 要約 (日本語5行)

Claude Thermos は長時間セッション中に prompt cache の 5 分有効期限切れを防ぐ reverse proxy です。メイン agent が待機中に subagent が実行される際、キャッシュが失効すると全会話履歴が再度エンコードされ、請求額が 22% 増加します。定期的な軽量 API 呼び出しでキャッシュを refresh し、高コストな write を避けて read rate で済ませることで、実質的なトークンコスト削減を実現します。Next.js + Supabase のような長時間パイプラインや複数エージェント並列実行時に特に有効です。実装難度は中程度で、reverse proxy 環境構築が必要ですが、セッションの既存コードは変更不要です。
