# Build a Basic AI Agent from Scratch: Long Task Planning

> https://medium.com/@rogi23696/build-a-basic-ai-agent-from-scratch-long-task-planning-14e803f9bd6d

## 要約 (日本語5行)

AI エージェントに長期タスク計画機能を追加する実装ガイドです。スクラッチパッドとTODOリストツールを使用して、エージェントが複数ステップのタスクを自走で完成させられるようにします。システムプロンプトで初期計画、段階的な実行、失敗時の診断を教込むことで、Eleventy から Hugo への静的サイト移行など複雑なタスクを自動化できます。段階的な思考外部化とリトライロジックが鍵となります。ただし実装段階で人間による破壊的コマンド承認機構の追加が必要です。
