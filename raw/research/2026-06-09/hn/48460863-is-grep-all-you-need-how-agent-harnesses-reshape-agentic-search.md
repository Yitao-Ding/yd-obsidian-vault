# Is Grep All You Need? How Agent Harnesses Reshape Agentic Search

> https://arxiv.org/abs/2605.15184

## 要約 (日本語5行)

エージェント実行フレームワーク（agent harnesses）がシステム全体の検索戦略をどう形作るかを論じています。グレップ的なシンプルな検索ツールで十分なのか、より精密な検索機構が必要なのかを実証的に問うています。Agent harness の設計が検索の効率性・精度・スケーラビリティを直接決定することを明らかにしています。エージェントが外部ツールを統合する際の検索戦略と harness アーキテクチャの関係を詳細に分析しています。エージェント駆動型アプリケーション開発では tooling と harness 設計が根本的に重要であることを示しています。
