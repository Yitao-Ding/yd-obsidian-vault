# Ornith-1.0: self-improving open-source models for agentic coding

> https://github.com/deepreinforce-ai/Ornith-1

## 要約 (日本語5行)

Ornith-1.0 は Gemma 4 と Qwen 3.5 をベースにした、エージェント型コーディングタスク向けのオープンソース言語モデルファミリーです。9B から 397B までの複数の構成が利用でき、強化学習による自己改善機構を備えています。ツール呼び出しと関数呼び出しに特化し、推論トレース（`<think>` ブロック）と OpenAI API 互換の構造化パースに対応しています。Terminal-Bench や SWE-Bench で同等サイズの大規模モデルを上回るベンチマーク性能を示しており、MIT ライセンスで全世界で自由に利用できます。256K トークンコンテキストウィンドウ対応で、vLLM や SGLang との互換性も完備されています。
