# The Author of Clean Code No Longer Reviews AI-Generated Code

## 要約 (日本語5行)

Clean Code著者のRobert Martinは、AIエージェント生成コードの品質保証戦略を提言しています。高齢であるため、生成コードを一切レビューせず、テスト・制約で品質を担保する方針を採用しています。ユニットテスト、Gherkinテスト、QA手順、品質メトリクス、ミューテーション検査など多層の制約を施します。これらの「制約のガントレット」を通すことで、高い信頼度のコードが得られると主張しています。人間レビューを手放すことで、エージェント生産性の優位性を十分に活かせるという実践的知見です。
