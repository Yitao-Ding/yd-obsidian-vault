# Agentty – A drop-in alternative to claude-code, written in C++26. 11.0 MB binary

> https://github.com/1ay1/agentty

## 要約 (日本語5行)

Agenttyは、C++26で実装されたターミナルベースのAIペアプログラミングツールであり、Claude Codeの代替となるAgent Client Protocol実装です。静的バイナリ（11MB）での配布で、サブミリ秒の起動時間と外部依存なしのセットアップが特徴です。複数のAIモデル（Claude、GPT、Groq、Ollama、OpenRouter）に対応し、Zedエディタへの統合が可能です。サンドボックス実行、エアギャップモード、ファイル操作・Git・Webサーチを含む完全なツールキットを備えています。シェルコマンドはbwrap（Linux）またはsandbox-exec（macOS）で安全に実行され、AIスキルの学習機能によりコードベース規約の習得もサポートしています。
