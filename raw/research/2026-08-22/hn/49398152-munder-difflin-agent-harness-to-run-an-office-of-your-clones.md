# Munder Difflin – Agent harness to run an office of your clones

> https://munderdiffl.in/

## 要約 (日本語5行)

Local-first で個人のワークフロー・文脈をキャプチャする multi-agent harness です。CLI ベースの AI エージェント (Claude Code / Copilot / Grok 等) を拡張して、24/7 動く autonomous worker を複数配置できます。E2E 暗号化で clone 間通信を保護し、各エージェントは独立 worktree で実行される仕組みです。組織全体で知識ベースを共有でき、開発・デザイン・営業など多職種に対応したボトルネック解消が可能です。ローカル実行とクラウド展開の両方に対応しており、実運用の自動化を支える基盤です。
