# The New MCP Roadmap

> https://blog.modelcontextprotocol.io/posts/mcp-roadmap/

## 要約 (日本語5行)

MCPのロードマップはエージェント向けメッセージング (Tasks、Subscriptions、進捗通知) と HTTP トランスポート統一を中核としています。エンタープライズセキュリティでは Workload Identity Federation と DPoP 採用を推進し、クラウドエージェントのデプロイメントを標準化します。ツール呼び出しの改善では結果ハンドリングを統一し、大規模ツール カタログの progressive discovery でスケーラビリティに対応します。SDK 全プラットフォームの人間工学・仕様準拠・ドキュメント品質に投資し、開発者体験を向上させます。Specification Enhancement Proposals (SEP) の迅速審査と Working Group 参加を通じて、コミュニティ駆動の仕様拡張を促進します。
