# Seed: Minimal, self-modifying agent harness

> https://github.com/vivekhaldar/seed

## 要約 (日本語5行)

Seed は最小限のエージェント・ハーネスで、言語モデルと bash 実行だけで始まります。エージェント自身がセッション中に self/ ディレクトリへコードを書き込むことで、自分の能力を段階的に拡張していきます。すべてのセッションは self/sessions/ に記録されるため、エージェントは過去の履歴から学んで新しい道具を開発できます。frozen codebase と可変の self/ という二層構造により、フレームワーク制約とエージェント自律性のバランスが実現されています。複数プロバイダ（OpenAI、Anthropic、Gemini）対応の llm ライブラリで、モデル選択の柔軟性も持ちます。
