# OpenAI Agents API

> https://developers.openai.com/api/docs/guides/agents-api/overview

## 要約 (日本語5行)

OpenAI Agents API は、エージェント実行をマネージする統合サービスで、言語モデル・ツール・MCP サーバーを一つの Agent 構成として定義し、セッション管理・オーケストレーション・インフラをホスティング側で担当します。
ファイルアクセス・コード実行・Web 検索・外部サービス接続といった基本機能を提供し、プログラマティック tool calling で任意のシステムとの統合を実現できます。
MCP (Model Context Protocol) サーバーをネイティブサポートし、複数エージェントの並列実行・階層的委譲・コンテキスト自動圧縮によって複雑な workflow を構成可能です。
インシデント対応・GitHub 調査・SQL データ分析・Slack ボット等の実装例があり、エンタープライズ向けオートメーション運用に適しています。
セッション再開・イベント駆動型通信により、複雑なマルチエージェント実装を API 呼び出しで実現でき、agentic システム開発の基盤として機能します。
