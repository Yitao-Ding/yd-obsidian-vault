# OKF Agent Memory – Git-native persistent memory for AI coding agents

> https://github.com/okf-memory/okf-agent-memory

## 要約 (日本語5行)

OKF Agent Memoryは、Git内の平文Markdownで AI agents向けの永続記憶を実現する標準フォーマットです。OpenKnowledge Format v0.2ベースで、ベクターDB不要・API料金ゼロの BM25検索（<300µs）により、YDのObsidian Vault運用を標準化・相互運用化できます。MCP サーバーとして Claude Code に直接統合可能で、morning_briefing や lecture_hub の知識管理に適用可能です。検証・検索・創出の Workflow が明文化されており、YDの Phase 3自動化ルール（確認なし自動保存）を構造化メタデータで実装できます。Go単一バイナリ・ゼロ依存でローカル運用完結です。
