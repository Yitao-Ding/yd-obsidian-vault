# We built a persistent agent memory layer on Elasticsearch with 0.89 recall

> https://www.elastic.co/search-labs/blog/agent-memory-elasticsearch

## 要約 (日本語5行)

Elasticsearch を使用した永続的なエージェントメモリシステムで、episodic・semantic・procedural の3種類のインデックスで認識情報を分類管理しています。RRF + 密ベクトルの2段階ハイブリッド検索と Cross-encoder 再ランキングにより、R@10で0.89の高い再現率を実現しました。時間減衰スコアリングと「supersession」メカニズムで、古い情報の優先度を自動低下させながら監査証跡を保持します。Same-turn write visibility や Document-Level Security により、同一会話内での新規事実即時反映とマルチテナント隔離を両立しています。認知科学の原理に基づいた検索メカニクスが、シンプルなベクトル類似度を超えた実用的なエージェント記憶を実現しています。
