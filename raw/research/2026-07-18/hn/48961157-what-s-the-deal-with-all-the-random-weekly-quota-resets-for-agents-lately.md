# What's the deal with all the random weekly quota resets for agents lately?

> https://minimaxir.com/2026/07/agent-quota-reset/

## 要約 (日本語5行)

OpenAI が Codex、Claude Code 等のエージェント quota を 2週間で 6回 reset するなど頻度が急増しており、Max Woolf は「予期しない報酬」としての効果が逆転していると指摘しています。quota が頻繁に reset されると、利用者は urgency を感じて急いでプロジェクトを消費しようとするため、dopamine deficit に陥り、実質的には retention ではなく competitor への乗り換え防止戦略ではないかと分析しています。過度な reset は quota を無意味にし、利用者の計画性を損なわせるため、既存ビジネスモデル (月額制課金) の前提が壊れる可能性があります。弁論としては「良好な UX 設計には頻度の閾値がある」という古典的な心理学を強調しており、AI サービスの monetization と user retention の緊張関係を浮き彫りにしています。
