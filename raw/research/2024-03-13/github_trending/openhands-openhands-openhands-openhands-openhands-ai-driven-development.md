## 要約 (日本語5行)

OpenHands は Claude / GPT に対応した Python ベースの AI agent フレームワークで、SDK / CLI / Local GUI の複数モードで動作します。SWEBench スコア 77.6、74.5k stars、TikTok / Netflix / Apple 等大手企業が採用する成熟した ecosystem です。Composable な SDK 設計で vidkit / lecture_hub / task_hub など既存プロジェクトを agent 化する統一基盤として活用できます。YD が Task Hub で既に 4 つの並列 agent (planner / builder / qa-evaluator / design-evaluator) を構築しており、フレームワークとの親和性が極めて高いです。Local CLI + on-device model 組み合わせでクラウド依存を最小化しながら agentic workflow を実現でき、YD の「仕組み化志向」に合致します。
