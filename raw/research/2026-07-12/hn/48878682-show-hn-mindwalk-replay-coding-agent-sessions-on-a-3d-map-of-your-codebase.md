# Show HN: Mindwalk – Replay coding-agent sessions on a 3D map of your codebase

> https://github.com/cosmtrek/mindwalk

## 要約 (日本語5行)

Mindwalk は Claude Code のセッションログを 3D コードマップで再生・可視化する Go + React/Three.js ツールです。ファイルの訪問履歴を色分けして表示し、エージェントの思考プロセスをインタラクティブに追跡できます。ローカル実行で、セッションデータは外部に送信されません。タイムラインスクラビング、ファイル検査、キーボードナビゲーションで細かく探索可能です。Claude Code や Codex のセッションを自動取得して可視化する点が特徴で、コード理解とデバッグの効率を高めます。
