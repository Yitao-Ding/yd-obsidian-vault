# The State of MCP Security [pdf]

> https://www.canopii.dev/State%20of%20MCP%20Security%202026.pdf

## 要約 (日本語5行)

Canopiiが11,524個のMCPサーバーをスキャンした結果、830個（1/14）がD/F評価のセキュリティ失敗を抱えていることが判明しました。232個が確認済みの危険なコード（eval、シェルインジェクション、安全でないdeserialize）を実装しており、エージェントの入力からホストコード実行に至る経路を持つサーバーが存在します。78%のサーバーがdependencyをpinしておらず、1,617個が既知脆弱性のあるパッケージに依存しており、供給チェーン攻撃に対し極めて脆弱です。184バージョンが公開後に定義を密かに変更する「rug pull」パターンが170個のサーバーで観測され、エンドユーザーが承認した定義と実行時の定義のズレが起きています。有名なサーバー（1000+ stars）ほどリスク高い傾向を示し、採用時は星数ではなく継続的なセキュリティスコア監視が必須です。
