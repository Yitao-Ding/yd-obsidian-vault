# OpenWiki: CLI that writes and maintains agent documentation for your codebase

> https://github.com/langchain-ai/openwiki

## 要約 (日本語5行)

LangChain AI が開発した CLI ツール。エージェントがコードベースを読みながらドキュメンテーションを自動生成・保守する仕組みを実装。
コード変更と doc の乖離 (documentation drift) を防ぎ、エージェント向けに常に最新の文脈を提供することが本来の目的。
lecture_hub のようなナレッジハブと組み合わせれば、個人プロジェクト全体の API 仕様と実装をエージェント向けに統合可能。
Salamat や Arte Grow のコードベース管理にも応用できるため、スタッフ教育の doc 自動化が期待できる。
morning_briefing のパイプラインに組み込めば、毎朝 code change に基づく自動更新ドキュメントを配信できるようになる。
