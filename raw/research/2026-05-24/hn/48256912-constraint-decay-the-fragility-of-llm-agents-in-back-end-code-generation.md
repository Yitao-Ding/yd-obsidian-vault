# Constraint Decay: The Fragility of LLM Agents in Back End Code Generation

> https://arxiv.org/abs/2605.06445

## 要約 (日本語5行)

バックエンド・コード生成タスクにおいて、LLMエージェントが最初は制約を守るものの、生成過程の進行とともに制約順守能力が劣化する現象を報告しています。複雑なコード生成では、エージェントが初期の仕様や制限条件を忘れたり無視したりする傾向が強まり、生成品質が低下することを指摘しています。この「制約decay」はエージェントの長期推論と状態保持の根本的な限界を示唆しており、現在のLLMは長いコード生成タスクに対して信頼性が不十分であることを示しています。バックエンド開発の自動化やコード生成エージェント設計には、制約を維持するメカニズムの強化が不可欠です。
