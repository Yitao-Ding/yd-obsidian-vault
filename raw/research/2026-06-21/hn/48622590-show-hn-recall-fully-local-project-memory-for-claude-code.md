# Show HN: Recall – fully-local project memory for Claude Code

## 要約 (日本語5行)

Recall はClaude Code向けのローカルプロジェクトメモリツールで、セッション横断的にプロジェクトコンテキストを保持します。.recall/ ディレクトリに history.md（トランスクリプト）と context.md（TF-IDF + TextRank による要約）を自動生成し、APIキーなしの完全オフライン動作です。次回セッション起動時に1-2Kトークンの要約から復帰するため、トークン効率が大幅に向上し、毎回のプロジェクト説明が不要になります。YDのVault 運用モデル（起動時の必須読み込みシーケンス）と相補的で、ローカル知識ベース + Claude Code メモリの二重化により、マルチセッション開発が劇的に効率化します。実装はPython（TF-IDF、TextRank）のみで依存が最小限です。
