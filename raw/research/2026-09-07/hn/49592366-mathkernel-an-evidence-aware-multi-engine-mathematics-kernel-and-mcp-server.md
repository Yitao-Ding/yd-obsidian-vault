# MathKernel: An evidence-aware multi-engine mathematics kernel and MCP server

> https://github.com/Staatsgeheim/MathKernel

## 要約 (日本語5行)

MathKernel は LLM 向けの多エンジン数学核で、SymPy/Z3/Lean/Numba/CUDA をオーケストレーションし MCP サーバーとして動作します。計算結果に SYMBOLIC/EXACT/FORMAL/NUMERIC/CERTIFIED といった信頼レベルタグと完全な由来追跡を付与するため、仮定や近似の由来が消えません。代数、微分方程式、確率、グラフ、有限要素法、代数位相、統計など 40+ ドメイン対応で、型付き MathIR を通じた厳密なコンポジションを実現します。視覚化とソニフィケーション(音化)をマルチモーダル出力として統合でき、計算証拠を保持したまま複数の表現を生成できます。非同期ジョブ実行、LaTeX パース、GPU 加速対応であり、本体は MIT ライセンスで production-stable (v1.3.0) です。
