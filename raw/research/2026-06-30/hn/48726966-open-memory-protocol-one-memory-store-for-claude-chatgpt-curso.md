## 要約 (日本語5行)

Open Memory Protocol (OMP) は、Claude・ChatGPT・Cursor 間でメモリを共有するための業界中立な仕様です。各 AI ツールが独立にユーザー情報を記憶するシイロ問題を解く、自ホスト型の REST API サーバーと MCP アダプタで実装されています。セマンティック検索・複数メモリタイプ対応・プライバシー第一の設計が特徴で、現在 v0.1-0.3 段階、v1.0 に向けて開発中です。
