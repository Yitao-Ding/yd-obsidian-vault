# Claude Code and Codex Can Have Real-Time Conversation via Git

## 要約 (日本語5行)

Agent Radio は Git を唯一の共有基盤とし、複数 AI エージェント間でリアルタイム協調を実現するシステムです。i5h プロトコルで JSONL メッセージ交換を行い、サーバー・スキーマレジストリ不要で軽量実装できます。Git の不変追跡により全通信が自動監査でき、分岐時の競合も set union で自動解決します。Claude Code と Codex など異なるエージェント間での並列実行と非同期通信を高速化でき、GitHub PR への結果投稿も統合できるため、大規模リポジトリでのマルチエージェント協調開発に有効です。
