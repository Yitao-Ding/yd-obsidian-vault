# Show HN: Id-agent – Token efficient UUID alternative for AI agents

> https://github.com/vostride/id-agent

## 要約 (日本語5行)

AI エージェント向けに設計された ID 生成ライブラリで、UUID の代わりに 4,096 単語の厳選リストで人間が読める識別子を生成します。8 単語 ID は 12-14 tokens で済み、UUID の ~23 tokens と比べて 39% の削減を実現し、300 trillion 個まで衝突回避が可能です。BPE tokenizer が自然言語に最適化されている仕様を活用し、prompting コスト削減によってエージェントの推論予算をより効果的に活用できます。HMAC-SHA256 による決定論的 ID 生成とランダム生成の両方に対応し、Zod での検証で安全性を確保しています。開発テストから本番 SaaS、LLM agent ワークフローまで、用途に応じた柔軟な長さの ID 選択が可能です。
