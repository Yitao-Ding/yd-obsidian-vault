# Agent skills that bring team coding standards to Claude Code and Codex

> https://github.com/tikalk/adlc-team-skills

## 要約 (日本語5行)

ADLC Team Skills はチーム規模の AI コーディングを「Directives as Code」で統治するオープンソーススキル・システムです。Claude Code や Codex などの AI エージェントが個別のプロンプト実験ではなく、バージョン管理されたチーム憲法に従うように設計されています。Strategy、Product、Architecture、Verification の4本柱で、team-boot、mission-brief、product-*、architect-* などのスキルが PM・設計・評価フェーズを自動化し、ADR・PRD・評価スイートを .adlc/ に生成します。複数の Agent Skills リポジトリ (mattpocock/skills、addyosmani/agent-skills など) に依存せず、adlc-skills-cli でスラッシュコマンド化し、セッション開始時にブートするため、個人の「Vibe Coding」を組織的な品質基準に統一できます。GitHub Copilot や Cursor にも対応し、PromptFoo や DeepEval による検証レイヤーで AI 出力の確実性を担保します。
