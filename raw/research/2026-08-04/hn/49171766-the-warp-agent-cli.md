# The Warp Agent CLI

> https://www.warp.dev/blog/introducing-the-warp-agent-cli-coding-agent

## 要約 (日本語5行)

Warp が独立した CLI コーディングエージェントをリリースし、任意のターミナル環境で実行可能にしました。複数 AI モデルの自動ルーティング、ターミナルアプリ（SQLite/vim等）の対話制御、リモート実行に対応しています。従来 Warp Terminal 専用だった機能を汎用化し、ターミナルワークフローの自動化を拡張したツールです。クラウドハンドオフやマルチエージェントオーケストレーション対応で、コード審査・バグ調査・リファクタリング等に活用できます。ターミナル多重化層により従来の CLI エージェントより高度なターミナル認識が可能です。
