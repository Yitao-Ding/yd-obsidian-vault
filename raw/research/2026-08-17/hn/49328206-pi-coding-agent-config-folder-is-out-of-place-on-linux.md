# Pi coding agent: config folder is out of place on Linux

> https://github.com/earendil-works/pi/issues/534

## 要約 (日本語5行)

Pi コーディングエージェントが Linux でホームディレクトリ直下に設定フォルダを作成する問題です。XDG Base Directory Specification に準拠すべきという提案です。PI_CONFIG_DIR → XDG_CONFIG_HOME → プラットフォーム別デフォルトの順で参照する実装が推奨されています。Linux/BSD では ~/.config/pi、Windows では %APPDATA%\pi というように統一する必要があります。ホームディレクトリの散乱を防ぎ、Linux エコシステムの標準慣例に合わせるための改善です。
