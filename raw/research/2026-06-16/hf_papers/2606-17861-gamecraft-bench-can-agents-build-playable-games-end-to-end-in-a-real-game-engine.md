# GameCraft-Bench: Can Agents Build Playable Games End-to-End in a Real Game Engine?

> https://huggingface.co/papers/2606.17861

## 要約 (日本語5行)

ゲームエンジン内で自律的なコード生成エージェントが完全に動作可能なゲームを実装できるかを評価する GameCraft-Bench ベンチマークを提案しています。
Godot を対象に 15 のゲームカテゴリ、140 個のタスクで、エンジン接地・アーティファクト完全性・対話検証を評価軸とした包括的なフレームワークを構築しました。
最先端のコーディングエージェントでも 41% の成功率に留まり、ゲーム内容の充実度・視覚フィードバック・統一されたプレゼンテーションが主な課題です。
ゲーム生成は従来のコード生成と本質的に異なり、スクリプト・シーン・アセット・レンダリング・実行時相互作用が一体として初めて動作するゲームが完成します。
interaction-grounded 評価により、再生デモと多モーダルな rubric 判定を組み合わせて、実際に遊べるゲームプレイの達成度を検証します。

## 原文 (Abstract)

Game generation is an emerging application of coding agents, requiring models to transform natural-language specifications into playable interactive systems. Unlike traditional coding tasks, game generation takes place within a game engine, where scripts, scenes, assets, rendering, and runtime interactions must jointly produce coherent gameplay. We formalize end-to-end game generation as the problem of producing a complete game artifact that realizes a specification through observable player-game interaction in a target environment. We argue that evaluating this setting requires three desiderata: Engine Grounding, Artifact Completeness, and Interactive Verification. We propose an interaction-grounded evaluation framework that assesses executable gameplay through replayed demonstrations and rubric-guided multimodal judging. We instantiate this framework as GameCraft-Bench, a benchmark comprising 140 Godot tasks across 15 game families. Evaluations of frontier coding agents show that end-to-end game generation remains highly challenging: the strongest agent achieves only 41.46%, and most agents score below 40%. Further analysis reveals that while agents often implement recognizable mechanics, they struggle to deliver complete games with sufficient content, functional visual feedback, and coherent presentation.
