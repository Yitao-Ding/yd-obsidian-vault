# Agent-talk: Enabling coding agents to work together

> https://github.com/xhluca/agent-talk

## 要約 (日本語5行)

Agent-talkは複数のコーディングエージェント（Claude Code、Codex、Antigravity、pi、opencode、Copilot）間でエンドツーエンド暗号化されたメッセージを交換できるプラグインシステムです。
各エージェントが独立して動作しながら、長時間実行中のタスク上で非同期に協調でき、リレーを通じた相互通信を実現します。
retalkという基盤技術を使い、別マシン・別ユーザー間でも通信可能で、従来はヒューマンがメッセンジャーになっていた部分を自動化します。
タスク管理・リーダー・共有状態がなく、メッセージプリミティブのみを提供する設計により、セッション外での長期実行ワークフローに適しています。
実装難易度は低く、インストール後は自然言語プロンプトで「message bob: hello」などの指示が使え、初回セットアップで最小限の管理負荷ですぐに運用開始できます。
