# MathCode, Mathematical Coding Agent

> https://math-ai-org.github.io/mathcode/

## 要約 (日本語5行)

自然言語で記述した数学問題を Lean 4 の形式的定理に自動変換し、証明を生成するエージェント型システムです。並列証明探索とサブゴール分解により複雑な定理を効率的に証明する手法を採用しています。永続的な Lean REPL により再コンパイル時間を 0.4秒に短縮（標準は 30秒）し、証明作成の反復を加速させます。定理の依存関係を Obsidian ボルト形式のナレッジグラフとして可視化し、証明過程の追跡が容易です。macOS・Linux 環境での CLI ツールとして提供され、オプションのブラウザ UI も装備しています。
