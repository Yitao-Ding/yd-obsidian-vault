# Agent Is Not the Model

> https://code.joejag.com/2026/your-agent-is-not-the-model.html

## 要約 (日本語5行)

モデルはトークン変換の数学関数に過ぎず、エージェントはハーネス・推論基盤を含む全体システムです。同じモデルでも、コンテキスト管理やツール統合の違いでClaudeデスクトップとCLIで異なる出力になります。トラブル原因は層別に異なり、推論品質はモデル層、速度は基盤層、ツール失敗はハーネス層の問題です。今のMCPやスキルはハーネス機能ですが、モデル性能が向上すれば不要になる可能性があります。用語精度がデバッグサイクルの効率化と改善の方向性を決めるため、システム層別の理解が実装に必須です。
