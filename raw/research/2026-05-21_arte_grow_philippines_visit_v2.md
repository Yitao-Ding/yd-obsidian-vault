## 結論 (3行)

- 第1版の前提が複数崩れました。**Cambio & Co. は 2026年2月に閉業 (米国 de minimis 廃止が直撃)**、**People Tree UK は 2023年9月清算 (負債 £8.5M、生産者未払 £500K)**。先行する成功モデルが事実上存在せず、Arte Grow は実証されていないモデルにベットする構造です。
- 視察コストは第1版の「3名 51-60万円」ではなく **隠れコスト込みで 96-150万円 (中級型)**、**ローンチまでの累計は 220-388万円** が実態。devil の主観評価で **Arte Grow が 5年生存する確率は 20-25%**。
- ただし視察の定義を **「パートナー選定」から「Go/No-Go を確定させる最終確認」に変える** なら ROI は成立。**視察前に絶対やる 1 アクション = Cambio 創業者 Nica Reyes に DM**(費用ゼロ、30分、閉業原因が関税だけか収益性問題かを直接確認)。

## 1. 第1版から変わった主要発見

### 1-1. 競合マップの崩壊

| ブランド | 第1版 (2026-05-20) | 実態 (2026-05-21 判明) |
|---------|----------------|---------------------|
| **Cambio & Co.** | 競合 + ベンチマーク両義として推奨 | **2026年2月閉業**。米国/カナダ間の de minimis 廃止 + 15% サーチャージで運営継続不能 |
| **People Tree** | 30年実績のフェアトレード代表 | **2023年9月清算 (UK)、2025年完全解体**。負債 £8.5M、生産者未払 £500K |
| **Makabayan UK** | 「海外で売る」軸の先行事例 | プラットフォーム移行中で実質オペ停止 |
| **ANTHILL** | 視察優先度 ★★★ | 評価維持。**Anya Lim の「企業は役に立たなくなるとき成功する」が Pride 軸と完全一致**。ASEAN-Japan Centre 特集 (2024) あり |
| **CCAP** | 視察優先度 ★★★ | 評価維持。ただし公式では「5地域・26コミュニティ」(第1版は「11州・31工房」)。要視察時確認 |
| **Sisam 工房 (京都)** | 第1版言及なし | **新発見**。日本フェアトレード小売25年。フィリピン取扱実績あり。日本市場の最初の卸候補 |

→ Arte Grow が比較軸にしていた「Cambio との位置関係」「People Tree との差別化」が両方とも消失。**実証されたモデルがほぼ存在しない領域で立ち上げることになる**。

### 1-2. コストの実態が大幅修正

第1版の試算は「予備費ゼロ・隠れコスト無視」の楽観シナリオでした。econ の再算定で:

| 区分 | 第1版 | v2 (現実) |
|------|------|----------|
| 視察コスト (3名・中級型) | 51-60 万円 | **135-150 万円** |
| 視察 + 累計ローンチコスト | 試算なし | **220-388 万円** |
| 隠れコスト (保険・ワクチン・手土産・チャーター・為替手数料・3名分) | ゼロ | **13-14 万円** |
| 予備費標準比率 | 言及なし | 旅行費の **20%** (10-11 万円) |

最大の修正ポイントは「視察 = 1 イベント」と捉えていた第1版に対し、v2 は「視察 → ローンチまで」の **累計投資 220-388 万円** が必要だと明示。これは Apple バイト代を全投入しても初年度で回収する目処はほぼ立ちません。

### 1-3. 法的義務 (第1版で完全に抜けていた)

ethics の発見が致命的:

- **IPRA 1997 (RA 8371)** がフィリピンで施行中。先住民族の文化・知財の商業利用には **FPIC (Free and Prior Informed Consent) プロセス必須**。違反は刑事・民事責任。
- **粗収入の 5% 以上のロイヤリティ** が法定。
- T'nalak (T'boli の布) は霊的・儀礼的紋様を含み、量産・複製は不敬とみなされる可能性。
- ブランド名 "Arte Grow" 自体がポルトガル/スペイン語起源。フィリピンの3世紀の植民地支配の歴史と接続する。
- FPIC プロセスを真剣に行うと **6-18 ヶ月**、フィリピン弁護士費用 + 通訳含めて **100-200 万円の追加コスト** がかかる可能性 (devil 試算)。

### 1-4. マクロ環境のリスク

- フィリピン **2026年4月インフレが 7.2% に急騰** (2025年通年 1.66% から急悪化)。職人の生活コスト直撃 → 「Pride 軸の賃金保証」と「日本販売価格」のバランスが崩れる。
- フィリピン工芸品輸出市場が **2024年に 20% 縮小** ($500M→$400M)、5年で **4,000 社撤退**。電力・物流・港湾コストでインドネシアに価格競争で負けている。
- PHP/JPY は過去3年で年 ±10-16% のボラティリティ。仕入価格への影響は上代の ±4% 程度だが、撤退ラインが未定義。

## 2. 5人エージェントの深化サマリ

### 2-1. econ (経済性アナリスト)

- **視察予算上限の現実値: 3名で 135-150 万円 (中級型)**。LCC節約型でも 96-105 万円。
- **HS 6214 (ストール) の RCEP 関税は 3.3-6.8%**。MFN (4.4-11.2%) より優遇あり。
- **家庭用品品質表示法**: 繊維組成 + JIS L 0001 取扱記号 + 表示者名を日本語ラベル必須。違反は20万円以下罰則。
- **5年後ターゲットのベンチマーク**: Indigo Handloom (年商 $576K / 従業員5名) が現実的。People Tree (年商 $5.4M) はスケール過大で参考になりにくい。
- **損益分岐**: 上代 ¥10,000 で月 18 点販売 = 月商 18 万円で利益 5 万円。立ち上げ1年は **月商 24-40 万円が現実的目標**。
- **判断材料の数字** (econ § 6):
  - 視察予算: 135-150 万円
  - 職人最低賃金目標: 月 ₱18,000 以上 (最低賃金の 120%)
  - 日本上代最低ライン: ¥8,000-10,000
  - 損益分岐: 月販 30 点 × ¥10,000 = 月商 30 万円

### 2-2. ethics (倫理・哲学レビュアー)

- "Pride, Not Dependency" は第1版時点で **構造的担保ゼロのスローガン**。
- 「依存」を 5 次元に分解 (経済・デザイン・情報・流通・技術) して各々の対策を設計する必要。
- 「5 年で完全独立」は **一般ビジネス5年生存率 52% から見て楽観すぎる**。「年次独立指標の透明評価」に再定義すべき。
- **IPRA + FPIC の法的義務を視察前に確認必須** (NCIP = 国家先住民族委員会)。
- **YD が前に出るほど職人がエキゾチック素材化する構造リスク**。柳宗悦の民芸運動が持った「東洋的オリエンタリズム」と同型。
- **視察前に明文化すべき原則 3 つ**:
  1. 収入依存上限 = 職人 1 人あたり Arte Grow 依存度を全収入の **30% 以下** に契約化。
  2. **YD 自身の取り分の上限** を先に決める。超過分の行き先 (職人還元 / ロイヤリティ積立 / 技術継承再投資) も事前設計。
  3. **離脱の自由** = 1 年更新制契約 + 離脱後もコンテンツ・ブランドストーリーの権利は職人帰属。

詳細: [[2026-05-21_ethics]]

## 3. 「視察に行くべきか」の Go / No-Go 判断軸 (今すぐの判断)

5 人の深化を踏まえた選択肢:

**選択肢 A — 視察を「Go/No-Go 最終確認」に再定義して実行**
- 視察前 1 ヶ月でオンライン検証 3 手 (§ 3-1) を完了する条件付き
- 視察予算上限を 130 万円固定 (3名)、超過分は日程縮小で吸収
- 帰国後 4 週間は意思決定を凍結 (サンクコスト効果を冷却)
- メリット: 体で確かめられる、Pagtambayayong コネクションも活用、Taichi/Rena/Haruka の本気度も同時確認できる
- デメリット: 100 万円超のコスト、台風リスク 30-40%、4 名のスケジュール調整

**選択肢 B — 視察を半年延期し、視察前検証を徹底**
- 2027 年 1-3 月 (乾季) に視察を延期、9 月は YD の卒論時期と衝突するためタイムラインを根本見直し
- 半年で Cambio 創業者ヒアリング・Sisam 卸条件確認・日本人 200 名アンケート・市場サイズ実測を完了
- 視察前に「ローンチする確信度」を 70% 以上に上げてから行く
- メリット: 投資の精度が上がる、卒論との衝突回避、為替動向も見極められる
- デメリット: 熱量が冷める可能性、9月の航空券安期を逃す、Taichi のスケジュール再調整必要

**選択肢 C — Arte Grow 自体を一時凍結し、Salamat / Task Hub / Lecture Hub に集中**
- YD のリソース分散リスクが最大の問題なら、根本対処として Arte Grow を 2027 年以降に先送り
- 視察予算 100 万円を Task Hub のスケールや Lecture Hub のローンチに投じる
- メリット: 機会費用が他事業の成功確率を上げる、Arte Grow は時間をかけて自然に熟成
- デメリット: Taichi との共同創業合意が宙ぶらりんになる、フィリピンとの関係が冷える、9 月の安価な航空券タイミングを逃す

### 推奨 (リーダーとしての判断)

**僕の推奨は A です。条件付きで。**

理由:
1. devil の指摘通り「視察 = Go/No-Go 最終確認」に再定義すれば、100 万円は「意思決定コスト」として正当化される。Zoom 何時間積み重ねても判断できない領域がある。
2. ANTHILL の Anya Lim の「企業が消える=成功」モデルが Arte Grow と完全一致するという発見は、視察に行く価値を底上げする。生の Anya Lim と会わずに判断するのは情報損失が大きい。
3. Pagtambayayong (Salamat 既存コネクション) の活用余地が、コールドメール返信率 5-15% の壁を破る現実的経路として残っている。
4. 帰国後 4 週間の凍結期間と「やらない基準 5 項目」を出発前に明文化することで、サンクコスト効果は構造的に防げる。

**ただし以下 3 条件のうち 1 つでも未達なら B (延期) に切り替え**:
- 視察前 1 ヶ月でオンライン検証 3 手 (Cambio DM・Sisam 問い合わせ・日本人アンケート 200 名) が完了している
- 6/30 時点で Arte Grow コンセプトペーパー英語版が完成している
- 7/1 時点で Taichi/Rena/Haruka 全員が視察参加で合意している

### 5-3. 倫理ガードレール (ethics の最優先 3 項目)

視察前に明文化、コンセプトペーパー英語版に明記:

1. **収入依存上限ルール**: 職人 1 人あたり Arte Grow 依存度を全収入の 30% 以下。超えたら他販路を積極紹介する義務を Arte Grow 側が負う。
2. **YD 自身の取り分の上限**: 数字で先に決める。超過分は職人還元 / ロイヤリティ積立 / 技術継承への再投資に回す。
3. **離脱の自由**: 1 年更新制契約。離脱後もコンテンツ・ブランドストーリーの権利は職人に帰属。

T'nalak (T'boli) など霊的紋様を扱う場合は FPIC + IPRA + NCIP 連携が必須。視察初動は FPIC 不要な現代的工芸品に絞ることで初期法務コストを大幅圧縮。

### 5-4. リスク管理 (devil + ops 統合)

- 為替: PHP/JPY 3.0 円超で仕入れ一時停止、3.2 円超で在庫消化後撤退検討 (撤退ライン数値化)
