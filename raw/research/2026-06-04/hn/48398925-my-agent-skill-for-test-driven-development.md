# My Agent Skill for Test-Driven Development

> https://www.saturnci.com/my-agent-skill-for-test-driven-development.html

## 要約 (日本語5行)

エージェント向け TDD スキルプロンプトの設計方法について論じています。Kent Beck の Canon TDD をベースに、Specify-Encode-Fulfill ループを提案し、エージェントに「テストとは何か」の原則を明示的に教えるアプローチが中心です。テスト設計レビュー用エージェント実装で品質保証を自動化し、Claude が原則ベースの指導に応じやすいことを実証しています。AI エージェントの出力品質を 60% の基礎段階から引き上げるには、「タイムレスで普遍的な原則」を明確に符号化することが不可欠だと主張しています。エージェント設計の本質的な課題――訓練データから自動推論できない「ソフトウェア工学の規律」をどう注入するか――への実践的な解答を提供しています。
