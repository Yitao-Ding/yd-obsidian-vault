# Show HN: Pulse – Dashboard for Claude Code, approve tool calls from your phone

## 要約 (日本語5行)

Claude Code のセッション実行状況をダッシュボード UI でリアルタイム可視化するローカル監視ツールです。スマートフォンから直接 tool call の承認を与えることができ、外出先からでも agent の実行を制御・監視できます。トークン使用量とセッションコストをリアルタイムで追跡表示するため、agent orchestration 運用のコスト把握が容易になります。ローカル実行のみ対応で、クラウド依存やアカウント登録が不要なため、データプライバシーとセキュリティが確保されます。複数 agent の並行実行時に各 agent の進捗・コスト・tool call の承認フローを一元管理する基盤として活用可能です。
