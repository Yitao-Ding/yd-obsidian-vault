# CC コマンドの権限バイパス機能 (2026-05-18)

## 要約

Salamat WBS プロジェクト (`~/Downloads/07_開発・アプリ制作/salamat-website-v2`) 用に
Claude Code の権限設定 (`bypassPermissions` + ホワイトリスト) を構築。
Obsidian Vault の特定フォルダのみ読み取り許可し、書き込みは全 deny する
セキュリティポリシーを確立。

また、デスクトップ Claude のメモリでは「WBS は Wix・5月1日公開」となっていたが、
実態は「Next.js 16 + React 19 + Tailwind v4 で独自実装」だったことが判明。
メモリ更新の必要性が浮上した。

## 主要な決定事項

### settings.json 配置
- パス: `~/Downloads/07_開発・アプリ制作/salamat-website-v2/.claude/settings.json`
- `defaultMode`: `bypassPermissions` (defaultMode で開発フローを止めない)

### Read 許可 (additionalDirectories)
- `/Users/ittou/ObsidianVault/knowledge` — Salamat 等のドメイン知識
- `/Users/ittou/ObsidianVault/current_state` — 現在の状況
- `/Users/ittou/ObsidianVault/decisions` — 意思決定ログ
- `/Users/ittou/ObsidianVault/wiki` — wiki 知識
- `/Users/ittou/ObsidianVault/CLAUDE.md` / `00_CLAUDE_BOOT.md` — CC 向けブート情報

### 除外フォルダ (プライベート寄り)
- `daily/` `raw/` `mistakes/` `identity/`

### Write/Edit
- Vault 全体で **deny** (読むだけ、書き込みは絶対させない)

### Deny リスト
```
Bash(rm -rf /), Bash(rm -rf ~), Bash(rm -rf ~/*), Bash(rm -rf $HOME*)
Bash(rm -rf /Users/ittou), Bash(rm -rf /Users/ittou/*)
Bash(sudo *), Bash(git push --force *), Bash(git push -f *)
Bash(git reset --hard *), Bash(git clean -fdx *), Bash(git filter-branch *)
Bash(git update-ref -d *)
Bash(npm publish *), Bash(pnpm publish *), Bash(vercel --prod *)
Bash(firebase deploy *)
Bash(curl * | sh), Bash(curl * | bash), Bash(wget * | sh), Bash(wget * | bash)
Bash(chmod 777 *), Bash(chown *), Bash(dd *), Bash(mkfs *), Bash(diskutil *)
Read(./.env), Read(./.env.*), Read(**/.env), Read(**/.env.*)
Read(**/secrets/**), Read(**/credentials/**)
Read(/Users/ittou/.ssh/**), Read(/Users/ittou/.aws/**)
Read(/Users/ittou/.gnupg/**), Read(/Users/ittou/.config/gh/**)
Write(/Users/ittou/ObsidianVault/**), Edit(/Users/ittou/ObsidianVault/**)
```
