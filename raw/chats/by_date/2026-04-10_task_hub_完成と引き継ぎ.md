# Task Hub: サークル向けプロジェクト管理アプリ (2026-04-10)

## 要約

Task Hub の主要機能が一気に完成した日。チーム・プロジェクト・タスク CRUD、
提出スレッド、デザイン統一 (ネイビー系) まで完了。マイタスク画面 (`/tasks`) を
追加し、ボトムナビを 4 ページに統合。

Notion に「Claude Code 引き継ぎ用コンテキスト」を Markdown で生成して、
新セッションへの引き継ぎ手順を確立した。

VSCode と Claude Code が同じファイルを編集して衝突するエラー
(`The content of the file is newer`) も対処を覚えた。

## 主要な決定事項

- **マイタスク画面**: Firebase Auth ユーザーの `uid` が `assigneeId` と一致する
  タスクを全チーム横断で取得。`getMyTeams` → `getProjects` → `getTasks` を並列実行
- **未完了・完了のセクション分け、期日順ソート**
- **ボトムナビ「タスク」ボタン**: `app/page.tsx` / `app/team/[teamId]/page.tsx` /
  `app/team/[teamId]/project/[projectId]/page.tsx` / `app/team/[teamId]/project/[projectId]/task/[taskId]/page.tsx`
  の 4 ファイルに `router.push("/tasks")` 追加
- **CC 衝突対処**: VSCode で保存しようとして「The content of the file is newer」が
  出たら **Overwrite** を選ぶ。今後 VSCode で直接編集しない方針に
- **Cowork は MCP 未接続**: 出先から Mac の `npm run dev` を起動できない。
  Vercel デプロイすればスマホから本番確認可能
