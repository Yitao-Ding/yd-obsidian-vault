# 平成たち祭 SNS拡散用ショート 5本案

> 縦動画 9:16 / 各 15〜30秒
> TikTok / Instagram Reels / YouTube Shorts 対応

---

## 共通ルール (全5本)

- 最初の 3 秒でスクロールを止める (フック設計が最優先)
- 音あり前提 (BGMはサムネイル・音量最大で最適化)
- SNS 公開: イベント楽曲そのままは著作権リスクあり → 著作権フリー音源使用 or 環境音 + SE のみ
- テロップ: 縦動画の中央エリア (上下15%は避ける)
- 書き出し: 1080×1920 (9:16) / H.264 / 30fps / ビットレート 10-15Mbps

---

## Short #1「3秒で振り向かせる」— BTS フック型

**長さ**: 20秒  
**ターゲット**: 踊る人・ダンサーフォロワー  
**最適プラットフォーム**: TikTok > Instagram Reels > YouTube Shorts

### フック (0〜3秒)
```
GoPro 縦カット: ステージに出る直前の後ろ姿 + 暗転
→ 「次のシーンに何が起こるか」の期待
テロップなし。環境音のみ (息を飲む静寂)。
```

### 本編 (3〜18秒)
```
[3s] GoPro 出番前の緊張顔・深呼吸
[5s] ステージに出る直前の後ろ姿 (引き)
[7s] R5望遠 ステージ上の見せ場 (サビ / 一気に照明ON)
[10s] GoPro 踊り終わって戻ってきた笑顔・ハイタッチ
[14s] R5望遠 観客の拍手・盛り上がり
```

### エンド (18〜20秒)
```
テキストカード: 「平成たち祭 -REPLAYGROUND- 2026.05.06」
+ SNS タグ: #平成たち祭 #ダンスイベント #replayground
```

**BGM**: アップテンポ instrumental / Artlist "cinematic beats"  
**カラー**: 波②グレード (ハイコントラスト・ライブ感)

## Short #3「ダンスの瞬間」— ベストカット型

**長さ**: 15秒  
**ターゲット**: ダンス動画好き / YouTube Shorts のメイン層  
**最適プラットフォーム**: YouTube Shorts = TikTok

### フック (0〜3秒)
```
スピードランプ: ジャンプ頂点でスロー → 着地で通常速度
テロップ: (なし) — 映像の力だけで止める
```

### 本編 (3〜13秒)
```
[3s]  R5望遠 照明変化の瞬間 (暗転→ON)
[5s]  R5望遠 見せ場 フォーメーション (24fps → 60fps スロー混在)
[8s]  FX30 観客ノリノリ盛り上がり
[10s] R5望遠 Haruhi ソロ 表情クローズアップ
[12s] GoPro ハイタッチ シーン
```

### エンド (13〜15秒)
```
テキスト: 「Full video on YouTube 🔗 」+ ロゴ
→ YouTube 本編への誘導
```

**BGM**: 使用楽曲のインスト or 著作権フリーEDM  
**カラー**: 波②グレード (彩度高め・ライブ感)

## Short #4「舞台裏の本音」— インタビュー型

**長さ**: 30秒  
**ターゲット**: ドキュメンタリー好き / 出演者のフォロワー  
**最適プラットフォーム**: Instagram Reels > TikTok

### フック (0〜3秒)
```
インタビュー: 「今の気持ちを一言で！」の回答の一番面白い / 感動的な部分
→ 最初の3秒で最強の一言を持ってくる
テロップ: 発言内容を大文字でオーバーレイ
```

### 本編 (3〜25秒)
```
[3s]  インタビュー 続き (ダンサー1名 or 複数名のカット割り)
[10s] 場当たりの様子 (インタビューの言葉と対応するシーン)
[15s] 本番中のR5望遠 (インタビューで語ったシーン)
[20s] 踊り終わって戻ってきた笑顔
[23s] インタビューの〆: 「どこを見てほしい？」回答
```

### エンド (25〜30秒)
```
名前テロップ: 「○○○ (Group Name)」
テキスト: 「平成たち祭 -REPLAYGROUND- 2026.05.06」
```

**BGM**: インタビュー中は音量下げる (声が主役) / BGMはサビで上げる  
**カラー**: INTRO/波①グレード (ウォームで落ち着いた)

⚠️ このシートが作れるかは「インタビュー素材が撮れているか」次第。
外部マイク使用かどうか → 音声品質確認が最優先。

## プラットフォーム別最適化メモ

| 項目 | TikTok | Instagram Reels | YouTube Shorts |
|-----|--------|----------------|---------------|
| 推奨サイズ | 1080×1920 | 1080×1920 | 1080×1920 |
| 推奨fps | 30fps | 30fps | 30fps |
| 最適尺 | 15-30秒 | 15-30秒 | 15-60秒 |
| テキスト位置 | 中央〜下部 (UI回避) | 中央 | 中央 |
| フック尺 | 最初の1-2秒が勝負 | 最初の3秒 | 最初の3秒 |
| 字幕 | 必須 (ミュート視聴多) | 強く推奨 | 推奨 |
| ハッシュタグ | 3-5個 | 3-5個 | 5-10個 |
| BGM | TikTok音楽でも可 | 著作権注意 | 著作権注意 |
