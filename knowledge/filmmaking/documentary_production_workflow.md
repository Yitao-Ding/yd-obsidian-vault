# ドキュメンタリー制作フロー（汎用テンプレ）

撮影素材の山 → 設計案（台本）→ Claude Code自動編集 まで、題材を問わず回せる型。
第1号案件: ダンちゃり長野「一匹でも」(2026-07) で確立。

## 全体像

Phase 0 素材整理(人間) → 1 素材把握(AI) → 2 設計(対話) → 3 検証(AI) → 4 CC実行プロンプト化 → 5 編集実行・仕上げ

人間が必ず手を動かす場所は3つだけ: 素材振り分け / 設計の意思決定 / チェックポイント対応（ラジオエディット試聴・BGM配置・試写）。

## Phase 0: 素材整理（人間・撮影後すぐ）

- 素材をシーン単位でフォルダ振り分け（後の設計の節と1対1対応させる）
- カメラの役割をメモ（例: Sony=映像メイン / DJI=ワイヤレスマイク収音）
- ロゴ・過去資料などのアセットも同じ親フォルダに集める

## Phase 1: 素材把握（AI）

- manifest生成: ffprobeで全素材の尺・解像度・fps・コーデック・作成時刻を一覧化
- whisper文字起こし → 引用候補抽出（発言テキスト・話者推定・強度評価・ASR破綻区間も記録）
- shotlog: Bロール候補、スタンドアウトモーメント、品質メモ（ブレ・白飛び・逆光）
- 使用不可素材の検出: 他者著作物の音声（現場のTV音声等）/ 回転メタデータ / 個人特定につながる言及

## Phase 2: 設計（AI×人間の対話。ここが作品の8割）

**先に決める5項目**: 尺 / 公開先（YouTube・SNS縦・上映）/ ナレーション有無 / タイトル / 背骨

**背骨（一本の問い）**: 全シーンが奉仕する一つの問いを立てる。奉仕しないカットは良絵でも切る。
NatGeo型の一体感を作る3装置:
1. コールドオープン — 核心の一言を冒頭に先出しし、本編で全文回収（エコー構造）
2. 境界を溶かす — 場面転換は音先行（Jカット）、状況テロップは最小限
3. BGM組曲運用 — 1〜2曲のバリエーション（Full/No Drums/Ambient）で全編を貫く。章ごとに曲を替えない

**インタビュー = Qブロック方式**
- 1質問 = 1連続音声。ブロック内のカット・無音詰め禁止（息継ぎ・言い淀みも残す）
- 映像はBロールで逃がすが、話者の顔を各ブロック最低1回見せる（言葉の責任の所在）
- 感情曲線: つかみ → 蓄積（かわいい/楽しい）→ 転調 → 重さ → クライマックス → 希望 → 着地

**尺配分表 + 伸縮ゾーン**: 目標尺のほか、短縮版・延長版の「削る順・足す順」を設計段階で決めておく

**倫理ルール（設計段階で確定）**
- 裏取り不能な数字（金額等）は字幕・テロップに出さない（音声はそのままで可）
- 個人特定につながる語り（家族構成・病名・未成年関連）は音声ごと不採用
- センシティブ要素の採否の最終判断は取材先に委ねる（試写を工程に組み込む）

## Phase 3: 検証（設計を紙で終わらせない）

- 尺配分の合計検算 / 全タイムコードがクリップ実尺内に収まるか照合
- 引用は該当区間の音声を再検証してから字幕確定 / 禁止素材をリスト化してプロンプトに引き継ぐ

## Phase 4: CC実行プロンプト化

- **モデル分離**: 司令塔（上位モデル）= 読解・指令・検収のみ。実行 = sonnet/haiku基本、複雑な実装のみopus（使用量節約）
- **トラック規律**: カメラごとに映像・音声トラックを分離、BGMは必ず独立トラック（後から手直し可能に）
- 字幕はSRTでサブタイトルトラックへ（焼き込み禁止）
- 人間チェックポイントを明示（CCが止まって待つ場所）: ラジオエディット試聴 / BGM配置 / 試写
- 検収チェックリストをプロンプトに内蔵: 尺 / 禁止素材未使用 / Q音声無編集 / トラック規律 / -14 LUFS
- 編集ソフトはDaVinci Resolve推奨（Python APIが自動化向き。外部スクリプティングはStudio版。無償版はXML生成→手動読み込みで代替）

## Phase 5: 編集実行・仕上げ

- **ラジオエディット先行**: 音声だけ先に並べて通しで聴き、耳で構成判断。OKまで映像に進まない
- 重い話の連続には5〜10秒の「無言の呼吸カット」を挟む（視聴維持率対策）
- テロップ規格（書体・サイズ・位置・表示秒数）は最初の1枚で固定し全編機械的に統一
- カメラ間同期は波形同期。内部時計・タイムコードを信じない（機種間で数分ズレる）
- 仕上げ: -14 LUFS整音 / チャプター / サムネ（サムネ=感情、タイトル=情報で役割分担）/ 説明欄に取材先リンク
- 公開フロー: メンバー試写 → 取材先試写（センシティブ要素の採否確認込み）→ 修正 → 公開
