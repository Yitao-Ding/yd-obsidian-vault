# エンドロール カード切り抜き位置 (pos) 決定ワークフロー

プペル エンドロール (2026-08) で確立した、540x380カード素材の切り抜き位置を機械的に決める手順。

## 仕様前提

- カードサイズ: 540x380 (aspect 1.42)
- 素材は写真 (jpeg/jpg) と動画 (mov/mp4) が混在
- pos は `"50% Y%"` 形式で media.json に書く
- 動画は in 点から 2.4秒間が表示される (1枠10.2秒・1点2.4秒制約)

## ワークフロー概要

1. スロット別に並列エージェントを起動 (wf_pos_qc.js)
2. 各エージェントがフレームを抽出→PIL/imageio で実解像度・EXIF を確認→Y% を変えながらシミュレーション
3. verdict (good / acceptable / replaced) + reason を返す
4. 結果を apply_selects.py で media.json に反映
5. Remotion でフルレンダー → extract_timeline.py でフレーム抽出 → wf_render_qc.js で全枠目視検証

## ✅ うまく行ったこと

- 19スロット並列エージェント (wf_pos_qc.js) はエラー0で完走 (約8分)
- 切り抜きシミュレーションが「天井/床だけの帯が残るか」を的確に判定できた
- 写真と動画で同一フォーマットの verdict 出力にしたことで apply_selects.py の処理が統一できた
- 横長素材 (1280x720 等) は縦方向のクロップが発生しないため pos Y%=50% で全件確定できた

## ❌ 詰まったこと

### 1. EXIF orientation vs sips ピクセル値の乖離

`sips -g pixelWidth -g pixelHeight` はEXIF回転を **反映しない** 生ピクセルを返す。  
例: IMG_1316.jpeg → sips: 5712x4284 (横に見える) → EXIF orientation=6 で実表示は 4284x5712 (縦)。

**影響**: 横長判定で縦位置調整をスキップすると後列の顔が切れる。  
**対処**: PIL `Image.open()` + `ImageOps.exif_transpose()` で実寸を取得してから縦横を判定する。

### 2. card_crop.py の「縦長素材」誤検知

4:3素材 (1477x1108 や 4032x3024) をカード比 1.42 と比較すると縦長フラグが立つ。  
実際の上下クロップは 69px (= 高さの6%) だけで、pos Y% の効きは小さい。  
card_crop.py の警告表示は当てにならない。実際にシミュレーションして確認する。

### 3. 解像度不足素材

IMG_3061.jpeg: 1108x1477 → 切り抜き後の実画素 1108x780。  
540x380 カードの2x Retina表示 (1080x760) にギリギリ。拡大演出があると甘くなる。  
1100px未満の短辺素材は代替候補があれば差し替えを検討。

### 4. in 点の末尾ブレ問題

動画の in 点を指定する時、`in + 2.4秒後` の絵も必ず確認する。  
終端でカメラが振れて被写体が外れるケースがあった:

| ファイル | 旧 in | 新 in | 理由 |
|---|---|---|---|
| line_363701787804069.mp4 | 16.7s | 16.5s | 19.1秒でカメラ振り→顔が左端から外れる |
| 807374508.037843.mp4 | 7.0s | 6.6s | 9.4秒でパン→左2/3が空壁になる |
| IMG_1511.mov | 4.4s | 4.3s | 6.8秒でメインの子が頭を下げる |

## 📋 次回同じことをするときのチェックリスト

- [ ] 素材の実寸は `PIL + ImageOps.exif_transpose()` で取得 (sips NG)
- [ ] 横長判定: aspect < 1.42 なら縦調整不要 (左右中央トリミングのみ)
- [ ] 縦素材の Y% シミュレーション: ±10%ずつ動かして「天井帯なし・顔フル・床帯なし」の3条件が満たせる range を探す
- [ ] 動画は in点 + 0.3 / 1.2 / 2.1 秒の3点でフレームを確認 (0.3秒ずれで安心)
- [ ] in + 2.4秒後の絵も必ず確認 (終端ブレが多い)
- [ ] 短辺 1100px未満の写真は代替候補を探す
- [ ] 横長素材は pos="50% 50%" 固定・縦調整は不要と明示してエージェントに伝える
- [ ] apply_selects.py 実行後、media.json の pos 付き件数を確認して漏れがないか検証
