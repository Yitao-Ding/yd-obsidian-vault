# 映像・音声 シビアレビュー標準 (自動適用ルール)

> **適用条件**: 「セレクトして」「粗編して」「カット編集して」「素材見て」「ダイジェスト/MV/メイキング作って」等、
> 映像素材の中身の判断を含むタスク全般。YDが明示的に「ざっくりでいい」と言った場合のみ簡易モードに落とす。

## 映像: 2パス方式で必ず「実際に見る」

### 1st パス: 全クリップ粗スキャン
- ffmpeg でコンタクトシート生成 (5秒間隔目安、4x3グリッド) → 画像として全数を目視
- タグ付け: シーン種別 / 候補パート / rank / 要人間確認フラグ → CSVに逐次追記

### 2nd パス: 候補クリップの精査 (ダンス・パフォーマンス系は必須)
- rank上位・使用予定クリップは **1秒間隔以下の連番フレーム** (必要なら1fps〜4fps静止画) で再抽出して見る
- 見るべきポイント:
  - **動きのピーク**: ジャンプ頂点 / フォーメーション変化 / シンクロの揃い / 決めポーズ → in/out はフレーム単位で指定
  - **ブレ・フォーカス**: 等倍クロップで甘カット除外 (望遠素材は特に)
  - **表情**: 目線・口元まで確認 (スロー候補は表情が命)
  - **照明変化**: 暗転→点灯の正確な瞬間
- ダンスは「カットのどこを使うか」で価値が10倍変わる前提で、ベスト区間を±0.5秒精度で記録

## 音声: 3点セット

1. **エネルギー解析**: RMS 1秒窓 + ピーク → 盛り上がりカーブをクリップ毎に記録
2. **ビート/オンセット検出**: librosa (or aubio) でBPM・ビート位置・ドロップ/サビ入りを検出 → ビート同期カットの基準に
3. **文字起こし**: 会話・MC・インタビューは whisper (mlx-whisper large-v3-turbo / 日本語) で全文。使える発言は引用で記録

## 成果物の形式

- `selects.csv` (逐次追記): file / シーン種別 / 内容メモ / 候補パート / ベスト区間 / rank / 要確認
- `shotlist.md`: パート順に クリップ / in-out (±0.5秒精度) / 尺 / **選定理由 (見た内容を具体的に)**
- 必須素材チェックリストとの突合結果 (見つからなかった物は代替案)

## 進行ルール

- 最初の10クリップの判定を先にYDに見せて精度OKを取ってから全数実行
- コンテキスト対策: バッチ処理 + 逐次保存 + 必要ならサブエージェント分担
- 判定不能は「要人間確認」で止まらず先へ
