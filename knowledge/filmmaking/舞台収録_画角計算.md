# 舞台収録の画角計算 (FX30 基準)

## 基本式

```
必要焦点距離 f = センサー幅 × 被写体面までの距離 ÷ 画面に写したい幅
```

FX30 の実効センサー幅 (水平):

| モード | 実効幅 | 備考 |
|--------|--------|------|
| 4K 24/30/60p | 約 22.4mm | APS-C 23.3mm を 6K クロップ (1.04x) してオーバーサンプリング |
| 4K 120p | 約 14.4mm | 1.62x クロップ読み出し。同じレンズで大きく寄る |
| フルサイズ換算 | 約 1.6 倍 | 36 ÷ 22.4 |

4K 通常時: `f = 22.4 × D ÷ W`

## 久喜総合文化会館 大ホール (2026-08-27 一次資料で確認)

舞台 (hall_big ページ + big_hall_heimen.pdf):
プロセニアム間口 18m / 奥行 15m / 高さ 9m (約5間) / 袖幕最小間口 14m / 奥の間口 13m /
舞台前〜正反 10m80、緞帳〜正反 9m / スノコ 20.8m / バトン飛切り 18m・長さ20m・300kgまで /
図面グリッド 1マス = 1.83m (1間) / 舞台前端は中央が客席側へ弧を描いて張り出す (エプロン、図中「C」)

客席 (big_hall_zaseki.pdf を画像化して実見):
- **1階席のみ。2階席・バルコニーは無い**
- 全29列。1〜9列と10〜29列の間に横通路 (クロスアイル) が1本
- 1〜9列 = 3ブロック (左7-18 / 中央19-30 / 右31-42)、前方ほど台形に狭くなる
- 10〜29列 = 5ブロック (外左1-6 / 左7-18 / 中央19-30 / 右31-42 / 外右43-48)、1列48席
- 縦通路は10列以降4本。**センター通路は無い** (中央ブロックが真ん中)
- 車椅子席は10列の左右端 (計4席)、総席数1,218席 (普通1,214 + 車椅子4)
- 客席後方に調光室・音響室は無い (両室とも舞台の袖側)

寸法は公開資料に無いため距離は推定。座席幅0.49m×48席+通路4本から客席幅約28m、
それを基準に座席表の縦横比で列ピッチ約0.95〜1.0mと読める。

- 29列 (最後列) → 舞台前端 約 28〜31m
- 29列 → プロセニアム面 (間口18mの面。エプロン先端より1.5〜2m奥) 約 30〜33m
- 最後列後方の通路 → プロセニアム面 約 32〜34m

## 焦点距離早見表 (FX30 4K、写したい幅別)

| プロセニアム面までの距離 | 18m幅 (開口ぴったり) | 20m幅 (開口+余白) | 24m幅 (花道込み想定) |
|---|---|---|---|
| 25m | 31mm | 28mm | 23mm |
| 30m | 37mm | 34mm | 28mm |
| 33m | 41mm | 37mm | 31mm |
| 36m | 45mm | 40mm | 34mm |

客席後方からの「画面いっぱいに舞台」= **35〜40mm (S35)、フルサイズ換算 56〜64mm**。
4K120p を使う場合は同じ絵が 22〜25mm になる (1.62xクロップのため)。

## 花道を入れる場合

1階席しか無いホールなので、後方席からの俯角が浅いのが本質的な制約。

最後列床は1列目床より3〜4m上がる程度。三脚のレンズ高1.5mを足しても舞台面との差は約4m。
花道先端が横通路 (9-10列間) 付近まで来るとして、カメラからの水平距離は約20m。
俯角は atan(4/20) = **約11度**。この浅さでは花道上の演者の足元は前方客の頭に埋まり、
見えるのは上半身だけになる。

対策の優先順:
1. カメラ高を上げる (三脚を目一杯 + ハイハット/脚立でレンズ高2.2〜2.5m)。俯角13〜14度まで改善
2. 花道は2台目 (客席サイドの縦通路や花道脇) で寄りを押さえ、引きは全景に徹する
3. 4K収録 → 1080p納品なら、引き1台固定 (28mm前後) + 編集クロップで寄りを作る

垂直画角の目安: 花道先端 (俯角11度) 〜 プロセニアム上端 (仰角9度) = 約21度 → 34mm相当。
横は同時に約19mしか入らないので、余裕を見て28〜30mmに引くのが安全。

## ✅ うまく行ったこと

- ホール公式の `/download/` に舞台図面・座席表・照明・音響のPDFが揃っており一次情報が取れた
- 画像PDFで中身が読めない時、Mac側で `curl` + `sips -s format png` で画像化 → Desktop Commander の
  `read_multiple_files` で画像として読ませると中身が見える。**この手順で座席構成を実見できた**
- センサー実効幅を「4K読み出し時のクロップ後 (22.4mm)」で計算したので実写とのズレが出ない

## ❌ 詰まったこと

- **2階席があると推定で書いてYDに指摘された (実際は1階のみ29列)。** 座席表PDFがテキスト抽出
  できなかった時点で「読めない」を「読まない」に変えてしまった。画像化して見れば5分で分かった
- 舞台図面PDFには客席寸法の記載が一切ない。カメラ〜舞台の距離はホール公開資料からは確定できない
- 「間口18m」だけでレンズを決めると、左右の余白・花道・エプロンの張り出しを見落とす

## 📋 次回同じことをするときのチェックリスト

1. ホール公式サイトの「ダウンロード」ページを最初に見る (舞台図面・座席表・照明・音響が揃う)
2. **PDFがテキスト抽出できなくても諦めない。`curl` → `sips -s format png -Z 2400` → 画像として読む**
3. 客席の階構成・列数は必ず座席表の実物で確認する。席数だけから階数を推測しない
4. 取れるのは舞台側の寸法だけと想定し、カメラ〜舞台の距離は下見でレーザー距離計実測を予定に入れる
5. FX30 のセンサー幅は 22.4mm で計算 (23.3mm ではない)。120p 併用なら 14.4mm で別途計算
6. 「写したい幅」は開口寸法ではなく、余白・花道・エプロンを足した実効幅で決める
7. 単焦点で決め打ちせず、必要焦点距離の1.3〜1.5倍のズーム幅を確保する
8. 1階席のみのホールで客席内の演出 (花道・客降り) を撮る時は、まずカメラ高を疑う
9. ムービングライトのLEDフリッカーはシャッター速度で現地確認する

## 追記 2026-08-27 (YDから図面PDF受領、レンズ確定)

### 備品リストの発見 (big_hall_bihin.pdf)

**「所作台(花道用) 1式」がホール備品にある。** つまりこのホールは花道を組む前提の備品を常備しており、
位置・幅・長さはホールに聞けば標準の答えが返る。歌舞伎様式なら下手 (客席から見て左) に組む。

関連在庫: 平台 6×6が6枚 / 4×6が27枚 / 3×6が30枚、所作台 909×3636×121 が36枚、
開き足 (高足/中足) 各サイズ、箱足40、振り落とし装置 L=18000、紗幕 W18000×H9000。
講演台・司会台・指揮台などの一般備品は No.2 に、客席側に使える脚立・タワーの記載は無い。

### 反響板時の図面 (heimen 2ページ目)

音響反射板を立てた状態の平面図。客席の断面・勾配の記載は無い (客席寸法は結局どの図面にも無い)。
舞台前端のエプロン (図中「C」の弧) はグリッド換算で中央の張り出し約1.2m、端は緞帳ラインとほぼ同じ。

### YD所有レンズ = Sony E 16-55mm F2.8 G (SEL1655G) で足りる

仕様: APS-C専用 / F2.8通し / 494g / フィルター67mm / 最短0.33m / 絞り9枚 /
**手ブレ補正なし・パワーズームなし (手動ズーム)**

距離33m (最後列後方→プロセニアム面) での写る幅:

| 焦点距離 | 写る幅 | 用途 |
|---|---|---|
| 16mm | 46m | 広すぎ。使わない |
| 24mm | 31m | 花道の根元〜先端まで全部入れる時 |
| 28mm | 26m | 花道込みの引き (実用域) |
| 35mm | 21m | 舞台いっぱい + 左右余白 ← 写真の絵 |
| 40mm | 18.5m | プロセニアム開口ぴったり |
| 55mm | 13.4m | 舞台中央2/3の寄り |

**必要域が16-55のど真ん中に収まる。16mm側は余る。**

花道の七三 (揚幕から7:舞台から3、花道の見せ場) は、花道長15m・下手6.5mと仮定すると
カメラから28.5m・横6.5m。35mm時の画面半幅は8.6mなので**七三は舞台いっぱいの構図のままでも画面内に入る**。
花道全景を入れるなら28〜30mm。

被写界深度: 40mm F2.8 距離33m → 過焦点距離30.1m、**15m〜∞にピント**。舞台奥行き15mを開放で全部カバー。
絞る必要がないのでISOを下げられる。

### この組み合わせの弱点 (3つ)

1. パワーズームでないので**録画中のズームは揺れる**。画角変更は演目の切れ目で。
   1カット内で「花道込み→舞台いっぱい」をやりたいなら 4K収録→1080p納品にして編集クロップ
2. OSS非搭載 → 三脚必須 (舞台収録では当然だが、手持ちのサブには使えない)
3. 55mmでも写る幅13.4m = **一人のバストアップは無理**。4K→1080pクロップで実質110mm相当・6.7m幅まで。
   本気の寄りが必要なら2台目に望遠が要る
