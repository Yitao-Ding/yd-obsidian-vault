# ビサヤ語 (セブアノ語) 撮影渡航フレーズブック — Tapul撮影 2026-09 仕様

> HTML納品版 (ダーク寒色) は 2026-08-16 のCoworkセッションでYDへ送付済み。本ファイルが正本。
> 設計思想: **馴染んでる証明は挨拶ではなく相槌で作る**。1日15分・音読主義・文法完璧主義は捨てる。

## 発音ルール3つ
1. ローマ字読みでほぼOK
2. アクセントは基本後ろから2音節目
3. ng は鼻音 (ンガ行)

## 4. 数字と金
- 1-10: usa / duha / tulo / upat / lima / unom / pito / walo / siyam / napulo
- Pila ni? (ピラ ニ?) = これいくら? — 金額はスペイン語系数字で返ることが多い (bente=20, singkwenta=50, syen=100)
- Mahal ra kaayo! (マハル ラ カアヨ) = 高すぎw / Barato ra = 安いね

## 5. 食事・生活
- Lami! (ラミ) = うまい! ★出された物を食べてこれ、が信頼構築の最短ルート
- Busog na ko = お腹いっぱい / Gutom na ko = 腹減った
- Init kaayo! = 暑すぎ! / Kapoy na! = 疲れたー
- Gwapa! / Gwapo! = 美人!/イケメン! (場和ませ鉄板)

## 6. 別れ・約束
- Amping! (アンピン) = 気をつけて → 返しは Ikaw sad (イカウ サッド) = 君もね
- Magkita ta usab = また会おう ★言ったら本当に来る、がGive and Take
- Salamat sa tanan = 全部ありがとう
