# 簿記3級の無料テキスト・講義の所在 (2026-08-27 調査)

税理士ルート ([[shikaku_shinro]] / 大学院での簿記論・財務諸表論) の入口として簿記3級の
無料テキストを探した結果。結論: TAC ではなく CPAラーニング。

## 本命: CPAラーニング (CPA会計学院)

- URL: https://www.cpa-learning.com/
- 費用: 完全無料。メールアドレス登録のみ
- テキスト: 市販の『いちばんわかる日商簿記3級の教科書』(CPA出版) と同内容の PDF を
  講座ページの「教材」からダウンロード
- 問題集 PDF、講義動画 23回 (約15時間51分)、ネット試験対策 15回 (約7時間7分)、模擬試験も無料
- 3級だけでなく 2級・1級 まで同じ条件で無料。簿記論・財務諸表論の下地として1級まで
  無料で行けるのが税理士ルート的に一番大きい

## TAC が無料で出しているもの (テキスト本体ではない)

- 解答用紙ダウンロード — 誰でも可。答案用紙のみ。https://bookstore.tac-school.co.jp/answer
- 書籍連動ダウンロードサービス — 書籍記載のパスワードが必要 (購入者限定)。
  Web解説講義・音声・スマホ学習用PDF(要点抜粋)・模試プログラムのみで、テキスト本体PDFは無し
- 3級のサンプル問題ページ — 一部の過去問と解説のみ

つまり「TACで無料テキストをダウンロードできた」は CPAラーニングとの記憶違いの可能性が高い。

## ✅ うまく行ったこと

- 「TAC 無料 テキスト PDF」で検索した時点で、上位に CPAラーニング関連記事が混ざって出た。
  資格予備校の無料教材を探すときは校名で絞らず「簿記3級 無料 テキスト PDF」で広く引くほうが早い
- TAC出版のダウンロードサービス規約ページを直接読んで「購入者限定・本体PDFなし」を確定できた

## ❌ 詰まったこと

- cpa-learning.com の講座ページは JS レンダリングのため WebFetch で本文が取れない。
  中身の確認は解説ブログや商工会議所 (kentei.ne.jp) の紹介ページ経由で行った
- 「無料テキスト」を謳う記事の一部は、CPAラーニングの登録ではなく
  「公認会計士講座の資料請求」への誘導 (アフィリエイト) だった。導線を混同しないこと

## 📋 次回同じことをするときのチェックリスト

1. 予備校名で絞らず「<資格名> 無料 テキスト PDF」で検索する
2. 公式サイトが SPA で読めない場合は、商工会議所など一次に近い紹介ページを当たる
3. 「資料請求で無料」系はアフィリエイト導線。会員登録だけで済むルートがないか先に確認する
4. ダウンロード前に版数 (第2版など) と最新の出題区分への対応を確認する
5. TAC出版の「ダウンロードサービス」は購入者限定なので、無料狙いなら最初から除外してよい
