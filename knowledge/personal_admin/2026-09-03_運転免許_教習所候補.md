# 運転免許 (普通AT・学割・通い) 教習所候補 2026-09-03

条件: 関東圏・通学・AT限定・学割必須。拠点は勝どき / 東洋大白山 / ヨドバシAkiba。
中央区・江東区・台東区・文京区に教習所なし。

- 第一候補: 北豊島園自動車学校 (練馬区、大江戸線 練馬春日町 徒歩7分、勝どきから1本約40分)。学割AT 300,780円 (一般325,296円)。免許の窓口 東洋大コース 304,150円 (毎月10名)
- 次点: 王子自動車学校 (北区、JR王子 徒歩10分、白山から南北線約10分)。生協経由AT 337,480円 (割引29,480円)、免許の窓口 赤羽店限定 343,200円。直申込は学割なし (371,800〜405,900円) なので必ず窓口経由
- 平和橋自動車教習所 (葛飾、京成立石)。学生332,190円、学割5,000円のみ。押上・北千住送迎
- 除外: 日の丸 (2027-03 閉校、受付終了) / 尾久自動車学校 (実は小金井) / 埼玉とだ・川口 (遠い)

申込ルート: 東洋大「免許の窓口」(イトーヨーカドー赤羽店4F、火木土日 13:00-18:30、0120-883-147) か大学生協通学免許。
未確認: 年齢 (26歳以下で安心パック+11,000円)、二輪免許有無、取得期限、生協組合員か、予算上限。

## 追記: 北豊島園 らくらく優先予約コース
- 段階ごとに2か月先まで一括予約 (教習所がスケジュール作成)。卒業目安60日〜。技能延長・検定再受験が卒業まで無料 (安心パック相当込み)
- 料金: 免許の窓口 学生 368,500円 / 東洋大限定コース 304,150円 (毎月10名) / 一般 41〜42万
- 送迎: 池袋・ときわ台・成増・高田馬場・お茶の水方面
- 判断: 北豊島園にするなら東洋大限定のらくらく優先一択。申込は月初に赤羽窓口へ電話で枠確認 (0120-883-147)

## 追記: 失敗しても追加料金なし (保証込み比較)
- YD は「ミスりまくっても無料で受けられる」保証を重視
- 北豊島園 東洋大限定らくらく優先 304,150円: 技能延長・検定再受験が卒業まで無料 (込み)
- 池上 295,020円 + 安心パック16,500円 = 311,520円 (技能・検定・効果測定の失敗無料。予約は自力、スピードプランは+44,000円)
- ソフィア船橋 定額保証 22歳以下 291,720円 / 23〜29歳 304,920円
- 保証込みで比べると3校ほぼ横並び。推奨は北豊島園 (予約が楽・送迎広い)、近さ重視なら船橋
