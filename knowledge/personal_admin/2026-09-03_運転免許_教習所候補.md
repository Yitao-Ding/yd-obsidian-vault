# 運転免許 (普通AT・学割・通い) 教習所候補 2026-09-03

条件: 関東圏・通学・AT限定・学割必須。拠点は勝どき / 東洋大白山 / ヨドバシAkiba。
中央区・江東区・台東区・文京区に教習所なし。

- 第一候補: 北豊島園自動車学校 (練馬区、大江戸線 練馬春日町 徒歩7分、勝どきから1本約40分)。学割AT 300,780円 (一般325,296円)。免許の窓口 東洋大コース 304,150円 (毎月10名)
- 次点: 王子自動車学校 (北区、JR王子 徒歩10分、白山から南北線約10分)。生協経由AT 337,480円 (割引29,480円)、免許の窓口 赤羽店限定 343,200円。直申込は学割なし (371,800〜405,900円) なので必ず窓口経由
- 平和橋自動車教習所 (葛飾、京成立石)。学生332,190円、学割5,000円のみ。押上・北千住送迎
- 除外: 日の丸 (2027-03 閉校、受付終了) / 尾久自動車学校 (実は小金井) / 埼玉とだ・川口 (遠い)

申込ルート: 東洋大「免許の窓口」(イトーヨーカドー赤羽店4F、火木土日 13:00-18:30、0120-883-147) か大学生協通学免許。
