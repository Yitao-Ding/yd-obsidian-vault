# 通称を日本で使う — 名乗りと住民票記載の切り分け

## 結論

「名乗る」と「住民票に載せる」は別物。名乗るだけなら手続きは一切要らない。
大学・職場・SNS で好きな名前を使うのは各組織の裁量であって、役所は関係ない。

住民票の通称記載は名前を作る制度ではなく、**すでに社会生活上通用している呼称と本人を
結びつける事実の公証**。だから「これから使う名前」では登録できない。順序は
「先に名乗る → 実績を作る → 役所」。

## 制度の要点 (2026-09 時点)

- 根拠: 住民基本台帳法 (2012-07-09 外国人登録法廃止に伴い外国人住民も住基台帳の対象)
- 通称は**住民票には記載されるが、在留カード・特別永住者証明書には記載されない**
- 使える文字は日本人が戸籍に記載できる平仮名・片仮名・漢字のみ。アルファベット・
  ハングル・記号は不可 → 「韜」は常用漢字にも人名用漢字にも無いため通称に使えない可能性が高い (要窓口確認)
- 記載には「国内において社会生活上通用していることが分かる資料」の提示が必要。
  自治体によっては2点必要 (柏市・志木市の例): A区分 = 勤務先や学校発行の身分証 (社員証・学生証)、
  官公署発行の資格証明書。B区分 = 郵便物・診察券・通帳等。**B2点では不可、A2点かA1+B1**
- 職権削除あり: 居住関係の公証に必要と認められなくなれば市区町村長が削除し本人に通知
- 通称の記載・削除の履歴は住民票の「通称の記載及び削除に関する事項」に残る
- マイナンバーカードには併記可能。銀行口座・クレカ・賃貸契約を通称でやるなら住民票記載が要る

## YD の場合の具体ルート

1. 東洋大に通称での学生証発行が可能か学務に確認 (規程の有無)
2. Apple の在職証明・社員証を通称で取得 — **契約終了が決まっているので在職中が期限**
3. この2点が揃えばA区分2点になる → 中央区役所 区民生活課住民記録係へ
4. 事前に候補の漢字を電話で伝えて可否だけ確認しておく

帰化すれば戸籍の氏名そのものを変えられるが、要件も所要期間も別物。
税理士登録 ([[shikaku-shinro]] 参照) を見据えるなら比較対象に入る。

## 📋 次回同じことをするときのチェックリスト

- まず目的を聞く。呼ばれ方を変えたいだけか、銀行口座・契約書類まで統一したいか。前者なら役所は不要
- 自治体ごとに必要資料の点数・区分が違う。居住自治体 (中央区) のページを直接見る
- 使いたい漢字が人名用漢字に入っているかを先に潰す。ここで弾かれると全部やり直し
- 一度削除した通称の再記載は制限される自治体があるので、名前は一発で決める
- 就活と絡めない。ES・入社書類は在留カードの氏名で出す方が整合する

## 追記 (2026-09-06) — 調査で確定した事項

- **「韜」は通称に使えない (確定)**: 名に使える漢字は常用漢字2136字+人名用漢字864字の計3000字。韜は韋部20画・漢検1級・JIS第2水準で、どちらにも入っていない。通称を登録する = 公証される日本での名前から「韜」が消える
- **通称が載る範囲**: 住民票・印鑑登録証明書・マイナンバーカード・役所からの送付物の宛名。在留カードと特別永住者証明書には載らない
- **運転免許証には併記できる**: 通称記載の住民票 (マイナンバーなし) + 在留カードを持って警察署か試験場へ。取得時・更新時・記載事項変更時に手続き。[[driving-license]] があるので、登録するなら免許取得**前**に済ませると一発で併記できる
- **同一発行者の書類は2点にならない** (朝霞市が明記): Apple の社員証と在職証明書を両方もらってもA区分1点扱いの可能性が高い。A2点を狙うなら「大学の学生証 + Apple の在職証明」の組み合わせ
- **「これから使用する、使用実績の乏しい呼称は登録できない」** (毛呂山町が明記)
- 職権削除あり。記載・削除の履歴は住民票に残る
- 中央区は通称の専用ページが公式サイトに見当たらない → 区民生活課住民記録係に電話確認が必要

## 名前の選択肢と推奨 (2026-09-06)

- A. 音を残して字だけ替える (丁 一斗 など) — 呼ばれ方が変わらない。本名との差が一字なので窓口判断を要確認
- B. 姓ごと日本式にする — Yitao Film・Salamat・三言語という自己紹介の組み立てとぶつかる。失うものが多い
- C. 登録しない (名乗りだけ) — 「韜」を残せる。免許・口座・契約は本名のまま二重運用

**推奨: 今は C。判断は Apple 退職前に一度だけ。**ただし在職証明書は契約終了後に取れなくなるので、A に進む可能性を残すなら在職中に確保しておく (取って使わないコストはゼロ、取り損ねると復元不能)。

## 再調査 (2026-09-06、YD「ちゃんと調べて」を受けて)

前回の追記は自治体案内の孤立した記述の寄せ集めだった。条文・一次資料に当たり直した結果。

### 条文

住民基本台帳法施行令第30条の16 (外国人住民の通称の住民票への記載等)。
第1項の定義: 通称とは「氏名以外の呼称であつて、国内における社会生活上通用していることその他の
事由により居住関係の公証のために住民票に記載をすることが必要であると認められるもの」。
第2項: 必要と認められるとき市町村長は記載しなければならない (羈束)。
第4項: 本人が削除を申し出れば市町村長は削除しなければならない。
第5項: 公証のために必要と認められなくなったとき職権削除+本人通知。

### 一度きりのルール (今回いちばん重い発見)

- **変更は原則不可**。婚姻等の身分行為で相手方の氏・通称の氏に変えるときのみ申出可 (柏市・志木市)。
  北九州市「ひとたび社会生活上通用していると認められた通称について、削除を申し出ることはできますが、
  変更は原則として認められません」
- **削除後の再記載も原則不可** (三条市)。日本人の旧氏には「削除後に氏が変われば再記載可」の救済が
  あるが、通称には無い
- **氏名と通称は一体で記載**され、片方だけを省略した証明書は出せない (北九州市)。通称を付けた後に
  「本名だけの住民票」は取れない

### 韜は帰化でも使えない

帰化後の氏名も戸籍法施行規則60条 (常用漢字+人名用漢字別表+かな) の範囲。中国固有の漢字は不可。
つまり帰化は韜を残す抜け道にならない。**韜を残す道は「登録しない」の一択**。
(参考: 名の変更の正当事由に「通称として永年使用した」があり人名用漢字外を認めた裁判例もあるが、
不許可傾向が強く、帰化後の話なので現時点の選択肢に数えない)

### 税理士登録での扱い — 確定

日税連「税理士登録の手引」(令和7年6月) 登録申請書第1号様式の注2:
「氏名は住民票又は身分証明書に記載されている字画どおりに記入する。**通称名は本名の隣に括弧書きで
記入する**」。つまり通称は使えるが併記であって置換ではない。
外国籍者の登録は制度上想定済み: 欠格条項・登録拒否事由に国籍要件なし。身分(身元)証明書が発行
されないため誓約書を提出し、外国籍であることの確認として国籍記載の住民票の写し(原本)を提出する。
→ **通称の有無は税理士ルートの障害にならないが、メリットにもならない。士業観点では中立**

### 大学の運用は2型に割れる (鶏卵問題の実体)

- 学芸大型: 通称名を使えるのは「外国籍の学生が**住民票に記載されている**通称名を使用する場合」
  → 住民票が先。学生証はA区分資料に使えない
- 東大型: 住民票を要件にせず、学生証を無料で再発行し学籍データ・履修者名簿・学位記・証明書まで
  通称名を反映 (法令上法律上の氏名が必要なものを除く) → 学生証が先に取れる
- **東洋大がどちらかは公開資料では不明**。学芸大型ならA区分は Apple の1点のみになり、
  Apple 在職中の資料確保が死活的になる

### 追加で判明した実務

- 健康保険・厚生年金: 住民票に通称登録が無いと通称名での資格取得はできない。あれば通称名で作れる。
  給与支払報告書も通称名で提出可能。社内の呼び名だけなら手続き不要
- 中央区は公式サイトに通称の専用ページが**存在しない**。「外国人住民向け情報」配下は1ページのみで
  通称への言及なし。電話確認一択。区民生活課住民記録係 03-3546-5320 / 月島特別出張所区民係 03-3531-1153

### 推奨 (更新)

C (登録しない) を継続。判断は Apple 退職前に一度だけ。根拠が強まった: 通称は併記なので二重運用は
登録しても消えない、変更も再記載もできないので迷いがある状態で付けるのは制度と噛み合わない、
士業観点では中立、韜を手放すコストと釣り合わない。
ただし Apple の在職証明書と社員証のコピーは在職中に確保する (東洋大が学芸大型ならA区分唯一の資料)。
