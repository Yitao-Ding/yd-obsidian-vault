# Shorts (リール) 企画 — 2026-09 フィリピン

正本は Notion「Grow me:) 9月フィリピン計画 > To do > Shorts（リール）の構成」内の DB「Shorts 企画一覧」。

## 位置づけ (YD 決定 2026-09-15)

- 本編 NIBALIK KO とは別ライン。Shorts は単体で面白さを追求する。目的はアカウントとフィリピンのスラムそのものの認知、そのためのバズ
- 「〜してみた」の驚き文法は許容。ただし宗教ネタは削除 (CFA が教会系、10/1-3 の関係を守る)
- 各企画ページの書式: ひねり / フック (最初の2秒) / 展開 3ビート / オチ / 撮影リスト / 必要なもの / NG・注意。見出し色は 灰=前提、青=フック・展開、橙=オチ、緑=撮影リスト・必要なもの、赤=NG
- DB 列: ステータス (案/採用/ボツ/撮影済/公開)、都市、型 (検証/対決/挑戦/ギャップ/フォーマット)、フック、バズ期待、リスク、必要な協力、撮影候補日

## 採用 (7本)

日給300ペソで1日生活 (旧「1万円生活」、1万円=日給10日分で成立しないため変更) / パグパグ全種類制覇+日本アレンジ (2本を統合、作る側に回るのが差別化) / スラムのミシュラン店 vs 隣の家の同じ料理 (スーツ案は撤回) / カルボン市場の魚で人力回転寿司 / 日本のダンサー vs スラムのキッズ TikTok ダンス対決 (チームがダンサーなのが武器、最有力) / 1,000ペソを3人に渡して1日で誰が一番増やせるか / サリサリストア買い占め

## 案 (6本)

100均商品をサリサリで売る / My Way をスラムのビデオケで歌う / ゴミ山のプロに500ペソでコーデ / 同時刻スプリット (ゴミ山4時 vs 渋谷4時) / スラムで一番高い家 / 床屋でおまかせ50ペソ
