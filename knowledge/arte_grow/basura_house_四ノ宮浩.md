# バスーラの家 (四ノ宮浩監督のフィリピン支援拠点)

## 概要

- 四ノ宮浩監督 (オフィスフォープロダクション、八王子) が『BASURA バスーラ』(2009) 公開を機に呼びかけ、マニラ北部トンド地区アロマゴミ捨て場 (Pier 18, Barangay 105) に 2010 年春に建てた支援拠点
- 運営母体 = 監督の会社内「バスーラの家基金」(2007 設立、旧称「アジアの貧しい子供たちへのサポートプロジェクト」)。現地代表 クリスティーナ・パズ
- 活動 = 予防接種・妊婦検診・医薬品配布 / 給食 / 年2回の教育プログラム・日本語教育 + 日本の若者のボランティア宿泊所
- 支援 = 年会費 1口 10,000 円、毎月 1,000 円募金、ボランティア、年2回訪問ツアー、不用品送付。俳優 東出昌大がボランティア協力
- 作品: 『忘れられた子供たち スカベンジャー』(1995、スモーキーマウンテン) → 『神の子たち』(2001、パヤタス) → 『BASURA』(2009、14年後の追跡) → 『わすれない ふくしま』(2013)。2024-08 から3本を有料配信
- **鮮度**: 公式サイト最終更新 2011-05、ブログ最終 2012-01、寄付者リスト 2017-05 まで。会社サイトは 2024-08 更新で紹介は残る。現地が今も稼働しているかは Web では不明 → 事務局 042-646-0012 に直接確認が必要
- 混同注意: 同じゴミ山を撮り、銃撃を受けて自費で学校を建てた監督は **瓜生敏彦** (別人)
- 成果物: Cowork 出力 `basura_house_research.html` (2026-09-09)

## Arte Grow との関係

- 設計思想は「日本の寄付 + ボランティアで現地に届ける」型で、Arte Grow の Type B (Pride, not Dependency) の逆側
- 使える点: ①15年前に日本人が建てた拠点のその後 (継続条件・失敗要因) を聞く ②映画→上映会→寄付→拠点 という「映像を入口に支援の輪を作る」手法は「映像で伝える」軸にそのまま応用できる
- 場所はマニラ。9/21〜10/3 のセブ渡航とは別の島
