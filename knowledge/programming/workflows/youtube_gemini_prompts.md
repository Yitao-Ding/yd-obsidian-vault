# YouTube動画 → Gemini文書化 → Claude連携プロンプト集

## ワークフロー概要

ClaudeはYouTubeリンクを直接解析できない。代わりに:

1. YouTube埋め込みのGeminiに下記プロンプトを投げて動画を文書化させる
2. 出力をClaudeに貼り付けて、分析・再現・蓄積に使う

用途別に2本。共通の設計思想は「**要約させず、一次資料として書かせる**」。

## 運用Tips

- Geminiは放置すると数行の要約で済ませる。物足りなければ「セクション◯◯をさらに詳しく」と追撃する
- 1時間超の動画は「前半(〜30:00)だけ上記フォーマットで」と範囲を区切って複数回に分ける
- 出力が途切れたら「続き」と送る(プロンプト側に継続指示あり)

## ① 再現用プロンプト(技術・実践系)

用途: 技術系・実践系動画(例: Claudeでビジネスをやってみる系)を手順書化し、Claudeと一緒に同じことを再現する。

```
この動画の内容を、後で別のAIと一緒に「同じことを再現する」ための手順書として文書化してください。要約ではなく、再現に必要な情報の完全性を最優先してください。

# 動画情報
タイトル / チャンネル名 / 長さ / この動画が達成するゴール

# 前提条件
使用ツール・サービス・アカウント(有料プランか、料金への言及があれば記載)/ 前提スキル・事前準備

# 手順(最重要)
実際に行われた作業を、実行された順番通りにステップ化。各ステップについて:
- [タイムスタンプ] ステップ名
- 具体的な操作内容(どの画面で・何をクリックし・何を入力したか)
- 画面に表示されたプロンプト・コード・コマンド・設定値は、省略せず全文を書き起こす(【画面】と明記)
- そのステップの結果として何が起きたか

# 話者の判断とコツ
「なぜそうしたか」の理由、注意点、失敗談、代替案として言及されたもの

# 成果・数値
最終的にできたもの、かかった時間・費用、収益や成果の数値が出ていればすべて

# 再現時の不明点
動画内で省略・カットされていて、再現時に自分で調べる/決める必要がある箇所

制約:
- 出力は日本語(コード・プロンプト・コマンドは原文のまま)
- 長くなって構わない。網羅性優先
- 出力が上限で途切れそうなら「(続きあり)」と書いて止め、「続き」と送られたら残りを出力すること
```

**Claude側への渡し方**: 出力を貼って「この手順書で一緒に再現したい。まず前提条件の確認から」と添える。

## ② 構成研究用プロンプト(ドキュメンタリー・vlog系)

用途: 参考にしたい動画(NatGeo、旅系vlog等)の構成・演出を分解し、自分の動画制作の参考にする。

```
私は動画クリエイターです。この動画を自分の動画制作の参考にするため、内容と構成・演出を分析できる形で文書化してください。

# 動画情報
タイトル / チャンネル名 / 長さ / ジャンル / 想定視聴者

# 冒頭フック(0:00〜1:00)
最初の1分で何を見せ、何を言って視聴者を引き込んでいるか。セリフ・映像・テロップを具体的に

# 構成の設計図
動画全体をパート分けし、各パートについて:
- [開始タイムスタンプ] パート名と尺
- 語られる内容・起きる出来事
- 映像面: どんな映像か(実景、インタビュー、Bロール、地図、資料映像など)、印象的なカットや構図
- 演出面: BGM・効果音の変化、テロップの使い方、ナレーションと現場音の切り替え

# 視聴維持の仕掛け
先の展開の予告、疑問の提示と回収、場面転換のテンポなど、離脱させない工夫をタイムスタンプ付きで

# ストーリーテリング
何が問題・目的として提示され、どう展開し、どう着地するか。感情の起伏がどこで作られているか

# ナレーション・話し方
一人称か三人称か、口調、テンポ、印象的な言い回しの引用(タイムスタンプ付き)

# 締めとCTA
終わらせ方、チャンネル登録や次の動画への誘導方法

制約:
- 出力は日本語。長くなって構わない
- 出力が上限で途切れそうなら「(続きあり)」と書いて止め、「続き」と送られたら残りを出力すること
```

**Claude側への渡し方**: 出力は [[knowledge/filmmaking/video_structure_study/index|動画構成研究フォルダ]] に1動画=1ノートで保存し、数本貯めて横断分析する。
