# セッション引き継ぎ・「キリのいいところで終了」モード運用テンプレ

> **背景**: 2026-05-26 の Project Agent Application 開発セッション (深夜→朝のフルスプリント) で、YD が「キリのいいところで終了して新ターミナルに移行したい」と指示。だが Claude が「自立ループ運用ルール」に従って builder 完了 → 即 design-evaluator 新規起動してしまい、YD「なんか新しいの立ち上がってない?」と気づかれる事案発生。
> 
> **教訓**: YD の「終了モード」発動時は **新規 Agent 起動禁止** が「自立ループ運用ルール」より優先される。本テンプレで明文化。

## 🚨 トリガー語彙 (これらを検出したら即「終了モード」発動)

### 直接的トリガー
- 「キリのいいところで終了」「キリよく終わろう」
- 「全部丸ごと新ターミナルに移行」「新ターミナルに切り替えたい」
- 「セッション切替」「セッション保存」
- 「一旦保存」「ここで区切る」「終わりにしよう」

### 間接的シグナル (組み合わせで判断)
- 「コンテキストが多くなってきた」「長くなってきた」
- 「ちょっと休憩」「一回まとめて」
- 「もうここでいい」「いったん止めよう」
- 朝 / 深夜 / 長時間セッションの末尾で出る曖昧な「終わりたい」感

## ⛔ モード中の動作ルール

### 絶対 NG (禁止事項)

- **新規 Agent 起動禁止** (自立ループ運用ルールより優先する)
- **YD が選択肢として明示提示してきた場合のみ例外** (例: 「A. 新規 Agent 起動」を YD が選んだ場合)
- **新規仕様変更 / 複雑な意思決定**を提示 (シンプルな確認 OK だが、判断を要求するのは禁止)
- **走り中 Agent の強制中断** (情報失う、自然完了を待つ)

### MUST (必須事項)

- 既存 BG Agent の **自然完了を待つ** (orchestrator は中継せず待機)
- 完了 Agent の **結果保存** (EVAL_*.md / IMPLEMENTATION_NOTES.md / decisions 等)
- **HANDOVER.md / active_projects.md / log.md を最新化**
- 走り中 Agent の **agent ID + output file path を引き継ぎドキュメントに明記** (新セッションで完了通知を受け取れるように)
- YD への報告は **「移行 OK の状態」** を明示

### OK (条件付き)

- SendMessage で走り中 Agent に「キリよく要約して終了」指示 (走り時間長い場合)
- 終了モード中の軽い確認質問 (YD への選択肢提示は問題なし)
- 既に走り中の Agent が連鎖完了通知を返す場合の受け取り + 保存 (新規起動でなければ OK)

## 🔍 走り中 Agent の処理判断

| 残り時間推定 | 推奨アクション | 注意点 |
|---|---|---|
| 5 分以下 (完了寸前) | 自然完了を待つ | YD への報告で「あと N 分で完了予想」と明示 |
| 5-15 分 | YD に「待つ?中断?」確認 or 自然完了 | YD のテンション次第 |
| 15 分超 (序盤) | SendMessage で「現状の要約で結果保存して終了」を依頼 | 不完全な評価になるリスクあり、YD と相談 |

## 📋 引き継ぎ完了チェックリスト

  - [ ] 走り中 Agent の ID + output file path 明記
  - [ ] 完了 Agent の結果サマリ
  - [ ] 次セッション起動時の Read リスト
  - [ ] Pass / Fail それぞれの次アクション (Decision Tree)
- [ ] **Vault `current_state/active_projects.md`** の該当プロジェクト最新進捗反映
- [ ] **Vault `log.md`** に 1 行追記
- [ ] 必要なら **`decisions/`** に意思決定記録 (大きい判断があった場合)

## 🌅 セッション切替後の動き (新セッションの Claude へ)

新セッションで Claude が起動した時:

1. グローバル `~/.claude/CLAUDE.md` の起動シーケンスを実行
2. Vault `current_state/active_projects.md` で「★ HANDOVER.md Read」指示を確認
3. プロジェクト直下 (or 指定パス) の `HANDOVER.md` を Read
4. HANDOVER.md の Step 1-4 を順に実行
5. YD への初手応答テンプレに従って報告
6. 自立ループ運用ルールに従って continue (新規 Agent 起動含む、終了モードは旧セッションでのみ有効)
