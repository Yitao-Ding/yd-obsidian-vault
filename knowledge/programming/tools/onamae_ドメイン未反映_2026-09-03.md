# お名前.com: 完了画面まで出たのにドメインが登録されない (2026-09-03)

ハタチたちHPのドメイン取得で発生。決済完了の画面が出たのに、ドメインが存在しない状態。
問い合わせのときにこのファイルの事実だけ伝えれば通る。

## 確認した事実

1. **カート完了画面は出ている**。お名前ID 20382623 でログイン中、`hatachitachi.com` / `studiometali.com` の2件が「受付完了」、合計1,894円、「ご指定のクレジットカード決済が完了しました」と表示。URL は `cart.onamae.com/register/complete`
2. **Navi のドメイン一覧が空**。`navi.onamae.com/domain` のドメイン表にヘッダー行だけあって中身なし。ページのHTMLに `hatachitachi` も `studiometali` も出てこない
3. **確認メールが1通も来ていない**。save.yitao@gmail.com (= このお名前IDの登録アドレス。同日14:57のログイン通知メールが同アドレス宛に届いていることで確認) に、注文受付・請求明細・ドメイン情報認証のいずれも未着。迷惑メール・ゴミ箱も含めて検索済
4. **レジストリに存在しない**。Verisign の RDAP (`rdap.verisign.com/com/v1/domain/<domain>`) が両方とも 404。購入から1時間半後、複数回確認。DNSも引けない。他TLD (net/org/jp/info/site/studio/work/tokyo/me/xyz) も全滅なので、綴り違いで取れているわけでもない

つまり「決済は通ったが登録処理が実行されていない」。GMOの審査待ちで保留されているか、登録が失敗して返金待ちのどちらか。

## やること

- カード明細に GMOインターネット からの1,894円が立っているか確認する
- お名前.comに問い合わせる。電話が最速。「完了画面で決済完了と出たがドメイン一覧に反映されず、確認メールも届かない」と伝える
- **再購入しない**。二重課金になる
- 完了画面のタブは証拠なので閉じない

## 教訓

お名前.comの「受付完了」は登録完了ではない。RDAPに出て初めて取れたと判断すること。
完了画面のスクリーンショットか本文テキストを必ず残す。
