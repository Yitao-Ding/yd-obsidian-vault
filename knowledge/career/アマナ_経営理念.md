# 株式会社アマナ 経営理念

> 求人票の人物像の筆頭が「理念へ共感された方」。その理念の中身を一次情報から確定させたもの (2026-09-09 調査)。

## 経営理念は3階建て (amana.jp/company/)

| 層 | 言葉 | 中身 |
|---|---|---|
| 目指すこと | **世界にノイズと美意識を** | 人の創造力という可能性を拡張し、社会の感性を豊かにすること |
| 提供すること | **伝わり、動かすコミュニケーションデザイン** | 企業や社会の本質的な価値や課題を見出してビジュアライズすることで、「届けたい想いが伝わり、行動を促す」コミュニケーションを創ること |
| 大切なこと | **人が中心「感性・集合・進化」** | 人の「感性・集合・進化」こそが創造の源であり、すべての提供価値のコア |

## 理念本文 (amana.jp/about/ 原文)

> 新たな問いを生む「ノイズ」が常識を覆し、人の感性を豊かにする多様な「美意識」が、未来を切り開くとアマナは信じています。人の創造力という可能性を拡張し、社会の感性を豊かにすること。それがアマナが目指す姿です。

## ノイズと美意識の定義 (取締役 石亀幸大)

- **ノイズ** = 刺激や気づきを与えて課題の提起を促すもの
- **美意識** = その課題に対して、期待を超えた解決をめざす姿勢
- この2つの感性が「伝わり、動かす」の源泉
- 石亀: 「素晴らしいビジュアルを生み出すだけでは、クライアント企業の利益を最大限に引き出すことはできません。広告においては、その先に人を『動かす』ことも重要」

## 経営陣の言い方

- 社長 **金子剛章 (かねこ・よしあき)**: 「世界にノイズと美意識という人間が持っている創造性を拡張する」。AIは「アシスタント」= 人間の創造性を補完するスーパーパートナー。これからのクリエイティブの核は編集能力と「ノイズ設計」(違和感・意外性)
- 創業者 進藤博信: 「"流れ"と捉える。時代の空気を掴んで、溜まらずに動き続ける組織」(Great RIVER構想) / 「世の中の役に立ち続けるというのが大事。だからゴールはないんですよ」/ 「クライアントからありがとうって言われることをゴールにすればいい」
- AIサービス名の "GreatRIVER AI STUDIO" はこの Great RIVER構想から来ている

## 理念と人物像リストの対応

求人票の人物像は理念の言い換えになっている。

- 「理念へ共感された方」 → ノイズと美意識
- 「人との関わりを大切にし、チームでの創造を楽しめる方」 → 「人が中心」の**集合**
- 「枠に捉われず新しいことに挑戦する / 変化や挑戦を前向きに / 新しいことにワクワク」 → **進化**、およびノイズ (常識を覆す)
- 「自分の感性を磨き続けたい / 自分なりの『好き』『こだわり』がある」 → **感性**、および美意識

## 実務上の読み方

理念の重心は「美しいものを作る」ではなく「違和感を仕込んで人を動かす」。ビジュアルの完成度で完結する話をすると理念とズレる。作ったものが相手の行動をどう変えたかまで話すのが理念に乗る形。

## 📋 次回同じことをするときのチェックリスト

1. 企業理念は `会社概要` と `about` の両方を見る。片方だけだと見出しか本文のどちらかが欠ける
2. 理念のキーワードの定義は、自社サイトより第三者の取材記事に載っていることが多い。「社名 + 理念のキーワード + インタビュー」で検索する
3. 代表者名・役職者名は必ず公式のIR/ニュースリリースで確定させる。フリガナも同じ
4. 求人票の人物像リストは理念の言い換えである可能性を先に疑う。対応表を作ると志望動機の骨格がそのまま出る
5. 面接で理念を引くときは、理念の言葉をそのまま復唱しない。理念の重心 (アマナなら「動かす」) を自分の実例の側で言い切る
