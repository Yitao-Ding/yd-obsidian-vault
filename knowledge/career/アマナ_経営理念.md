# 株式会社アマナ 経営理念

> 求人票の人物像の筆頭が「理念へ共感された方」。その理念の中身を一次情報から確定させたもの (2026-09-09 調査)。

## 経営理念は3階建て (amana.jp/company/)

| 層 | 言葉 | 中身 |
|---|---|---|
| 目指すこと | **世界にノイズと美意識を** | 人の創造力という可能性を拡張し、社会の感性を豊かにすること |
| 提供すること | **伝わり、動かすコミュニケーションデザイン** | 企業や社会の本質的な価値や課題を見出してビジュアライズすることで、「届けたい想いが伝わり、行動を促す」コミュニケーションを創ること |
| 大切なこと | **人が中心「感性・集合・進化」** | 人の「感性・集合・進化」こそが創造の源であり、すべての提供価値のコア |

## 理念本文 (amana.jp/about/ 原文)

> 新たな問いを生む「ノイズ」が常識を覆し、人の感性を豊かにする多様な「美意識」が、未来を切り開くとアマナは信じています。人の創造力という可能性を拡張し、社会の感性を豊かにすること。それがアマナが目指す姿です。

## ノイズと美意識の定義 (取締役 石亀幸大)

- **ノイズ** = 刺激や気づきを与えて課題の提起を促すもの
- **美意識** = その課題に対して、期待を超えた解決をめざす姿勢
- この2つの感性が「伝わり、動かす」の源泉
- 石亀: 「素晴らしいビジュアルを生み出すだけでは、クライアント企業の利益を最大限に引き出すことはできません。広告においては、その先に人を『動かす』ことも重要」

## 経営陣の言い方

- 社長 **金子剛章 (かねこ・よしあき)**: 「世界にノイズと美意識という人間が持っている創造性を拡張する」。AIは「アシスタント」= 人間の創造性を補完するスーパーパートナー。これからのクリエイティブの核は編集能力と「ノイズ設計」(違和感・意外性)
- 創業者 進藤博信: 「"流れ"と捉える。時代の空気を掴んで、溜まらずに動き続ける組織」(Great RIVER構想) / 「世の中の役に立ち続けるというのが大事。だからゴールはないんですよ」/ 「クライアントからありがとうって言われることをゴールにすればいい」
- AIサービス名の "GreatRIVER AI STUDIO" はこの Great RIVER構想から来ている

## 理念と人物像リストの対応

求人票の人物像は理念の言い換えになっている。

- 「理念へ共感された方」 → ノイズと美意識
- 「人との関わりを大切にし、チームでの創造を楽しめる方」 → 「人が中心」の**集合**
- 「枠に捉われず新しいことに挑戦する / 変化や挑戦を前向きに / 新しいことにワクワク」 → **進化**、およびノイズ (常識を覆す)
- 「自分の感性を磨き続けたい / 自分なりの『好き』『こだわり』がある」 → **感性**、および美意識

## 実務上の読み方

理念の重心は「美しいものを作る」ではなく「違和感を仕込んで人を動かす」。ビジュアルの完成度で完結する話をすると理念とズレる。作ったものが相手の行動をどう変えたかまで話すのが理念に乗る形。

## 社名の由来 (2026-09-09 追加)

「アマナ」は約2500年前の日本古代のことばで、エネルギーの概念を意味する。森羅万象、すべてのものが生まれるところ、**創造の源**。グループのクリエイティブ・スピリットを表現したもの (Wikipedia「アマナ (企業)」)。

理念の3階目「人が中心」の説明が「人の『感性・集合・進化』こそが創造の源」となっているのは社名と地続き。面接で触れる価値がある。

## 他AIの説明のファクトチェック (2026-09-09、Gemini の回答を検証)

YD が Gemini の回答を持ち込んだので一次情報と突き合わせた。**もっともらしいが公式の文言と違う箇所がある**。

### 合っているもの

- 広告写真スタジオが源流。進藤博信はフォトグラファー、8×10 の大判で商品撮影 → ○
- 感性とテクノロジーの掛け合わせ、CG/XR/バーチャルプロダクション/生成AI への早期シフト → ○ (現在の AI Creative Architecture 等で裏付く)
- 『IMA』の運営、アート写真領域へのコミット → ○ (2012年創刊、現在もアマナのサービス一覧に掲載)
- 受託制作からクリエイティブパートナーへの進化を意識した理念運用 → ○ 方向性は現在の発信と整合

### 事実と合わないもの

- **「ビジュアルコミュニケーションで、人の心を動かす」を創業以来一貫した理念として掲げている**: 公式サイトにこの文言はない。現在の経営理念は3階建て (世界にノイズと美意識を / 伝わり、動かすコミュニケーションデザイン / 人が中心)
- **コーポレートパーパス「ビジュアルコミュニケーションで、世界を豊かにする」**: 公式の文言は「人の創造力という可能性を拡張し、社会の感性を豊かにすること」。似ているが別物
- **ストックフォト事業を現在の理念の一部として語る**: 2022年5月に売却済み。源流としては事実、現在形で語ると誤り
- **★ 最重要: ノイズ = 写真の粒子感・ブレ・光漏れ等の「不完全さ」という解釈**: 公式にも取材記事にも無い。会社の定義は「刺激や気づきを与えて課題の提起を促すもの」= コミュニケーション上の問いの起点であって、画のノイズの話ではない
- **「原点はノイズの徹底排除 → 現代はあえてノイズを残す」という三段構成の歴史**: 出典が見当たらない。もっともらしい再構成
- **「説明しすぎると情報のノイズになるから引き算する」**: 方向が逆。アマナはノイズを**足す**側の言葉として使っている

### 拾えていなかった重要事実

- 社名の由来 (創造の源)。理念の3階目と直結する一番強い材料
- 現社長 金子剛章、2023-12-28 就任、進藤含む全役員退任
- 創業者 進藤の Great RIVER 構想 (会社を「流れ」と捉える) → AIサービス名 GreatRIVER AI STUDIO の由来

### 教訓

企業理念を他AIに聞くと、社史と業界知識から**もっともらしい理念文を合成**してくる。理念の文言と、その中のキーワードの定義は、必ず公式サイトの原文と役員の取材発言で確定させる。特に「一貫して〇〇を掲げています」という言い切りは要注意。
