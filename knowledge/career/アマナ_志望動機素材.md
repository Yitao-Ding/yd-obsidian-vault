# アマナ プロデューサー職 志望動機の素材 (2026-09-09)

> YD が自分で書いた原稿を、口に出せる形に整えたもの。中身は変えず順番と言い方だけ調整。整形版の全文は準備ノート (Artifact) の「志望動機の言い直し」節。

## 骨子

- **なぜプロデューサー職か** = 個人の依頼が全部自己流。社会で通用する映像がどういう順番で、誰が何を決めて出来上がるのかを知りたい。特に「限られた予算と期間の中で、どこに時間とお金をかけて、どこを削るかの判断」
- **技術職でなくプロデューサーである理由** = つくる側の言葉 (撮影・編集・カラーを自分でやってきた) と、頼む側の言葉 (Apple で言葉になっていない要望を形にしてきた) の両方を持っているから、間に立つ役割が一番効く。加えて外と接する量が一番多い場所にいれば、世の中が何を必要としているかを一番早く受け取れる
- **工程全体を知る意味** = 判断を前倒しできる。撮影の場で、あとの編集で困ることを潰せる
- **人との関わり / チーム** = Salamat 代表1年・260名。2週間の街全体フィールドワーク → コミュニティリーダーに一人ずつ会う → 口に出ていなかった要望を拾う → 次の渡航で保育園の大型改修・塗装につながる。塗装は教室内と外壁を子どもたちと共同 (自分で塗った場所には通いたくなる = 当事者意識)。最終日に地域全体へ告知してパーティー
- **枠に囚われず / 変化** = 説明のつかない慣習を全部洗い直してアクティブメンバー率 20%→50%。フィリピンワークは1部隊が当たり前だったのを見直し、期間・費用・人数を2倍
- **感性・こだわり** = 目の前で見た景色の衝撃を画面越しでも同じだけ届けたい。インパクトは「どれだけ長く記憶に残るか」で測る。撮って画面に載せる過程で質感や空気が落ちる。その落ちた分を戻すのがレタッチと編集。入院して外に出られない人が景色を映像でしか見られない、という例

## 直した点と理由 (重要)

1. **「制作に没頭すると新しいものに排他的になる」という論法を撤去**。技術職を下に見ていると取られる。アマナにはレタッチャー・CG・フォトグラファーが大勢おり、面接官がその出身の可能性もある。さらにYD自身が反例 (独学で技術をやりながらAIツールを触りまくっている)。→「職種の性質」ではなく「自分の持ち札と性質」で同じ結論に着地させた
2. 「クリエイターとしての勘 / 制作の感覚」→「限られた予算と期間の中で、どこに時間とお金をかけて、どこを削るかの判断」
3. 「必要な意見出しが可能になり効率的に進められる」→「判断を前倒しできる。撮影の場で、あとの編集で困ることを潰せる」
4. ルンバニ → 「支援先の保育園」と説明を足す (固有名詞のままでは伝わらない)
5. MCP という語は外す。「AIツールを一通り触って、実際にアプリを作って TestFlight まで出した」で足りる
6. 「データ圧縮」の比喩は使わない。映像業界ではコーデックの意味になる。「質感や空気が落ちる / 落ちた分を戻す」で同義

## 足りていないもの

- 全ブロックが「学びたい・知りたい・吸収したい」で終わっている。採用側が見るのは「うちで何を出すか」。各ブロックに持ち込めるものを対で置く
- **納期8日前倒しの実績が未使用**。プペルOPは納期希望8/16に対し8/8納品。プロデューサー職では志望動機のどの言葉より効く
- **曖昧な指摘を基準に置き換えた実績が未使用**。ゆかやねん夜の色合わせ (「なんか暗くない?」→ FX30実測±10%)。「頼む側の言葉をつくる側の言葉に翻訳した」実例
- Apple のデモの話は集客数を使えない (Vaultルール: 販売ランキング数値とグループデモ参加者数は不使用)。デモの中身をどう変えたかで語る必要あり → YD未回答
- クリエイティブ経験の本数と「一番出したい1本」が未確定
