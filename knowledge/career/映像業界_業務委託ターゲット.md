# 映像業界 業務委託ターゲット (2026-08-28 調査)

## 中核の発見

AKIYA型 (個人がYouTubeで名前を作って法人化した映像会社) は **構造的に採用しない**。
6社 (GOC/TranSe/ORIENTIS/FLAG/Noko/BLUE BANANA WORKS) 全社で採用ページゼロ、
公開窓口はクライアント向け問い合わせのみ。案件が代表個人の名前で来ており、
発信力そのものが商品なので、必要なのは「自分で仕事を取れる人」= もう社外にいる人。
→ 「入る」対象ではなく「なる」対象。

YDが惹かれた3点 (作品の質 / 一人でやらない環境 / 案件の規模) のうち、
「発信で稼ぐ形」を選ばなかった。AKIYAがSONY・FUJIFILM公式案件を回せるのは
登録27.8万人の発信力ゆえで、腕だけの仕事ではない。よってAKIYA型に雇われても
求めるものは手に入らない。3条件で洗い直した結果が下記。

## ✅ うまく行ったこと

- 「AKIYAMOVIEに入りたい」を額面で追わず、惹かれた理由を4択で分解してから調べたこと。「発信で稼ぐ形」が選ばれなかった時点で、AKIYA型を追うのが筋悪だと判定できた
- サブエージェント2本 (クリエイター発映像会社 / ダンス・アーティスト映像チーム) を並列で走らせ、実在確認済みのリストを一度に取れた。「推測で埋めず不明と明記」を指示したのが効いて、採用導線の有無という一番大事な項目が信頼できる形で返ってきた
- 求人サイト (Vookキャリア等) を先に潰したこと。掲載枠がマンガ動画・採用インタビュー・ブライダルばかりで、YDの3条件をどれも満たさないと早期に分かり、会社側から特定する方針に切り替えられた

## ❌ 詰まったこと

- YouTubeチャンネルページは WebFetch でメタデータしか取れない。登録者数・動画一覧が読めず、外部記事 (Blackmagic note、gocinc.jp) から回り込む必要があった
- GOCの所在地が「AKIYA氏は大阪府出身」に引きずられて大阪と誤認しかけた。正解は東京都渋谷区道玄坂で、出典は本体サイトではなく Visual Park の特定商取引法表記。会社サイトは「セキュリティのため住所非公開」
- 社名の重複に注意。ダンス専門は odoriba.tokyo の株式会社ODORIBA (渋谷区神宮前)。odrb.jp (宮城・宿泊飲食) と odoriba.co.jp (日本橋・コンテンツ企画) は無関係の別会社
- 最初 read_multiple_files で current_state を3ファイルまとめ読みしたら 77,642 文字でトークン上限超過。current_state/active_projects.md は586行あるので単独で length 指定して読むこと

## 📋 次回同じことをするときのチェックリスト

1. 「○○に入りたい」が来たら、まず○○の実態を調べる前に「○○の何に惹かれたか」を選択肢で分解する。憧れの対象と、本人が本当に欲しいものはズレる
2. 会社の採用導線は必ず実サイトのナビゲーションで確認する。求人媒体に載っていないことと、募集していないことは別
3. 小規模クリエイター企業の住所・法人格は、本体サイトではなく特定商取引法表記かPR TIMES企業情報かgBizINFOで拾う
4. 業務委託の入り口が実在するかの判定材料は3つ。採用ページの雇用形態欄に「業務委託」の語があるか / 外部クリエイターがMEMBERページに役割つきで載っているか / ランサーズ等の第三者プラットフォームに法人アカウントの発注履歴があるか
5. 営業の前にショーリール。実績が何本あっても、1本にまとまった映像が無ければ相手に判断材料がない
