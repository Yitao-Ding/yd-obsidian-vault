# 能登ワーク (2025年3月) — YDが新規に立ち上げたプロジェクト

Vault に記録がなかったが、ESや面接で使える最上位の素材。YDが代表在任中に「新規プロジェクトとして企画・実行」したもの。

## 事実
- 期間: 3月17日〜3月21日 (4泊5日)。活動場所: 石川県七尾市
- 活動内容: 被災した家屋の片づけなど、地域住民の要望に沿った活動
- チーム名 Passo a passo (資料の由来説明は「フランス語で一歩ずつ踏み出す」。実際はイタリア語なので、面接では由来の語源に触れない方が安全)
- メンバー12人: 現3年6人 (日馬颯太・島村芳乃香・丁一韜・佐藤里緒・土屋望実・高木夏望)、現2年5人 (山内梨聖・田代匠・大塚優衣・阿部夏香・八十島透輝)、現社会人1年目1人 (工藤怜)
- 受け入れ先: 民間災害ボランティアセンター「おらっちゃ七尾」(地域の困りごとを請け負い、ボランティアに支援先を紹介する懸け橋のような支援団体)
- 移動: 8人乗りの自家用車 + 5人乗りレンタカー。行き8時間、帰り6時間
- 宿泊: 石川県七尾市能登島向田町 牧山家族Weランド
- 現地の流れ: 9:00に旧石崎保育園に集合しオリエンテーション、当日に役割が伝えられる。2日目は6時起床・8時出発・9時活動開始・17時活動終了

## 企画した理由 (報告会の論の立て方そのまま)
1. 現状: 春休みの活動はフィリピンワークしかない。Salamat全体200人に対し、実際に活動に参加したことのあるメンバーは約80人
2. 課題: 「メンバーの思いを実現できていない」。誰かのために、社会のために何かをしたいメンバーがいるのに場がない
3. 根拠: YD自身が2024年11月に能登半島ボランティアへ個人で参加し、現場を見ていた。地震被害に加えて大雨で家屋倒壊・土砂崩れが多発し、多くの場所が手つかずだった
4. 現地の声: 「ボランティアの高齢化も進んでいて、学生がいてくれるだけでみんな元気になる」「ボランティアの数が減っていて、受け入れ口が減ってきている」「まだまだ復興まで時間がかかる。東洋大生の後輩よ、頑張ってくれ」
5. 結論: 「SAVESMILE」の体現 → Salamatの機動力・経験を生かした新たな災害ボランティアへ

## なぜ就活で強いか
- 羽鳥 (TYO MONSTER/drive)「自分から積極的にアイデアの提案ができる人」への直球の答え。既存の枠の中で改善した話ではなく、無かったものを立ち上げた話
- 浜谷「ハートに火がある人」。11月に自分で現場を見に行ってから3月に実行、という順序が火の証拠
- 岸本 (Third)「自分の作ったもので社会を動かしたい」
- Save Smile (フィリピンの子どもの笑顔を守る) を国内の被災地へ適用した = 「入った場所の理念を自分の目標にして走り切る」という YD の軸そのもの
- 石川竜大 (TYO)「とにかく失敗する勇気をもつこと」にも対応

## 数字の不一致 (面接前に要整理)
報告会資料は「Salamat全体200人」「15年間Salamat」、Vault/ESは「260名」「18年目」。時点の違いか数え方の違いか不明。
ESでは「18年目・260名」「活動する人の割合を2割から5割」で提出済み。報告会資料の「200人中80人が参加経験 (=40%)」とも噛み合わないので、どの時点の何の数字かをYD本人が説明できるようにしておくこと。

## うまく行ったこと
- YDが「別にわざわざ書かなくていい」と言った資料が、実際には手持ちで最も強い札だった。渡された資料は一度中身を見てから判断すべき
