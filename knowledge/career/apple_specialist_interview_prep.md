# Apple Specialist 社内公募｜面接 想定問答集

作成: 2026-08-13 / 対象: 丁一韜 (YD) — ASC(ヨドバシAkiba) → Retail Specialist
前提: 日本語・1対1・面接官はリテール(店舗)側の人間

---

## 0. まず、この面接の勝ち筋

友達の情報を分解すると、面接官が見ているのは実質この3つです。

| 見られている点 | 相手の本音 | あなたが出す弾 |
|---|---|---|
| ① 話が通じるか | 「聞いたことに答えられる人か」 | 結論ファースト30〜45秒。長話をしない |
| ② 何ができる人か | 「うちの店で即戦力になるか」 | Mac開拓・GD・AppleCareの**数字** |
| ③ うちのチームで回るか | 「リテールの文化に馴染むか」 | チームへの還元エピソード＋Values |

そして友達の「店舗の規模感を説明できるように」というアドバイスの本当の意味はこれです。

> **面接官はASC/量販店の世界を知りません。**
> あなたが「Mac CEを3.6倍にしました」と言っても、母数の景色が浮かばないと数字が評価できない。
> だから**数字の前に必ず"環境の一言"を置く**。これが今回の最大の差がつくポイントです。

**鉄則**: 数字を言うときは必ず「どんな環境で」→「何をして」→「どうなった」の順。

### Q1.「まず簡単に自己紹介をお願いします」(ほぼ必ず来る)

**構成**: 所属 → 強み3つ → 代表的な数字 → 一言

```
ヨドバシAkibaでASCをしております、丁一韜と申します。2025年5月から
Apple製品の販売を担当しています。

強みは3つあります。1つ目は、日本語・中国語・英語の3か国語で接客できること。
2つ目は、動画編集や生成AIといったクリエイティブ分野の知識を、そのまま接客に
活かせること。3つ目は、学んだことをすぐチームに共有して、店舗全体の数字に
還元することです。

この3つを掛け合わせて、入社当初は知識が浅かったMacを自分で開拓し、
Mac関連の接客数を前年の約3.6倍、成約率を25%から45%まで伸ばしました。

本日はよろしくお願いいたします。
```

⏱ 約50秒。**ここで喋りすぎない**。深掘りしてもらう余白を残すのが正解。

### Q2.「なぜSpecialistに応募したのですか」★最重要

**この質問の裏の意味**:「ASCのままでいいのでは? なぜわざわざ?」
→ **"Apple Storeにしかないもの"を1つに絞って言い切る**のが勝ち筋。あれこれ並べると弱くなる。

**結論(1文)**:

```
お客様と、買っていただいた"後"まで関わりたいからです。
```

**根拠(2文)**:

```
ASCの仕事は、基本的にお会計までが範囲です。自分がこの仕事で一番やりがいを
感じたのは、以前提案したお客様が後日また売り場に来てくださって「あのMacで
実際に動画を作れた」と話してくださった時でした。ただ、量販店という環境では
そういう関わりは偶然に頼るしかありません。

Apple Storeは、購入前の相談からセットアップ、Today at Apple、その後の
サポートまで、同じ場所で一貫してお客様に伴走できます。自分がやりがいを
感じてきたことが、仕組みとして毎日できる場所だと考えています。
```

**締め(1文)**:

```
その上で、他社製品が隣に並ぶ売り場で選んでいただく提案をしてきた経験は、
Apple Storeでも活きると考えています。
```

⏱ 約60秒。

> ⚠️ **「後日また来てくださった」エピソードは実話に差し替えてください。**
> 具体的な人物像(年配の方/学生/海外のお客様)と、何を提案して何が起きたかまで。
> ここが作り物だと深掘りで必ず崩れます。実話がなければ、下の代替版を使ってください。

**代替版(実話がない場合の結論)**:

```
提案の"幅"を、製品を売ることの外側まで広げたいからです。
量販店では、お客様の目的が「買う」に固定されています。Apple Storeには、
まだ買うと決めていない方、使い方を学びに来る方、修理に来る方がいらっしゃる。
その全部に対応できるようになることが、自分にとって次の成長だと考えています。
```

#### 深掘り想定と返し

| 深掘り | 返し方 |
|---|---|
| 「ASCのままでもできるのでは?」 | 「ASCでできるのは購入までの提案です。セットアップやToday at Apple、修理のご相談まで一貫して担当できるのはApple Storeだけだと理解しています。」— **現環境の悪口にしない**。範囲の違いという事実だけ述べる |
| 「Apple Storeに行ったことは? どこの何が良かった?」 | **★これは必ず来ます。面接前に必ず1店舗行ってください**(下の実施タスク参照) |
| 「Specialistの仕事、どこが大変だと思う?」 | 「複数のお客様を同時に見る場面が量販店より多いと思っています。今の売り場でも待っているお客様に一声かけて回すことはしていますが、そこは入ってから一番早く慣れるべき点だと考えています。」 |
| 「今の仕事で不満があるの?」 | 「不満ではありません。今の環境で3か国語やクリエイティブの提案を伸ばせたのは事実です。その上で、次に伸ばしたい方向がApple Storeにある、という話です。」 |
| 「給与や条件は下がるかもしれないが?」 | 事実確認だけして「条件よりも、やりたい仕事の内容で選んでいます」と短く。粘らない |

### Q3.「今の店舗はどんな環境ですか / 規模感を教えてください」★対策必須

**構成の型(この順で言うと伝わります)**:

1. **立地と客層** — どんなお客様が来るか
2. **売り場の規模** — 広さ・取扱いの範囲
3. **体制** — ASC何名、シフト、リーダー体制
4. **忙しさ** — 1日の接客数、ピーク時間
5. **Apple Storeとの違い** — できること/できないこと

**穴埋めテンプレ**(★の数字は面接前に必ず埋める / 分からなければ「体感で」と前置きしてOK):

```
ヨドバシAkibaの中にあるApple売り場で、秋葉原という立地上、国内のお客様と
海外からのお客様が半々くらいの日もあります。★免税のお客様は体感で全体の
★約○割です。

売り場としては、Apple製品のほぼ全ラインが並んでいて、加えてヨドバシの中
なので、他社のPCやアクセサリ、周辺機器も同じフロアで比較されます。
ここがApple Storeとの一番の違いです。

体制は、ASCが★○名、うち学生スタッフが★○名で、シフトは1日★○名程度が
売り場に立ちます。自分は週★○日、四半期で★約120〜180時間ほど入っています。

忙しさで言うと、平日で1日★約○件、土日やホリデー・新生活の時期は
★約○件のお客様を接客します。ピークは★○時〜○時です。

Apple Storeと違って、修理や購入後のサポートは自分たちの担当範囲外なので、
基本的にはお会計までが自分の仕事になります。
```

> **数字が正確でなくても大丈夫。「体感で」「おおよそ」と前置きすれば誠実に聞こえます。**
> むしろ**分からないのに断言する方が危険**。

### Q4.「今年一番の成果は何ですか」

**Mac開拓の話で行く**。PR・レジュメと完全一致していて、数字も強い。

```
入社当初ほとんど売れていなかったMacを、自分の主力商材にしたことです。

自分はもともとMacの知識が浅く、iPadやiPhoneのご案内が中心でした。ただ、
趣味の動画編集や生成AIの知識と、3か国語での対応を組み合わせれば、自分にしか
できないMacの提案ができると考え、製品理解を集中的に深めました。

結果として、労働時間あたりのMac接客数が前年の約3.6倍、成約率も25%から45%
まで上がりました。接客数を増やすと普通は成約率が下がるところを、両方同時に
上げられたのが自分としては手応えでした。
```

⏱ 約45秒。**最後の一文(量と質の両立)が効きます。必ず入れてください。**

#### 深掘り想定

| 深掘り | 返し |
|---|---|
| 「具体的にどんな提案をした?」 | 実例を1つ用意。例:「動画編集をされる方に、スペックの数字ではなく"書き出しにかかる時間がこれだけ変わる"という伝え方をした」など。**シーンが浮かぶレベルまで** |
| 「なぜ成約率も上がった?」 | 「ニーズを引き出してから提案する順番に変えたからです。以前は製品説明が先でした。」— 因果を1文で |
| 「その3.6倍って何が母数?」 | 「四半期ごとに出勤時間が違うので、労働時間あたりで比較しています」と**先に言う**。これで数字の誠実さが伝わる |

### Q5.「チームに貢献した経験は?」

**AppleCareの話**。「学ぶ→改善→共有」の流れが綺麗。

```
AppleCareの提案の仕方を改善して、それをチームに共有したことです。

自分はAppleCareの提案が苦手で、付帯率が伸びていませんでした。先輩に相談して
フィードバックをいただき、提案するタイミングと言い方を変えたところ、Mac購入時の
AppleCare付帯率が前年同期の13%から45%まで上がりました。

上がった要因が自分だけの工夫ではなく、教わったことの再現だったので、
すぐキャッチアップの時間でチームに共有しました。何人かのメンバーが取り入れて
くれたのが嬉しかったです。
```

**もう1つの弾(学生Mac)**: 新生活シーズンに、学生ASC同士で「学生にMacをどう提案するか」を議論して成功事例を共有し、チームで学生層のMacを強化した。→ **チームワークの質問が2回来たらこちらを出す**。

### Q6.「グループデモ(GD)について教えてください」/「工夫した経験は?」

```
用意されたスクリプトをそのまま読まずに、自分の言葉に組み直して実施しました。

自分自身が昔PCに対して分かっていなかったことを思い出しながら、通常5分の
内容を噛み砕いて約15分に、テーマも通常3つのところを5つに増やしました。
結果として1回あたりの参加者が通常の約2倍になり、デモの後に個別に相談へ
来てくださる方が増えました。
```

> 「言われた通りにやらなかった」と取られないよう、**"目的は同じで、伝わり方を変えた"**というニュアンスを必ず入れる。

### Q7.「うまくいかなかったこと / 失敗経験は?」

**ここは正直に、かつ"その後どうしたか"で締める**。おすすめは2択。

**A案(数字の話・誠実さが伝わる)**:

```
Mac購入時のAppleCare付帯率が、一度45%まで上がった後、次の四半期で20%まで
下がりました。原因は、うまくいった時の型を自分の中で言語化しきれておらず、
接客が忙しくなると提案自体を飛ばしてしまっていたことでした。今は提案の
タイミングを自分の中で固定して、必ず一度は触れるようにしています。
```

> ⚠️ **これは面接官が数字を照合してくる可能性への保険にもなります。**
> 自分から先に出しておけば「都合の良い数字だけ出す人」に見えません。**強く推奨。**

**B案(スキルの話)**:

```
Apple以外の製品知識が不足していたことです。ヨドバシの中なので、ウイルス対策
ソフトやMicrosoft製品まで含めて提案できるとお客様の生活がもっと良くなるのに、
自分は答えられない場面がありました。今は自分で学びつつ、チームでも共有できる
機会を作れないかマネージャーに相談しているところです。
```

### Q8.「あなたの強みと弱みは?」

**強み(1つに絞る)**:

```
学んだことをすぐ人に渡せることです。自分で工夫して結果が出たら、それを自分の
中に留めずに、その日のうちにチームに共有します。AppleCareの件も、学生への
Macの提案の件も、共有したことでチームの数字につながりました。
```

**弱み(改善行動とセット)**:

```
一度に多くのお客様を見るのがまだ得意ではありません。1人のお客様に深く入り込む
接客が自分のスタイルなので、待っている方への目配りが遅れることがあります。
今は、深く入る前に周りを一度見渡す、というのを意識的にやっています。
```

> **弱みは"Specialistで致命傷にならないもの"を選ぶ**のが原則。ただし「複数対応」は
> Specialistの必須要件なので、**必ず「今こうしている」を付ける**。付けないと落ちます。
> 不安なら弱みはB案(Apple以外の製品知識)に変えてもOK。

### Q10.「Appleで働く上で大事にしていることは?」/「なぜApple?」

```
お客様が自分では気づいていないことまで持ち帰っていただくことです。

自分は映像制作や生成AIを個人でやっていて、Apple製品でできることの幅を
ユーザーとして実感しています。だからこそ、お客様が「これができればいい」と
おっしゃった一段先まで提案したい。それが自分の考えるApple製品の価値の
届け方です。
```

**「なぜApple(会社として)」を聞かれたら**: 製品への熱ではなく**人への接し方**で答える方が刺さります。「製品を売る前にお客様を理解する、という順番が徹底されている会社だと、実際に中に入って感じました」。

## 3. 深掘り耐性:「なぜ?」3段掘りの練習

面接官は同じ話を3回掘ってきます。**2段目で用意がなくなる人が落ちます**。
各エピソードについて、この3層を用意してください。

| 層 | 聞かれ方 | 用意するもの |
|---|---|---|
| 1段目 | 「何をしたんですか?」 | 行動(すでに準備済み) |
| 2段目 | 「なぜそうしようと思ったんですか?」 | **動機・気づいたきっかけ**(← ここが手薄になりがち) |
| 3段目 | 「それをSpecialistでどう活かしますか?」 | **接続の一文** |

### Mac開拓の3層(例)

1. Macの製品知識を集中的に学び、クリエイティブ用途の提案に振った
2. **なぜ?** → iPad中心の接客に限界を感じていた。趣味の動画編集の話をした時のお客様の反応が明らかに違ったので、これは強みになると気づいた
3. **Specialistでは?** → Apple StoreにはMacを目的に来る方が多い。Today at Appleでもクリエイティブの領域は直接活きる

### AppleCareの3層(例)

1. 先輩のフィードバックで提案の型を変えた
2. **なぜ?** → 付帯率が低い理由を「自分は押し売りが苦手だから」で片付けていたが、実際は提案するタイミングが遅すぎただけだと気づいた
3. **Specialistでは?** → 数字が伸びない時に自分の性格のせいにしないで、型の問題として分解する癖はどこでも使える

### 語学の3層(例)

1. 日中英で接客している
2. **なぜ?** → Akibaは海外のお客様が多く、英語だけでは提案まで届かない場面が多かった。翻訳した提案文をiPhoneに用意しておく運用を自分で作った
3. **Specialistでは?** → 都心のApple Storeも海外からのお客様が多い。同じ運用をそのまま持ち込める

## 6. 逆質問(3つ用意、2つ聞く)

**良い逆質問 = 「入った後の自分」を前提にした質問**。制度や待遇の質問はしない。

1. 「Specialistとして入った方が、最初の3か月でつまずきやすいのはどんな場面ですか?」
   → 学ぶ姿勢が伝わる。答えを聞いて「今から準備しておきます」で締める
2. 「今の店舗のチームで、これから伸ばしていきたいと考えていることは何ですか?」
   → 相手を主語にした質問。会話が続く
3. 「量販店から来る人間に、リテール側が一番期待するのはどこだと思われますか?」
   → 自分の立ち位置を確認できる。**答えを次の一言で拾えると強い**

**避ける質問**: シフト、時給、評価制度、異動、「私は受かりそうですか」

## 7. 話し方の実務(吃音対策も兼ねる)

- **一文を短く**。「〜で、〜ですが、〜なので」を切る。結論ファーストは言い切り型なので相性が良い
- **最初の一文だけは完全に暗記**。出だしが出れば後は流れる
- 詰まったら**言い換えずに一拍おく**。焦って言い換えると崩れる
- 数字は**ゆっくり**。「にじゅうごパーセントから、よんじゅうごパーセント」
- 各回答は**45秒以内**。長い＝準備不足に見える
