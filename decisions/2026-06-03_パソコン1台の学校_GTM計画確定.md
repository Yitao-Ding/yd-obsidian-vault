# パソコン1台の学校 GTM(Go-to-Market)計画確定

> SNS(Instagram + Threads)で売る情報商材のローンチ計画を確定。
> 正本 = `~/projects/CC-business/marketing/launch/`(8ファイル) + `CC-business/HANDOVER.md`。

## 状況
- 製品(LP / 料金 / 受講ゲート / 法務4 / 86レッスン / ポスター6)はローカル構築完了・Playwright検証済、Go-live待ち。
- 「実際に売り出すための広告・投稿・ペースを細かく決める」段階。YD が4つの運用パラメータを選択 → それに沿って GTM 一式を生成。

## 決めたこと(意思決定)
1. **媒体 = Instagram + Threads の2つ**(他媒体は当面足さない)。役割分担:
   - **Threads = 信頼構築・物語・会話**(オーガニック専念)。テキスト中心=半自動運用と相性最高、新規アカでも初速が出やすい、「2週間前まで初心者」の等身大ナラティブと好相性。← YD「スレッズいけそう」の勘を裏付け。
   - **Instagram = 認知・視覚フック・広告・着地**(リール/カルーセル)。
   - 有料広告は Instagram リール面のみ(Threads 広告は未成熟)。勝ちリールが出たら無料で TikTok 転用、先行投資はしない。
2. **広告 = 少額テスト**。目的=トラフィック(プロフ遷移)、リール面のみ、1クリエイティブ ¥500×3日=¥1,500 を1単位、A1(正体・黒い画面)+B1(ビフォーアフター)を2本同時 → 探索7日 → 勝ちに寄せて7日。kill/増額の閾値は `05-ads.md`。
3. **リール = ハイブリッド**(基本 faceless = 画面録画+テロップ+合成音声、要所だけ肉声ナレ/手元カット)。
4. **運用 = 半自動**。Claude が週1で全原稿を一括生成 → YD は Meta Business Suite で予約投下 → 毎日やるのは投稿後30-60分の返信だけ(`06-comment-playbook.md` の15テンプレ)。
5. **進め方 = 助走7日(ノーセル)→ Go-live → 本格オファー2週間 → 先着100名到達/定価復帰後の継続運用**。
6. **KPI** = 保存率2-3%・プロフ遷移率3-5%を週1チェック → kill/寄せ。3週目に自分の Insights 実データで投稿時間を上書き。

- 「ベンチ調査 → チャネル別 並列生成 → 景表法 反証チェック → カレンダー統合」を1本のWorkflowで一気通貫。コンプラ反証が CLEAN を裏取りできた。
- 既存素材(ポスター6 / Threads10 / キャプション)を土台に拡張させ、トーン・CTA・着地を完全統一。

## ❌ 詰まったこと
- GTM Workflow で instagram コンテンツ agent が構造化出力を返さず脱落 → `03-instagram-feed.md` 未生成。単発Agentで再生成 + コンプラ再チェック + README/07 整合修正で解消。**教訓: 大きいファイルWrite + schema返却を1 agentに兼ねさせると返却を落とすことがある。Write系はschema無し(テキスト要約返し)が安全。**
- 並行CC調査で、CC-business と同じ cwd の claude プロセスを「orphan 並行CC」と誤認し kill しかけた(実は自分自身)。verifyで回避 → [[claude_mistakes]] A-17。

## 📋 次回同じことをするときのチェックリスト
- 媒体選定は「商品の売り方(物語/正直さ)」と「運用負担(faceless/半自動)」から逆算。テキスト商材なら Threads オーガニック + IG広告 の二段が筋。
- 有料広告は最初から少額テスト(¥500単位×複数クリエ)で勝ち発見、母数投下は勝ち筋検証後。
- 景表法: 収益訴求は必ず個人差注記、嘘の希少性禁止、Mac/AI月額を早期開示。新原稿は `07` の敵対レビューを必ず再実行。
- Workflow で大きいファイルを書かせる agent には schema を付けない(Write + 構造化返却の二重責務で脱落しやすい)。
- 破壊操作(kill/rm)の前に対象の実体を必ず verify(自分自身のPIDでないか含む)。
