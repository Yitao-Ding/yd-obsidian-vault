# ハタチたち5 説明会動画を FCPXML 自動生成で編集し、FCP プロジェクトとして納品

## 状況

2026-09-14 の平成たち祭 vol.2 で収録した「ハタチたち5 説明会」(FX30 定点、10:52、A027C007) を、ダンサー募集 (締切 9/30) 向けに SNS 用へ編集する依頼。YD の指示は「Apple の新製品発表会みたい」「見にくい所は Canva スライドを全面に出して話者を右下か左下の丸窓に」「スライド内の動画はその動画だけ全画面」「Canva 9〜13 は動画メイン、それ以降は動画続きにしない」「噛みはカット」「字幕」「座談会は触らない」「編集は FCP で」。

## 選択肢と選んだもの

- 成果物の形: A. Remotion/ffmpeg で完成 mp4 を出す / B. FCPXML を生成して FCP プロジェクトとして渡す → **B**。YD が FCP で微調整・書き出しできる。字幕・寄り・丸窓・スライドが全部クリップとして残る
- スクリーン差し替え (投影面にきれいなスライドを合成): 見送り。話者がスクリーンの前に立つ時間が 88% で、合成すると話者が隠れる。ワイド/寄りは撮影のまま、スライドを見せたい所は全面表示にした
- 寄り: FCP の変形キーフレーム (0.25秒刻み、顔トラッキング由来) で 240% の仮想カメラ。YD が FCP 上で直せる
- 丸窓: 1920x1080 の透過 ProRes 4444 に焼いた右下版・左下版の2ファイルを変形なしで接続 (320px 素材 + 空間適合なし は FCP で拡大されてしまった)

## 成果物

- `/Volumes/Extreme pro/平成たち祭２/ハタチたち説明会&座談会/_FCP納品/` に fcpxml (v5 が最終)、assets (Canva PNG 21枚 / 動画ページ11本の全画面版 / Canva 全ページ MP4 / 丸窓2本)、README.md、字幕 SRT
- FCP ライブラリ `YITAO's FILE/final cut pro/26.9.15~.fcpbundle` に「ハタチたち5 説明会 v5」イベントとして読み込み済み
- 尺: 本編 8:39 + エンドカード 6秒。カット 32区間、ショット 71 (ワイド11 / 寄り16 / スライド全面28 / 動画全画面16)、字幕 120本

## うまく行ったこと

- 文字起こし → カット → ショット割り → FCPXML → FCP で実画確認、を1セッションで通せた。FCP 上の見た目確認 (Control+P でタイムコードを飛ばして screencapture) で v1〜v4 の不具合を全部拾えた
- YuNet 顔検出 + Savitzky-Golay の仮想カメラは、そのまま使える寄りになった

## 詰まったこと

- FCPXML の position 単位 (px ではなく 1080/100)、静止画キーフレームの interp 属性、空間適合なし が効かない、`open` で起動した FCP がウインドウ無しで止まる、の4つで v1〜v4 を消費した。詳細は [[fcpxml_auto_edit_pipeline]]
- Canva の共有リンクは MCP で書き出せず、Chrome 経由のダウンロードに切り替えた
