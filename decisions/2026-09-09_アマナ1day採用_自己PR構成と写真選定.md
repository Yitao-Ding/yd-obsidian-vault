# アマナ 1day採用 自己PR構成と写真選定 (前日確定)

## 背景

アマナ 1day採用の一次選考 (2026-09-10) で自己PR 5分を行う。友人 (つん) のアドバイスを受けて前日夜に構成と写真を確定した。

## 選択肢

### A. 価値観から写真を作り直す
- 長所: メッセージと完全に一致する
- 短所: 時間がなく品質が下がる

### B. 写真はそのまま、価値観の対象を広げる
- 長所: 既存の強い写真 (レザー×公衆電話等) をそのまま使える
- 短所: 原稿との接続に説明が必要

## 決定

**選択肢 B を採用**。写真は変えず、価値観の対象を「景色」から「目の前にあるもの (人も含む)」に広げる。

## 理由

1. 既存3枚は広角・俯瞰・直射ストロボ・色の振り切りで統一感があり「自分の型がある」証明になる
2. 前日夜に新規撮影しても既存の質を超えられない
3. 「景色でも人でも同じ」という一文で接続できる

## 実装方針

冒頭: 「自分を一言で言うと、感動を減らさない人です」— この言葉を冒頭・作品提示・締め・スライド1枚目で3回繰り返す (つんの助言: 「○○の子」と呼べる印象1つが7割)

写真パートの順番と構成:
1. ジャポニカ学習帳 (白背景) → 2. ピンクソファ + 魔法ステッキ → 3. レザー + 公衆電話 Broadway Diner (最強を最後に)
- 全画面1枚ずつ、各10秒、1文ずつ、合計40秒以内
- 写真1枚ごとの説明はしない

作品パートの台本:
「減るのは景色だけじゃなくて人も同じ。会った瞬間の衝撃から逆算して3人分の別の世界を作った。景色でも人でも同じ」

未確認事項 (当日持ち越し):
- 3人の属性 (ダンサー/アイドル等)、依頼案件かどうか
- ファイル名 (Sony-0127 / nana-11 / のあみ-3) と人物の対応

## 追記: 最終構成確定 v5 (2026-09-09 深夜〜当日)

### 構成方針の転換

募集文どおりの3本立て (誰にも負けない / 熱中 / 特技) に再構成。

- 誰にも負けない = 完成度への執着と体力 (睡眠3時間で1年回したを証拠に。根性自慢にしない)
- 特技 = 写真の配布+スライド。Apple言及は締め1文のみ、順位の数字は使わない
- 熱中 = Salamat代表。中(アクティブ20%→50%、参加上限・お金の使い道まで慣習全見直し)→外(渡航 年2回・1チーム20人→年4回・2チーム・年間約100人、2つの幼稚園、セブ最大のゴミ山地域)→証拠(睡眠3時間)
- 志望動機の段落は削除 → 最終のグループ面接で話す
- 約1,250字、4分半

### つかみの確定

写真のプロに「がっかりしたことありませんか」と問うのは野暮 (YD指摘)。自分への告白に変更:
「僕は今でも、自分で撮った写真にがっかりします。目の前で鳥肌が立ったのに、画面だと半分も残っていない。その半分を取り戻すために写真と映像をやっています。丁一韜です」

代案: 数字3連 (20%→50% / 年2回→年4回 / 睡眠3時間)

### タイムライン (v5 最終)

- 0:00-0:20 名乗り+3本立て宣言。誰にも負けない=完成度への執着と体力、証拠は後
- 0:20-1:20 特技=写真 (配る)。3人の第一印象から逆算、撮る前の判断、映像も同じ、依頼で作り続けている
- 1:20-3:40 熱中=Salamat代表。中(20%→50%、慣習全見直し)→外(年2回20人→年4回100人、2幼稚園+ゴミ山)→証拠(睡眠3時間で授業・成績維持)
- 3:40-4:10 誰にも負けないことの回収。突破力と初対面で関係を作る力
- 4:10-4:40 Apple一言 (学生向けデモ企画、数字なし)
- 4:40-5:00 締め+名乗り
- 入れない: 志望動機・理念・Appleの順位 → 最終質疑へ

冒頭は募集文の項目名を読み上げない (YD指摘: ホームページの言葉をなぞるのは駄目)。推奨: 「妥協しない」で統一 (写真=完成度、Salamat=組織、睡眠3時間=体力、全部その証拠)。代案: 「決めたらできるまでやめない」

## 追記: 最終稿 v6 + 構成リセット案 (2026-09-09 深夜)

### 最終稿 v6 構成

- 冒頭: 名乗り → 「妥協しない人間です。一度こだわると、できるまで手を止められません」→ 写真の価値観 (減った分を埋めることに一番こだわる) → 写真と大学の2つで見せる宣言
- 写真 (配る) → Salamat (中20%→50% / 外 年2回20人→年4回100人+ゴミ山 / 睡眠3時間で授業・成績維持 → 「できるまで手を止められない」を回収) → Apple (デモ企画、数字なし) → 締め「妥協しない。人と一緒に作る仕事で。目の前の衝撃を減らさず届ける仕事をアマナで」→ 名乗り
- 約1,350字。超過時はApple段落を1文に

言葉遣い: YD本人の言い回し (説明がつかない伝統や慣習 / 会費に見合う活動を返す / ゴミ山) を優先。「証拠」という語は使わない (YD指示)。

一言の候補 (「妥協しない」が薄いとYD指摘):
- 推奨: 「『まあいいか』が言えない人間です」
- 次点: 「できるまで、やめられない人間です」
- 冒頭・睡眠3時間の回収・締めの3か所を同じ言葉に揃える

### 構成リセット案 (水平思考)

YDが「わからなくなった、0から水平思考で」と判断。「属性を言ってエピソードで裏付ける」型は全員がやるので埋もれる、が理由。

新しい型: 強みを一切言わず、物語を2本話す。締めで初めて「この2つに共通するのが僕です」と一言。

- 物語1 写真 (2分): 1枚 (推奨レザーの公衆電話) ができるまで。依頼・会った時の印象・何を見せ何を捨てたか・当日のトラブル・引かなかった所・本人の反応。撮って出しと仕上げを並べて見せる案 (元データがあれば最強)
- 物語2 Salamat (2分): 場面で話す。20%の会議室、伝統を壊すと言った時の反対と対話、ゴミ山に初めて入った日、裏側の睡眠3時間
- 名乗り10秒、締め30秒。Apple・志望動機・人物像対応表は捨てる

次の手順 (YD側タスク): 写真の選択・元データの有無・反対の場面とゴミ山の日を話せるか → の3点をYDが決める → YDが録音するつもりでしゃべる → 文字起こしをClaudeが削る (Claudeが原稿を書かない)
