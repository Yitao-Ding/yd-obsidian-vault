# アマナ 1day採用 自己PR構成と写真選定 (前日確定)

## 背景

アマナ 1day採用の一次選考 (2026-09-10) で自己PR 5分を行う。友人 (つん) のアドバイスを受けて前日夜に構成と写真を確定した。

## 選択肢

### A. 価値観から写真を作り直す
- 長所: メッセージと完全に一致する
- 短所: 時間がなく品質が下がる

### B. 写真はそのまま、価値観の対象を広げる
- 長所: 既存の強い写真 (レザー×公衆電話等) をそのまま使える
- 短所: 原稿との接続に説明が必要

## 決定

**選択肢 B を採用**。写真は変えず、価値観の対象を「景色」から「目の前にあるもの (人も含む)」に広げる。

## 理由

1. 既存3枚は広角・俯瞰・直射ストロボ・色の振り切りで統一感があり「自分の型がある」証明になる
2. 前日夜に新規撮影しても既存の質を超えられない
3. 「景色でも人でも同じ」という一文で接続できる

## 実装方針

冒頭: 「自分を一言で言うと、感動を減らさない人です」— この言葉を冒頭・作品提示・締め・スライド1枚目で3回繰り返す (つんの助言: 「○○の子」と呼べる印象1つが7割)

写真パートの順番と構成:
1. ジャポニカ学習帳 (白背景) → 2. ピンクソファ + 魔法ステッキ → 3. レザー + 公衆電話 Broadway Diner (最強を最後に)
- 全画面1枚ずつ、各10秒、1文ずつ、合計40秒以内
- 写真1枚ごとの説明はしない

作品パートの台本:
「減るのは景色だけじゃなくて人も同じ。会った瞬間の衝撃から逆算して3人分の別の世界を作った。景色でも人でも同じ」

## 追記: 理念・原稿 v3・写真プリント (2026-09-09 夜)

### 理念の扱い

「ノイズ」「美意識」は腹落ちしていないため原稿から外し、「人が中心」のみ残す。

- 締め冒頭: 「アマナが創業からずっと『人が中心』と言い続けていることを知って、自分がSalamatでいちばん大事にしてきたことと同じだと思った」
- 聞かれた時の1文: ノイズ=常識に「本当にそう?」と引っかかりを作ること、美意識=自分なりの美しさの基準

### 原稿 v3 の変更点

- アマナPD職は写真中心 (スチール・映像・CG・AI横断)。映像は1文のみで問題なし
- 「レタッチ・編集を覚えた、技術を上げたい」を削除 → 「減らさないために一番大事なのは撮る前の判断 (何を見せ、何を切り捨てるか)」に置換
- 「4年」を削除 (写真は4年ではない、映像は約2年) → 「大学に入ってから」に変更

## 追記: つかみ強化・最終稿 v4 (2026-09-09 深夜)

### つかみの候補 (YD選択待ち)

1. 問いかけ: 「旅先で撮った写真を見返して、がっかりしたことはありませんか」→ 許せなくて写真と映像をやっている → 名乗り → 「感動を減らさない」
2. 無言で3枚のプリントを置き、全員が見てから「この3人、会った時の第一印象がまったく違いました」(沈黙を作れるなら最強)
3. 数字から (保育園の壁を子どもと塗った、2週間歩いた)。写真との接続が遠く弱いため優先度低

名乗りは冒頭ではなく、つかみの後に回す。

### 最終稿 v4 の技術7つ

1. 問いか断言から入り名乗りは後
2. 一言を冒頭・中盤・締めの3回
3. 抽象の直後に具体
4. 前後の対比
5. 証拠は説明せず見せる
6. 間を3か所
7. 締めは冒頭の言葉に戻す

### v4 冒頭・締め

冒頭: 「旅先で撮った写真を見返して、がっかりしたことはありませんか」→ 許せなくて写真と映像 → 丁一韜です → 「感動を減らさない」
締め: 「人と一緒に何かを作って、感動を減らさずに届ける。それを仕事にしたくてアマナに来ました。丁一韜でした」
(配る) は写真パート冒頭、(間) は冒頭・写真・締めの3か所。約1,250字。
