YD が YouTube「今すぐにこれら9つのMCPを導入してください【Claude Code / MCP】」(Shin Coding Tutorial、2025-09-29、39:37) を視聴して、9個の MCP を Claude Code に入れる依頼。タイムスタンプは YD が手打ちで提示。

## 検討した選択肢

### スコープ
- **A. user scope** (`claude mcp add --scope user`) — 全プロジェクトから使える
- **B. 動画通り project scope** (`.mcp.json` をプロジェクト直下に置く) — プロジェクト単位
- **C. ハイブリッド** — 認証不要・1アカウント系は user、DB系 (Supabase/Stripe) は project

→ **A 採用**。理由: 複数プロジェクト並行運用中で、毎回設定するのは無駄。Supabase のように project_ref が必要な MCP は lecture-hub 専用の設定を user scope に固定 (将来切り替えが必要になったら project scope に分割)。

### Notion / Figma
- **A. claude.ai 経由のクラウド版で十分、ローカル版は入れない** (二重稼働回避)
- **B. 動画通りローカル版も追加** (ツール名衝突あり)
- **C. claude.ai 版を切ってローカル版に統一**

→ **A 採用**。理由: claude.ai 経由で既に `mcp__claude_ai_Notion__*` / `mcp__claude_ai_Figma__*` が利用可、ローカルにも入れるとツール名衝突 + メンテナンス2重。

### GitHub MCP
- **A. Docker版** (`ghcr.io/github/github-mcp-server`)
- **B. gh CLI 拡張** (`shuymn/gh-mcp`)

→ **B 採用**。理由: (1) YD の Mac に Docker 未インストール、(2) 動画スピーカーも「私は gh コマンド派」と明言、(3) `gh auth status` の認証情報をそのまま流用できて PAT 別管理不要。

## なぜこの決定をしたか

1. **動画の手順厳密遵守ではなく実用最適化**: 動画は `.mcp.json` project scope だが、YD のように複数プロジェクト並行運用では user scope のほうが管理コスト低い
2. **claude.ai 経由の既存連携を活かす**: Notion/Figma を二重に入れる必要なし
3. **Docker を入れない**: Mac で Docker 動かすコスト > gh CLI 拡張で済むメリット

## ✅ うまく行ったこと

- `video-tutorial` skill の初実運用 → 39分動画を 1m30s で前処理 → transcript 抽出で動画内容を把握。スピード十分
- 認証不要 4 個の MCP は 15分以内で全て `✓ Connected` 達成
- `gh-mcp` 拡張は `gh auth status` の認証情報を流用するため、PAT を別途発行・保管する必要がなく、セキュリティ的にもメリット
- Context7 は API key なしでも `✓ Connected` した (公開クエリは可能、key ありで品質向上)

## ❌ 詰まったこと

- **vidkit tutorial の `--lang auto` バグ**: 日本語動画なのに `en` 字幕を最初に取りに行って HTTP 429 で fatal 終了。`--lang ja` で再試行して解消。これは [[vidkit]] の改善タスクとして Opus 4.7 サブエージェントが並行修正中
- **重複起動問題**: 同じ URL を2回投げると2並列で実行される (出力ディレクトリ同名で race condition の温床)。M5 Max は耐えたが、これも vidkit 改善タスクに含む
- **vidkit の objc クラス重複警告**: cv2 (libavdevice.61) vs av (libavdevice.62)。動作はするがノイズ
- **youtube_auto 字幕の固有名詞ガタガタ**: "Stripe→STIPE/ストラプ", "kaito→カト", "Tailwind→テil", "Figma→PIGM" 等。grep でセクション抽出に苦戦。`--source whisper` オプション追加で MLX-Whisper 再文字起こしできるよう改善タスクに含む

## 📋 次回同じことをするときのチェックリスト

### MCP 追加時
1. 認証要否を最初に分類 (不要なものから先行)
2. user scope vs project scope を選ぶ (複数プロジェクトで使うなら user)
3. claude.ai 側に既にあるコネクタと重複しないか確認
4. `claude mcp list` で接続確認、`✓ Connected` を全て見届ける
5. `~/.claude.json` の `mcpServers` 直編集はせず必ず `claude mcp add` 経由で

### YouTube チュートリアル動画から自走実装
1. **`vidkit tutorial <URL> --lang ja`** (日本語動画なら `auto` ではなく `ja` 固定推奨)
2. `~/Downloads/vidkit_<日付>_tutorial_<id>/` の `PROMPT.md` / `transcript.md` / `scenes.md` を確認
3. PROMPT.md は実装系前提なので、セットアップ系チュートリアルでは流れを読み替える
4. 動画スピーカーが提示する **「全部入れる」前提を疑う** (環境に不要なもの・代替手段があるものは抜く)
5. 認証情報が必要な MCP は YD に明示的に依頼 (PAT/Token を出してもらう)
