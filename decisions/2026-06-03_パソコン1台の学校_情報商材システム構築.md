# パソコン1台の学校 — SNS情報商材システム構築

> SNS(Instagram リール広告 + Threads)で売る情報商材の販売システム一式を構築。
> 表の入口は「PC1台 × AI × 誰でも(主婦/学生/高齢者)で稼ぐ力」、中身の主役は **Claude Code**(サブタイトル扱い)。
> パス: `/Users/ittou/projects/CC-business`

## 状況・動機

YD の真の目的は「情報商材が実際どう稼ぐのかを自分で見てみたい」。怪しい商材が多い裏側を、本物のクオリティで一度作って回してみる実験。運用負担は最小化し、Claude にほぼ全部やらせる方針。素材は YD が約2週間で Claude Code で量産した実プロジェクト群(vidkit / 朝ブリーフィング / AI研究員 / 並列Claude基盤 等)を Obsidian Vault から解析して教材化。

## 確定事項(YD 決定)

- **ブランド名**: 「パソコン1台の学校」/ メイン「AIを、あなたの“もう一人の自分”にする学校。」/ Claude Code はエンジンとして裏方
- **価格(最終)**: ★ワンプラン。定価 ¥29,800 / 発売記念 ¥15,000・先着100名限定(以降は定価)。お試し¥1,000は当初採用→2026-06-03に廃止。先着100名は Stripe 実購入数で自動判定(100名で定価復帰)、景表法対策で¥29,800は「以降の定価(将来価格)」表示。購入で全6コース解放(単一ティア "all")
- **決済**: 本番品質 + **Stripe テストモード**(本番キー差し替えで即 Go-live)
- **トーン**: 正直×攻め。誇大広告(「必ず稼げる」)禁止、特商法表記・免責・返金ポリシー必須(景表法・特商法配慮)
- **教材形式**: 文章 + イラストのみ(動画なし)。未完成プロジェクトも「完成例」として描写してよい
- **デザイン**: Claude.com(Anthropic)準拠の温かい編集デザイン。後に YD が **Claude Design**(claude.ai/design)で生成したHTML/CSSバンドルを忠実移植
- **★ 個人特定情報は出さない**: 団体名(Salamat)・大学名(東洋大)・勤務先名(Apple)・学部名・事務所名は一般化。年齢/身分/吃音/「販売で全国トップ」「260名団体代表」等の基本情報は残す

## 構成(技術)

- Next.js 16(App Router, Turbopack)+ Tailwind v4 + Shippori Mincho/Newsreader/Noto Sans JP/JetBrains Mono(next/font)
- 決済 = Stripe Checkout(inline price_data)/ 解放 = 署名付きJWT(jose)を httpOnly クッキー、**DB不要・Stripeを真実の源**(購入復元はメール→Stripe照会)
- 法務4ページ(特商法/利用規約+免責/プライバシー/返金)、`/learn` 配下はゲート付き(intro/all)
- 教材 = 6コース・25章・**86レッスン**(`content/bodies.ts` 自動生成)、LP は Claude Design 移植版(`app/editorial.css` に `.ed` スコープで隔離)
- SNS素材 = Instagram ポスター6枚(実寸1080×1350、ポスタースタジオ `/studio/posters` を Playwright で書き出し)+ Threads原稿10 + OGP

## 採用した「品質を上げる仕組み」(YD 指示)

3人の架空人物(**みどり**=PC苦手主婦 / **リョウ**=デザイン感度高い大学生 / **田中**=元雑誌編集者AD)を並列エージェント化し、制作物をレビュー→修正集約→書き直し→再レビューの**自走ループ**を回した。

- コピー批評ループ(4ラウンド): 費用/Mac前提/実績の正直な開示、具体的な失敗談、「AIっぽい言い回し」除去
- デザイン批評ループ(2ラウンド・実スクショを画像Readでレビュー): 明朝のニセ太字→実ウェイト化、本文可読性、コーラル過多の是正、コース別アイコン

## ✅ うまく行ったこと

- **Workflow オーケストレーション**が効いた: Vault解析(6並列)→ 86レッスン執筆(25並列)→ ペルソナ批評ループ。1ターンで大量の高品質生成。
- **Claude Design バンドルの移植**: README が「ソース直読みでピクセル再現」を指示。site.css を `.ed` スコープに隔離(`app/editorial.css`)してアプリ他ページと衝突回避 → 既存の Stripe/ゲート機能を壊さず見た目だけ差し替え成功。
- **DB不要の決済解放**(JWT cookie + Stripe を source of truth)で、YD の Go-live 作業を「本番キー差し替えのみ」に圧縮。
- ペルソナ批評ループが**実際に効いた**: 「誇大広告回避」「人間が書いた文章」を機械的にではなく"読者の体温"で詰められた。デザイン批評は**スクショを画像 Read** させて視覚レビューが成立。
- イラストを**コース別に別アイコン**(人/錠/時計/棒グラフ/網/ノード)にして「全部同じ」批評を解消。

## ❌ 詰まったこと

- **PII一括スクラブの過剰置換**: `Apple`→「スマホ販売の現場」で "Apple Podcast"(アプリ名)や "Apple製"(Mac製造元)まで壊した。固有名詞の文脈(雇用主 vs 製品/アプリ)を区別せず一律置換したのが原因。→ 置換後に `grep`/文脈確認で "スマホ販売の現場 Podcast" 等を検出して個別修復。**教訓: 一律 find-replace は文脈破壊する。置換後に必ず周辺16字を目視 + 再 grep。**
- **next/font の CJK フォント選択**: Shippori Mincho を weight 600+ で使うと大見出しで「ニセ太字」に見えると批評(高コントラスト明朝の宿命)。一旦 Noto Serif JP に替えたが、Claude Design が Shippori 400/500 を採用していたため**実装側を Claude Design に合わせ**、weight 500 で軽く使う形に統一。
- **reveal-up のフルページ撮影**: IntersectionObserver で初期 opacity:0 のため、Playwright フルページ撮影だと下部が空に写る。`browser_evaluate` で全 `.reveal-up` に `.in` を強制付与してから撮影。
- ポスター要素撮影で**固定ヘッダーが被る** → スタジオを `z-[200]` で前面化して回避。
- Playwright MCP の保存先は許可ルート配下(`<project>/.playwright-mcp` か `<project>`)のみ。`/tmp` は拒否。
