# Arte Grow — 軸の再定義とフィリピン渡航確定

## 決定事項

1. **軸の再定義**: Arte Growは「支援団体」でも「物販会社」でもなく、軸は**「映像で伝えること」**。普通じゃない環境(スラム等)に入り、そこにある誇りと技術を撮って発信する。支援も物販もこの軸からの派生。モノ・金をあげる支援は根本解決にならない、というYDの原体験(Salamat)が出発点。
2. **Pride, Not Dependency のカメラ翻訳**: 貧困の悲惨さではなく、技術・誇り・生活の強さを撮る(ヨシダナギ型)。「なぜ搾取(poverty porn)じゃないのか」に一行で答えられることが生命線。
3. **収益エンジン構想**: ①メディア(YouTube/ドキュメンタリー/講演) ②コマース(Arte Grow物販) ③制作受託。映像①は物販②の最強マーケ装置(職人フィルム=商品の付加価値)。
4. **渡航確定: 2026-09-21〜10-03**(セブ滞在=9/26〜10/3、CFA訪問=10/1-2。メンバー4名: YD/Rina/Taichi/Hina。詳細=[[../knowledge/arte_grow/2026-09_渡航情報]])。位置づけは「視察」ではなく**「パイロット撮影+アクセス開拓」**。持ち帰り3点=①エピソード・ゼロ素材 ②「また来ていい」の現地関係1つ ③職人コミュニティ候補+サンプル。
5. **Manuel Stumpf に訪問打診送信済**(2026-08-08 3:26、Messenger)。CFA / Feeding & Family Center のドイツ人、ダンちゃり経由の既存の繋がり。返信が来たら2通目で映像無償制作オファー。
6. **Notion新アカウントに管理正本を新設**:「Arte Grow｜フィリピンプロジェクト」ページ+DB5つ(タスク/論点/アイデア/現地コンタクト/参考事例)。

## 背景

- 現地団体に「支援の輪を広げたい」とメール → 有料ツアー営業ばかり返ってきた。原因は「実績も具体的提案もない外国人」カテゴリに自動仕分けされたこと(向こうの標準フィルター)+慈善とビジネスの顔の混線。
- 対策3点: **オファーを変える**(映像無償制作=入場券) / **チャネルを変える**(メール→FB Messenger→対面) / **ターゲットを変える**(検索上位の有名NGOでなく草の根・教会・バランガイ)。
- 現地の信用の作り方: courtesy call→MOA・感謝状という「儀式と紙」。差別化は「また来ること」(3回目でvisitor→partner)。
- 参考モデル: ヨシダナギ / 原貫太 / Motherhouse(山口絵理子) / NasDaily / ANTHILL Fabric Gallery(セブ・商談対象) / Rags2Riches / Human Nature。
