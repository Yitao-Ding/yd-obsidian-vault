# Bitaw (ビサヤ語会話アプリ) の設計確定と v0.1 完成

## 背景

セブ渡航 (9/21〜10/3) に向けて、YD と友達2人がビサヤ語を「話せる」ようになるための iPhone アプリを作る指示 (2026-09-02)。条件: Duolingo に寄せる、Xcode で作る、AI は Claude の課金プラン内で完結、車輪の再発明はしない、使用者は3人。

## 選択肢と決定 (YD 承認済、全て推奨案を採用)

AI 経路: (A) Mac 中継 + 事前生成 / (B) 事前生成のみ / (C) ライブは Gemini 無料枠 → **A**。教材は Mac の `claude -p` で生成、会話練習は Mac 常駐サーバー (`server/relay.mjs`) が `claude -p` を叩き Tailscale Funnel で公開。Mac が落ちていればレッスンだけ動く。

音声: (A) ElevenLabs 一括生成して同梱 / (B) ネイティブ録音 / (C) Apple 代用音声 → **A** (未生成の間はインドネシア語音声で代読し「仮の声」表示)。Apple 標準音声にフィリピン系は存在しない。

発音判定: (A) WhisperKit 端末内 (タガログ判定) + Levenshtein 一致度 0.55 / (B) 録音聞き比べのみ → **A**。Apple も Whisper もセブアノ語非対応。

バックエンド: (A) Supabase + Sign in with Apple / (B) CloudKit / (C) ローカルのみ → **A** (Vault の backend-patterns と同じスタック。未設定でも全機能が動く)。

## 結果

`~/AI projects/bitaw/` に v0.1。シミュレータでレッスン・会話練習の動作確認済み。詳細は [[bitaw]] (knowledge/programming/projects/)。

## ✅ うまく行ったこと

- 初回 xcodebuild が一発で通った (WhisperKit 1.1.0 / supabase-swift 2.55 / xcodegen)
- `claude -p` は 2026-06-15 の Anthropic の方針一時停止により今もサブスク枠。`--setting-sources "" --strict-mcp-config` でコンテキスト 137k→0 トークン、36秒→3秒
- Claude が教材の "Pwede hangyo?" を "Pwede tawad?" と訂正してきた (会話練習の訂正機能が教材の品質チェックにもなる)

## ❌ 詰まったこと

- `--json-schema` を付けると 1 ターン 18〜20 秒。プロンプト指示 + 受信側検証に変更して 4〜8 秒
- `CLAUDE_CODE_SIMPLE=1` は OAuth を読まず認証エラー。`--bare` と同じ罠 (claude_mistakes A-8)
- 会話練習の相手の声は動的なので事前生成不可。今は代読。本物にするなら relay で ElevenLabs (有料) が要る

## 📋 次回同じことをするときのチェックリスト

1. `claude -p` をサーバー化する時は最初に `cache_creation_input_tokens` と real time を計測する (MCP の多い Mac は 100k 超える)
2. 構造化出力が要る場合、`--json-schema` の速度を計ってからプロンプト方式と比べる
3. Cowork → Mac の転送は tgz を device_commit_files で置いて md5 照合
4. 音声認識・合成の対応言語を最初に確認する (マイナー言語は Apple/Whisper 非対応が普通)
5. iOS から `claude -p` は叩けない。Mac 常駐 + Tailscale が唯一のサブスク内経路
