# 説明会+座談会を融合した~15分動画の構成決定

## 状況

既に編集済みの説明会動画 (4K v4) を大幅改変し、座談会 (C008、33:47) と融合して~15分の合体動画を作る方針に変更。説明会パートは「ハタチたちの雰囲気重視」に再構成。

## 決定内容

### ページ別の扱い

| 区間 | 扱い |
|------|------|
| p1〜4 | 10〜20秒でサラッと。基本説明は流す程度 |
| p5〜8 | 普通の尺。p5 から今回のハタチたちの話に入る |
| p9 | 横動画: 3〜4秒切り抜いて全画面。縦動画: 無駄なとこだけカットしてほぼ全部 |
| p10〜14 | スライド (内部動画再生込み) そのまま。リーダー紹介なので長くしない |
| p14 | 動画+日付修正版が後で届く → 仮で動画入りていで組む |
| p15〜19 | メイン雰囲気パート。プレゼン音声と共にそれなりの尺。動画を1本ずつ全画面再生。背景は同じ動画のサムネをぼかして全画面敷く |

### 字幕

- スライドに情報が書いてある場面では字幕不要。スライドが全部語る
- 必要な場面では: 目立つデザイン + 画面横配置 (Netflix スタイル)
- 白文字+固定下部配置は廃止 (背景次第で読めなくなる)

### テンポ・音声

- カットの前後に自然な間を置く (詰めすぎない)
- MKe600 収録だが小さい音・ノイズがある箇所は適宜 RMS 正規化 + ノイズリダクション
- 字幕だけに頼らず聴感でも聞きやすくする

### 尺配分

- 説明会パート: 5〜8分
- 残り: 座談会パート (後で合体)

## 実装パイプライン (20:41〜21:00 時点の進捗)

- cuts_v2.json / cuts_v2_draft.json — 新しいカットリスト作成中
- audio_process3.sh / audio_process4.sh — compressor パラメータ調整中 (makeup=1 → 4, threshold=-14dB など反復)
- render_subs.py — 字幕を左右バー方式でレンダリング (4K PNG PNG として焼き込み)
- build_fcpxml_v2.py — 新構成の FCPXML 生成スクリプト
- make_comps.py / canva/tiles/picks.json — p15〜19 の動画ピックと合成
- plan_v2_template.json — セグメント別タイプ (S=スライド全面, M=動画メイン) のプランテンプレ

## ✅ うまく行ったこと

- 前セッションで作った Canva 全ページ MP4 / PNG がそのまま流用できる
- ffmpeg + Python パイプラインが既に _cc_work に整っており、変更コストが低い

## ❌ 詰まったこと

- audio compressor の makeup/threshold のパラメータ調整を複数回繰り返した (makeup=0→1→4、threshold=-22→-14dB)。log から最終値を確認してから固定すること
- 字幕配置: 白文字固定下部が見づらい問題が発覚 → Netflix 横スタイルに変更

## 📋 次回同じことをするときのチェックリスト

- 説明会+座談会の合体動画では、説明会パートを「雰囲気重視」に先にリストラしてから座談会を後ろに接続する順で作る
- p15〜19 の背景ぼかしは `make_comps.py` の picks.json を先に確定させてからレンダリングに入る
- p14 は動画+日付修正版を待ってから差し替える (placeholder で組んでおく)
- 字幕はスライド表示中は非表示にする条件を cuts_v2.json の type フィールドで管理
- audio の最終 compressor パラメータを audio_process4.log から確認してから FCPXML に組み込む
