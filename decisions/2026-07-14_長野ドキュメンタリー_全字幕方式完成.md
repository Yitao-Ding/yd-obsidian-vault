# 長野ドキュメンタリー: ナレ廃止→全字幕方式で2本完成 (DaVinci Resolve API 自動構築)

## 状況

2025-07-06 のダンちゃり長野訪問素材 (Sony 23 + DJI 24クリップ) から、DaVinci Resolve 版ドキュメンタリーをゼロから制作。当初は Phase 1 (台本+YD地声ナレ録音) → Phase 2 (実装) の2フェーズ計画だったが、Phase 1 完成後に YD 指示で**ナレーション廃止・全字幕 (テキストカード) 方式に転換**し、録音待ちなしで最後まで一気通貫。

## 選択肢と選んだ理由

- **ナレの代替**: A. AI音声 / B. 全字幕カード → **B採用** (YD指示。地声の代役をAIにやらせない、字幕なら再編集も文言修正も再実行一発)
- **テロップ実装**: A. Resolve Text+ / B. Pillow PNG→ProRes4444焼き込み → **B採用** (ミニテストで Text+ のフォント名サイレント失敗を実測。88本のテロップを確実に制御するには B が唯一の安全解。詳細 [[davinci_resolve_api]])
- **ビルド先DB**: A. kodama クラウド (YD標準) / B. ローカルDB → **B採用** (クラウドはセッション切れで PM API 全死を実測。.drp 書き出しで引き渡し可能なので安定性優先)
- **確認事項が未回答のままの制作続行**: 施設名=クレジットのみ「NPO法人 一匹でも犬・ねこを救う会」/ 人名=伏せる / 誘導先=なし / BGM=Kevin MacLeod 流用 / タイトル=仮のまま採用 等、保守側デフォルトで代行判断 (一覧は `davinci/README.md`。YDが変えたら design.py 修正→再実行で反映)

## 成果物

- 前編「91匹の家」5:02 / 後編「蛇口を閉める人たち」5:06 — 4K H.264、-14 LUFS、`render/{zenpen,kouhen}_4K_v1.mp4`
- Resolve プロジェクト `NaganoDoc_v2` (ローカルDB) + `davinci/NaganoDoc_v2.drp`
- 再生成可能パイプライン `davinci/build/` (design.py が唯一の真実)

## ✅ うまく行ったこと

- **司令塔(Fable)=構成・台本・裁定、実装=Opus/Sonnet便、検証=Workflow 11便並列**の分業が今回も機能。指摘14件を1ラウンドで潰して4Kまで到達
- 台帳 (QUOTES_FINAL/shotpicks) 起点の設計で、字幕の事実正確性が考証レビューで致命ゼロ
- 検証エージェントの critical 誤検出 (I-K4a) を監督の実フレーム反証で棄却 → 無駄な手戻りゼロ
- SSD切断・API接続断・クラウドDB死のトラブル3種を全部自動/半自動で復旧して完走

## ❌ 詰まったこと

- 白文字カードが露出オーバー背景で溶ける (major 4件) → ストローク+二重シャドウの3層描画で解決。**最初からストローク前提でデザインすべきだった**
- B-roll 2枚の配置ミス (OUTROのオチの先出し / 文脈違いのドアップ) — 設計時にフレーム未検証の候補をそのまま使った箇所で発生。差し替えで解決
- Blackmagic Cloud ライブラリのセッション切れで PM API 全死 (GUI でしか復旧できない) → 詳細 [[davinci_resolve_api]]

## 📋 次回同じことをするときのチェックリスト

1. 撮影素材→台帳 (QUOTES確定字幕+shotpicks) を先に固める。設計は台帳からのみ引く
2. テロップ多数なら最初から PNG焼き込み + ストローク付きスタイル
3. design.py (単一の真実) → manifest → 素材生成 → タイムライン → 検証、の再生成可能パイプライン構造を踏襲 (`davinci/build/` をテンプレとして流用可)
4. 検証は「テキスト全数フレーム検分 / B-roll内容 / 音声実測」の3系統を Workflow 並列で。critical は監督が実フレームで裁定してから手を打つ
5. 長時間ビルドはローカルDB。最後にクラウドへ GUI 復帰
6. 未回答の確認事項で止まらない場合は、保守側デフォルト+代行判断の一覧化 (README) + 「design修正→再実行で変えられる」構造にしておく

## 追記 (2026-07-15): v3 で1本化して最終完成

YD指示で前後編を廃止し **本編「91匹の家」1本 (9:40)** に統合、`render/honpen_4K_v1.mp4` (3.95GB) が最新の完成品。合わせて「DJIはインタビュー音声用、壁・街歩き映像は画面に出さない」方針でBロールを18本に増量 (Q02/Q03/Q06は全面カバー、Q07→Q08のジャンプカットはカットまたぎインサートで隠蔽)。手ミックス用の `honpen_edit` (A1=クリップ生音独立 / A2=BGM区間独立) も新設。検分で得た教訓: **shotlog standout の秒数は±10sズレうる → 未検証スパンはProxyのフレームグリッドでプローブしてから採用** (詳細 `davinci/DIRECTOR_NOTES.md` ラウンド3)。前後編版の4K 2本は履歴として残置。
