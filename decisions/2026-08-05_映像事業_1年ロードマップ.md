# 映像事業 1年ロードマップ (2026-08 → 2027-08)

## 結論

12ヶ月後に映像売上 月50万。柱は3本 — ①寝てる実績の資産化 (8月中) ②ダンス特化のSNSエンジン ③スタジオ発表会パッケージの直販。開拓は紹介に頼らず自力で行う (YD意向 2026-08-05)。

## 前提 (2026-08-05 時点)

- 進路 = Apple + 映像 + 事業の3タテ (企業就職はしない)
- Apple: Advisor継続 or Specialist (8/13面接、横浜NSO時期未定)。どちらも時給約¥2,100、週3-4×8h → 月24〜28万。土日マスト、希望休は前月15日締め
- 映像の有償導線: 現状ほぼゼロ。プペル (年2回開催) 以外は無償実績 (平成たち祭・ダンちゃり長野は無料、JAMBOREEは単発¥70,000で継続性薄)
- @yitao_film はほぼ停止中。SNS戦略をゼロから構築する
- 平日は映像にフルで使える

## 数字の設計

マイルストーン: **3ヶ月で月10万 → 6ヶ月で25万 → 12ヶ月で50万**

月50万の構成イメージ:

- 発表会/イベント パッケージ 25万 × 1本
- MV/アーティスト撮影 10〜15万 × 1本
- SNS動画リテイナー 4〜5万 × 2〜3社

Apple 25万前後と合算で月商75万規模。年商600万ペースが見えた時点で法人化 (OOO Studio) を判断する。

## 週の運用モデル

- **平日**: 編集 / SNS制作・投稿 (週3本) / 営業DM 10〜15件
- **土日**: Apple。**毎月「土1日+日1日」を撮影スロットとして先行で希望休申請** (前月15日締め)。撮影が入らなければ編集日に転用
- **リードタイム規則**: 土日撮影の受注は6週間以上先の日程で提案する。短納期案件は平日撮影のみ受ける

## Q1 (2026-08〜10月): 基盤づくり

- [ ] **公開許可の取得**: 平成たち祭 / ダンちゃり長野 / JAMBOREE / プペル → リール切り出し12本をストック。無償案件の対価は公開権・クレジット・紹介 — 今後は受注時に必ず条件化する
- [ ] **IG再始動**: ポジショニングは「ダンスを撮る映像作家」一本。週3投稿、IG/TikTok/Shorts同時配信
  - 柱1: 作品切り出しリール (カラーグレーディング before/after 含む)
  - 柱2: BTS・撮影ノウハウ (FX30設定、照明、ジンバル)
  - 柱3: **応募制ダンサー撮影企画** (月1回・無料・本人シェア条件) — 平成たち祭応募フォーム企画の常設化。出演者のフォロワーに毎回リーチする拡散装置
- [ ] **料金表v1**: 発表会パッケージ (記録+ダイジェスト+ショート) 15〜25万 / MV 10〜15万 / リテイナー月4〜5万
- [ ] **ポートフォリオサイト再稼働** (休眠中のYitao Filmサイト。実績+料金+問い合わせフォーム)
- [ ] **営業リスト**: 都内ダンススタジオ50件 → DM/持ち込み開始。12月発表会シーズンから逆算し、**10月中旬までに提案を届ける**
- [ ] 開業届 + 青色申告承認申請
- [ ] 9月フィリピン視察 (Arte Grow) でドキュメンタリー素材を撮る → 3〜5年軸「国際協力×ドキュメンタリー」の種まき。IGでは番外編扱いにして軸ブレを防ぐ
- **KPI**: 有償1件目成約 / フォロワー500 / 月売上5〜10万

## Q2 (2026-11〜2027-01): 発表会シーズンで初期収益化

12月は発表会の最盛期。Q1の営業はすべてここに照準を合わせる。

- 発表会パッケージ2〜3本の受注・納品
- 応募企画の出演者からMV・個人撮影への転換を狙う
- **KPI**: 月25万 / リテイナー1社 / フォロワー1,500

## Q3 (2027-02〜04): 安定化

- リピート+紹介ループの確立 / 値上げ第1弾 / 春の新歓・イベントシーズン獲得
- **KPI**: 月35万 / リテイナー2社

## Q4 (2027-05〜07): 50万到達と選別

- パッケージ値上げ / 割に合わない単発案件の選別開始
- OOO Studio 法人化判断 (インボイス・消費税・Hi,Me:) 持ち分の合意が論点)
- **KPI**: 月50万

## 3〜5年の方向 (仮置き、次回議論)

- 短期はA×B (ダンス特化 × AIパイプラインの利益率) で稼ぎ、C (国際協力×ドキュメンタリー) を作家性資産として育てる
- OOO Studio = 器。チーム化 (Taichi構想) は売上が安定してから
- 汎用の「なんでも撮る映像屋」化は価格競争に沈むためやらない

## リスクと対策

- 発表会シーズン依存 → リテイナーで月次を平準化
- 希望休が間に合わない案件 → 平日撮影を提案して拾う
- SNSが3ヶ月で伸びない → 応募企画の頻度を上げる / 少額広告テスト (¥500×数日から)
- 無償案件の引力 → 公開権+クレジット+紹介1件を必須条件にする

## ✅ うまく行ったこと

- 「企業案件は映像会社経験がないと無理」は誤解と整理できた — 発注側が見るのはジャンル一致のポートフォリオ。障害は経験ではなく導線
- Appleシフト制約 (前月15日締め) を「先行希望休+リードタイム規則」という運用に変換できた

## ❌ 詰まったこと

- 有償導線が実質ゼロと判明 (プペル年2回・JAMBOREE継続薄・他は無償)。実績はあるのに全部非公開で、資産化されていなかった
- 士業 (ともに) ルート・人脈紹介 (Metaliana等) ルートはYD意向でパス → 自力開拓前提に設計変更
- ウェディングは式場提携構造で直受け参入がきつく、下請けは低単価+土日拘束のため不採用

## 📋 次回同じことをするときのチェックリスト

- 収益設計は「単価 × 導線 × 稼働」の3変数で置く。導線がゼロなら導線づくりから
- 無償案件は受注時に公開権を必ず条件化する
- シフト制約は受注リードタイムに織り込む (締め日から逆算)
- 単品売りせずパッケージで切り出す (JAMBOREE 7万の教訓)
