# 2026-05-26 新アプリ大方針再定義 (パートナー雑談議事録より)

## 決定

Project Agent Application の方向性を、「Teams ライクなタスク管理アプリ」から **「チームで頑張る過程を青春にして、頑張りを可視化する Z 世代向けハイブリッドアプリ」** に再定義する。

## 背景

2026-05-26、YD とパートナーの雑談セッションで、Salamat 経験を根拠にした多数のキラーアイデアが出現。録音 → 文字起こし → Gemini 整理の手順で議事録化したものを Claude Code に投入し、本決定に至る。

### 出典

- 生ログ: `~/ObsidianVault/raw/meetings/2026-05-26_新アプリ議事録_yd_partner_生ログ.md`
- Gemini 整理版: `~/ObsidianVault/raw/meetings/2026-05-26_新アプリ議事録_yd_partner_gemini整理.md`

## 方針シフトの本質

### 旧方針 (2026-05-23 〜 05-25)

- 大学生・若年層向け Microsoft Teams ライクなプロジェクト/タスク/チーム統合管理アプリ
- 5 階層モデル + RLS + リマインダー + 軽量チャット
- ベンチマーク UX 採用 (Discord/Spotify/Instagram/BeReal/Finch/Duolingo)

### 新方針 (2026-05-26 〜)

- **「チームで頑張る過程を青春にする」** がコアバリュー
- **「頑張りを可視化する」** ことで Z 世代の自己肯定感を支える
- 「タスク管理」は手段、目的は青春創出 + 頑張りの可視化 + 100% やりきれるチーム体験
- 「全部のハイブリッド」 = 青春 + 頑張る人応援 + 次世代タスク管理 (YD 明言)

## 確定: 5 つのキラー機能を MVP に追加 + 2 つのコンセプト統合

### 1. お宝箱 (仮称、タイムカプセル機能) ★ YD「これだけで勝ち」「他のどのアプリにも絶対勝てる」

- ミーティング中に「今から N 時間以内に写真撮って」と通知 (BeReal/Setlog インスパイア)
- 撮ったデータは **プロジェクト完了まで非公開**
- リーダーがプロジェクト「完了」を押した瞬間に、PJ 期間中の写真・動画が **1 本の思い出ムービーに自動生成**
- 名前は「お宝箱」「タイムカプセル」とも仮称、後で確定 (planner にネーミング案 5 つ依頼)
- 派生用途: 学年クラスラインのように 1 年間使われる広がりの可能性 (YD 強調)
- Sprint 08 で実装

### 2. 振り返りダイジェスト (4 粒度) ★

- お宝箱と同じ素材を使って、4 つの粒度でダイジェスト生成
- ★ お宝箱と振り返りは「素材箱」と「出力」の関係 (混同しないこと、YD 明言)
- Sprint 09 で実装

| 粒度 | トリガー |
|---|---|
| PJ 単位 | PJ 完了時 |
| 月単位 | 月末自動 |
| 半年単位 | 6 月末・12 月末 |
| 1 年単位 | 年末 (Spotify Wrapped 風) |

### 3. ポートフォリオ共有

- アプリ内プロフィール欄: 名前 + 特技 + 特徴 + 達成 PJ 数 + 総合ポイント (PJ 規模で換算)
- 「**プロフィール欄がそのまま共有可能リンクになる**」のがコア
- インスタの自己紹介欄に貼って「ちょっと意識高い」イメージを醸成
- 将来: 就活ポートフォリオサポートへ拡張
- ★ 年末振り返り (= Spotify Wrapped 風) とは別機能 (Claude の前回認識違い、訂正済)
- Sprint 10 で実装

### 4. AI Recognition (褒める一言診断)

- PJ 完了時、Apple Store の Recognition 文化インスパイア (1 on 1 / Recognition カード)
- アプリ内の動き + 期限厳守率 + 寄せ書き文字数 などを材料に **Gemini API で診断**
- 例: 「縁の下の力持ち」「明るく元気なファッションリーダー」「情熱的、インスパイアに満ち溢れた」
- Sprint 10 で実装

### 5. 寄せ書きコーナー

- PJ 完了でタスク管理ページが寄せ書きに変化
- メンバー同士で一言メッセージ
- Sprint 05 (軽量チャット) に統合

### + タスクお掃除コンセプト (キャラ拡張)

- ホームのキャラ (コハル) の足元がゴミだらけ → タスク完了で減る
- 「掃除完了おめでとう」演出
- 仮称、後で確定
- Sprint 07 (キャラ + ホーム) に統合

## 確定: 技術スタック追加

- **AI: Gemini API** (Free 1500 RPD → 有料 Gemini 2.5 Flash $0.075/M tokens)
- ★ Anthropic API は **採用しない** (商用配布のため Max 20x 個人プラン不可、Claude の認識違いを YD が訂正)
- API key は Supabase Edge Function で隠蔽 (フロントエンドに置かない)
- 既存の React Native + Expo SDK 53 + NativeWind v4 + Tamagui + Reanimated 3 + Supabase + Expo Notifications + Expo AuthSession + Expo Router は維持

## 確定: 招待制は採用しない

議事録の「BeReal/招待制 SNS のレア感」言及は誤読、招待制は採用しない。**誰でも DL 可能** な普通の配布。意識高い層へのニッチ刺しは自然な口コミ + インスタストーリー導線で実現する。

## 確定: マーケティング戦略

- **インスタストーリー導線** (PJ 開始「今日から頑張るぞ」/ 完了「やったー!」画面が共有しやすいデザイン)
- **意識高い大学生にニッチ刺し** (招待制で絞らずに自然な口コミ)
- 先行体験: Salamat 内 PJ + ハタチタチ
- ウェイトリスト/口コミ熱量 → リリース (議事録「先行体験者がプロモーターになる」)
- マネタイズ: 初期赤字 OK (Gemini Free 枠で MVP 中はコスト 0)
- 長期: **100 億バイアウト目標** (Google 等の大企業に売却)
