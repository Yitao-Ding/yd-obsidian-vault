# 2026-08-28 ハタチたち公式HP スタック確定 + Phase 1 実装

## 状況

ハタチたち (その年の二十歳100人で作るダンス映像プロジェクト、ハタチたち5開催決定) の公式HPを作る。デザイン草案は Canva「ハタチたち - Webサイト」(Linaさん共有、1ページ7セクション。ヒーロー/NEWS/ABOUTは実コンテンツ済、残りはプレースホルダー)。YDの依頼は「バックエンドとフロントエンド整えたい」。

## 決定 (YD回答)

- 更新の仕組み: microCMS 無料枠 (news / archive / site の3 API)。運営が毎年二十歳の代に総入れ替えするため、非エンジニアが管理画面で更新できることを最優先
- Instagram: 手動埋め込み (公式blockquote、URLはmicroCMSで差し替え)。Meta API・外部ウィジェットは運用が重いので不採用
- 公開先: Vercel + 最初から独自ドメイン
- サイトの役割: ①信頼性の担保 (保護者・会場・協賛向け) ②当日の告知・案内。応募フォームは外部リンクで十分
- スタック: Next.js 16.2.6 + React 19 + Tailwind v4 (salamat-website-v2 と同構成)。SSG + Webhook再ビルド + revalidate 3600保険
- プロジェクト: `~/AI projects/hatachi-tachi-website` (git初期化・初回コミット d4498e4)

## ✅ うまく行ったこと

- Canva共有リンクは未認証でも Playwright で編集ビューを開けて全セクション実見できた (ログインモーダルを閉じてスクロールコンテナを直接操作)
- microCMS未接続でも `src/content/site.ts` のフォールバックで全ページのビルドが通る設計にした → YD入力待ちでも実装を止めずに Phase 1 完了
- salamat-website-v2 の構成 (next.config の turbopack root pin / eslint.config / pnpm-workspace.yaml の allowBuilds) をそのまま流用して初回ビルド一発通過に近い状態

## ❌ 詰まったこと

- pnpm 11 の `allowBuilds` (sharp / unrs-resolver) が無く初回ビルド失敗 → salamat と同じ pnpm-workspace.yaml で解決
- VerticalText コンポーネントに `inline-block` を固定で持たせたら呼び出し側の `hidden` と display 競合してモバイルに縦書きが漏れた → display は呼び出し側指定に変更
- Next 16 は cacheComponents 有効時に `export const revalidate` が削除される仕様。今回は無効のまま従来モデルで回避 (有効化しないこと)

## 📋 次回同じことをするときのチェックリスト

1. Canvaの草案は canva.link を Playwright で開けばログインなしで実見できる (モーダル閉じ → スクロールコンテナを scrollTop 操作)
2. microCMS無料枠は API 3個 / メンバー3人。コンテンツモデルを先に3個以内に設計してから着手
3. CMS系サイトは「env無しでもフォールバックでビルドが通る」を最初に作る (入力待ちで実装が止まらない)
4. pnpm 11 新規プロジェクトは pnpm-workspace.yaml の allowBuilds を最初に置く
5. Tailwind: 表示切替するコンポーネントに display ユーティリティを固定で埋め込まない
6. Webhook は全APIに登録 (設定系オブジェクトAPIを忘れがち)

## 実測カラー値

Canvaスクリーンショットから PIL で抽出した実測値 (定義場所は `src/app/globals.css` の `:root`。site.ts ではない):

- 紺: `#1f469d` — NEWS帯 / ボタン文字。仮置きは `#22409a`
- ヒーロー背景: 温かみのあるオフホワイト `#f5f3ee`〜`#fcf9f2` (仮置き `#f7f3ee` はほぼ正解)

コントラスト実測: 白文字 on `#ff5757` = **3.11:1** → WCAG AA の本文基準 4.5:1 に不足 (大文字基準 3:1 は充足)。白文字 on `#1f469d` = 8.67:1 で問題なし。ABOUT は珊瑚レッド全面に白本文が乗る草案なので、ブランド色を保ったまま AA を満たす方法の判断が要る。
