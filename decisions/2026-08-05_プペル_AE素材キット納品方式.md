# プペル エンドロール: AE素材キット方式へ転換

日付: 2026-08-05
決定者: YD

## 決定

Part A の仕上げは HTML直レンダー (puppeteer→ffmpeg) ではなく、**素材単位でAEに落とし込み、YDがAE 2026で編集**する方式にする。

## 内容

- 背景素材をレイヤー分解してアルファ付き書き出し (4K基準=2倍解像度):
  bg_sky / stars_tile / town_tile(窓込み) / smoke_plate_loop.mov / grain / ポラロイド枠2種
- 煙は 12.012秒=59.94fpsで720フレームの**完全ループ** ProRes 4444 (gen_town.py の煙周期を統一して実現、seed互換維持)
- クレジット文字はPNG化せず **AEネイティブテキストレイヤー** (HiraMinProN-W6/W3, Baskerville-Italic)
- .aep は after-effects スキル (ExtendScript/osascript) で自動構築:
  `_cc_work/ae/プペル_PartA_kit.aep` + README.md
- スクロールは2枚タイル + `[3840-(time*スライダー)%3840, y]` expression (速度スライダー化)

## 学び (次回に効く)

- AEコールドスタート中のDoScriptは60秒タイムアウトで死ぬ → **先にAEを起動させてから (or 軽いクエリで疎通確認後) 本番スクリプトを送る**
- AEのセキュリティ設定 (スクリプト書き込み許可) をスクリプトから変更するのは Claude Code の安全機構がブロックする (今回そもそも設定オン済みで不要だった)
- CSS/SVGアニメの完全ループ化: 全アニメの周期を出力fpsのフレーム整数倍 (720/59.94=12.012s) に揃える。乱数順序を保てば見た目互換を維持できる
