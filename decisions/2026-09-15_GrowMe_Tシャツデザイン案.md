# Grow me:) 渡航Tシャツのロゴデザイン案 (前面・背面、リメイク版)

## 状況

9月フィリピン渡航 (LINE グループ「じじばばGrowMe」の4人) で着るオリジナルTシャツ。YD の要件は、前面 = 左胸 10×10cm に Hi,Me ロゴと Arte Grow ロゴを融合させた小さいロゴ、背面 = 背中いっぱいに、YD と太一のカメラ、metalina と日菜のダンスの2要素を融合させ「新しい地で挑戦・調査する」意気込みを込めたデザイン。既存の素材を活かしつつ、複雑にせず見たら分かるもの。印刷はカラフル転写、使用者は4人のみで商用化しない。

1版目は2つのロゴ画像を切り出して並べたが、YD から「文字が見切れている (Me の M など)」「繋ぎ合わせではなくリメイクに」と指摘。2版目で全部ベクターで描き直した。

## 作ったもの (2版目 = 現行)

Claude Design のキャンバス https://claude.ai/artifact/6q5zugKobq7qP7QdqxFhLN に5枚。

前面 A「Grow Me」(主案): Titan One を土台に1文字ずつ傾けた太いレタリング。「o」をカメラ (黒いボディ、ファインダーの出っ張り、白い丸レンズに黒い玉とハイライト) に置き換え、ボディ右上に Arte Grow の黄色い光。G の後ろに Arte Grow の青い絵の具の飛沫、M の中に Hi,Me のハート、e に Hi,Me のスマイル (白い目2つと口。Titan One の e の小さい穴は黒で埋めて顔の面を作った)、Grow と Me の下に Hi,Me の赤と青の二重線。スマイルは最初レンズに入れていたが、YD 指示「本来は e にニコちゃんが付いているからそっちに」で e に移し、レンズは普通のレンズにした。
前面 B「Camera」: カメラ単体を大きく、下に Grow Me の文字 (e にスマイル)。
背面 A「Dancing Camera」(主案): 上に前面 A のレタリングを横一列、中央にフィリピン国旗の8条の太陽、その上に同じカメラに手足を付けて踊らせたマスコット。下に PHILIPPINES 2026 と訪問地 (MANILA · TONDO · CEBU · SELMA · LUMBANI · TAPUL)、09.23 – 10.03 · CAMERA × DANCE。
背面 B「Viewfinder Tour」: ファインダー枠 (REC 付き) の中にレタリング、PHILIPPINES の大文字、ツアーTシャツ風の日程リスト、小さい太陽。
Tシャツ配置プレビュー: 前後のシャツ形に A/B を切り替えて載せられる。

印刷データは `~/AI projects/GrowMe-Tshirt/print/` に4案とも 300dpi 背景透過 PNG (前面 1181×1181 px = 10cm、背面 3544×4375 px = 30×37cm)。生成スクリプトは `work/gen.py` (これが正本。4枚の .dc.html を書き出す)。

## 決めたこと・前提

- ロゴ画像の貼り込みはやめ、要素 (太い文字・カメラのブロック・スマイル・ハート・飛沫・光・二重線) をベクターで描き直す。フォントは Titan One (レタリング) と Anton (英字の情報)
- Tシャツは白系を前提。黒地にするなら色反転版が必要
- A/B の選定は4人で行う。Claude は決めない

## ✅ うまく行ったこと

- 「Grow Me」の o をカメラにするだけで「カメラ×ダンス (Hi,Me のスマイル)」が1つの単語に収まった。文字の切れも無くなった
- 4枚とも `gen.py` の関数 (camera_svg / sun / splat / underline / wordmark) から生成しているので、サイズや位置の直しが1か所で済む
- Playwright で .dc.html を単体レンダリングし、キャンバスに載せる前に見切れと衝突を潰した。印刷データも同じファイルを deviceScaleFactor で拡大して透過出力

## ❌ 詰まったこと

- 1版目はロゴ画像の切り出しで作ったため、M の左端が切れ、Grow の w がアートボードからはみ出し、A の脚を消した G に欠けが残った。ロゴ画像を継ぎ接ぎすると、切り出し境界がそのまま「見切れ」になる
- Titan One の文字幅は見積もりより広く、Grow (196px) と Me を同じ行に置くと衝突した。背面は Grow 172〜176px、Me 184〜190px、Me の x を 720 以降にして解消
- `read_multiple_files` で Vault を一括読みすると 18万文字で上限を超えた。identity/ と current_state/ は分けて読む

## 📋 次回同じことをするときのチェックリスト

1. デザインの正本は `~/AI projects/GrowMe-Tshirt/work/gen.py`。直すときは gen.py を編集 → `python3 gen.py` → 各 .dc.html を Playwright で確認 → 再シード → 同じ URL に再公開
2. 印刷データは scale 1.5625 (前面 10cm) / 3.125 (背面 30cm) で透過レンダリング (`.note` を消し、背景を transparent に)
3. ロゴを組み合わせる依頼は、画像の貼り込みではなく要素を抜き出してベクターで描き直す。切り出し境界は見切れとして見える
4. 黒Tシャツにするなら反転版 (黒→白、レンズと文字の白→黒) を先に作ってから見せる
5. 入稿前にカラフル転写の最大サイズ (A3 = 29.7×42cm が多い) に背面 30cm 幅が収まるか確認する。収まらなければ 29cm に落とす
6. 縮小版アセットは別ディレクトリに出し、作業ディレクトリの原本を上書きしない
