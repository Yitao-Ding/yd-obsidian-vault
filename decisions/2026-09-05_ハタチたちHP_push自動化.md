# ハタチたちHP: push を確認なしで自動実行する

YD 指示「次からは自動でPushして」。

## 背景

スマホ表示の修正を2回続けて出したとき、毎回「push していいですか」と確認を取っていた。
グローバル CLAUDE.md に「push は YD の許可を得てから」と書いてあるため。
このサイトは YD 個人の持ち物でレビュアーが他にいない。壊れても直せばいいだけなので、
確認のラリーのほうがコストが高い。

## 決めたこと

hatachi-tachi-website では、コミットと `git push origin main` を確認なしで実行する。
push すると Vercel が hatachitachi.com に自動デプロイされるが、それも含めて確認不要。

条件は、ローカルで `pnpm lint` と `pnpm build` が緑であること。
デプロイ完了まで見届けて、結果を1回で報告する。

## 範囲

**確認を省くのは push だけ。** 以下は従来どおり事前に確認する。

- ドメイン・DNS の設定変更
- 支払いが発生する操作、アカウント設定の変更
- `rm` / `kill` / sudo などの破壊的操作
- 設計の大方針の変更

今のところ hatachi-tachi-website に対する指示。他のリポジトリでは
グローバル CLAUDE.md の許可制が生きている。広げる場合は YD の明示指示が要る。
