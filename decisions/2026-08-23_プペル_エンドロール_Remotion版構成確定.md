# プペルエンドロール Remotion版 構成・ビジュアル確定

## 確定した意思決定 (優先度順)

### 1. エンドロール全体構成 (v6確定)
- 0:00〜1:32: クレジットロール (演目20枠、映画式等速スクロール)
- 1:32〜2:04: メイキング映像 + スタッフローワーサード5枠 (各約6.4秒)
- 2:04: サビ頭で0.6秒の消灯暗転 → 終了
- 総尺124秒 (旧仕様2:02→2:04に変更)

根拠: 参照動画 (前回エンドロール) の構成を忠実に再現。「曲調が落ち着く1:32でロール終了」「2:04サビ頭で暗転して幕が上がる」はYD口頭指示 2026-08-23 23:25。

### 2. 背景モーション: 右→左スクロール (YD採択 2026-08-23 17:19)
- 鏡像タイル3840px帯を14px/sで等速スクロール
- 2案 (スクロール vs ドリーイン) を25秒プレビューで比較提示 → YDがスクロールを選択
- ドリー案は `EndrollDolly` コンプとして温存
- 採択理由 (Claude分析): クレジットが読み物として主役なので、方向が直交する背景の動きが引き算として機能する

### 3. 写真カードのアニメーション: 枠固定・写真クロスフェード (YD指示 2026-08-23 17:20)
- ポラロイド枠の傾きは固定 (回転アニメなし)
- 中の写真・動画のみ0.5秒フェードアウト/インで入れ替え
- 動画は6秒クリップ化してループ再生

### 4. 背景ビジュアルの修正 (v4, v5)
- v4: 窓を建物実面のみに限定。奥行きで3段階 (近景=明・密/中景=中間/遠景=窓なし)。`gen_windows_v2.py` (seed固定+レクト内クランプ)
- v5: 煙突シャフト・縞帯・配管・マスト・タンクを除外ゾーン化。窓351→244個。機械検証+拡大目視で確認

## ✅ うまく行ったこと

- **データ駆動レンダリング**: programs.json 1ファイルで全20演目を管理。メンバー数4〜30名の可変組版が決定論的に動き、`npx remotion still` で任意フレームを瞬時に確認できた
- **プレート方式のQC**: DesignのHTMLをChromeで4Kレンダリング → AEフレームとピクセル差分照合 (0.047%) で「見た目が違う」問題を完全排除
- **プレビュー先出し → 全編**: 背景モーション2案を25秒クリップで出してYDに選ばせる → 決定 → 全編焼きの流れが効率的だった
- **窓生成スクリプト (gen_windows_v2.py)**: seed固定で再現性を担保しつつ、除外ゾーン定義を追加するだけで対応できる構造

## ❌ 詰まったこと

- **Claude DesignのSVGダウンロード**: ブラウザのCORS/DL制限でcurl・連続DL・base64転送がことごとくブロックされた。最終的にクリップボード経由 (`navigator.clipboard.writeText` → `pbpaste`) で1ファイルずつ転送した
  - 解決策: `GetFile` API (内部エンドポイント `/design/anthropic.omelette.api.v1alpha.OmeletteService/GetFile`) でSVGテキスト取得 → クリップボードへコピー → `pbpaste > filename.svg`
- **窓の浮き問題 (2回発生)**: v4で「建物のないところに窓が浮く」→ v5で「煙突に窓が乗っている」を指摘された。2段階の精査が必要だったが、最初から「建物レクトのみ対象かつ煙突類を除外ゾーン化」をセットで実装すべきだった
