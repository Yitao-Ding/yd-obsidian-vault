# AI学習スプリント開始 + 朝ブリーフィング + 教科書システム

## 背景

YDがClaude Max 20xプラン (月$200) に契約しているが、1日あたり10%も消費できていない状態。
お金は問題ないが「使い切れない罪悪感」が発生。

進路は決定済み (就活フェーズ終了)、AI学習に本気で振り切るタイミングと判断。
「めちゃくちゃ勉強したい」「AI資格は確実に取りに行く」というYDの宣言を受けて、
3つの並行システムを立ち上げる意思決定。

## 決定事項

### 1. AI学習スプリント

**登録メアド**: `save.yitao@gmail.com` (Claude.aiと同じ、AI系専用)

**順序**:
1. **Anthropic Academy 全コース完走** (今週〜来週)
   - URL: https://anthropic.skilljar.com
   - 17コース、全部無料、メール登録のみ
   - 1日1-2コースペース、2週間以内に証明書17枚LinkedIn直貼り
2. **Claude Certified Architect Foundations** (5月末〜6月)
   - 60問試験、5領域 (エージェントアーキ + Claude Code が最重点)
   - Partner Network経由
3. **Google AI Professional Certificate** (6-7月)
   - Coursera経由、Google AI Pro 3ヶ月無料付き
4. **Google Cloud Generative AI Leader** (7月以降、余裕あれば)
   - $99試験、90分、4領域

**進捗管理**: `learning/ai_certifications/` 配下に各コースのログ・受講メモ。

### 2. 朝ブリーフィング システム

**配信時刻**: 毎朝 7:30 JST (cron自動)
**配信形式**: 図解PDF + 音声版 (TTS mp3)
**配信先**: Google Drive 自動アップロード (iPhone Driveアプリで通勤中閲覧)

**内容構成 (毎日)**:
- 業界ニュース3本 (AI / 撮影 / 開発ツール)
- ポッドキャスト新着サマリ (英: Tim Ferriss / Lex Fridman / Acquired / My First Million / All-In、日: COTEN RADIO / Off Topic / 西野亮廣 / a scope)
- 「今日読むなら」推薦書1冊 (ビル・ゲイツ最新リスト + 古典全ジャンル統合)
- 「今日のAIコース」推薦1本 (Anthropic Academyの進捗に応じて)
- (任意) 新刊・新ツール・新コース情報

**デザイン要件**:
- 縦長PDF (iPhone最適化、16:9のスライド形式は不採用)
- フルカラー、図解必須、雑誌っぽいレイアウト
- 情報量多め、スタイリッシュでかっこいい

### 3. YD専用教科書システム

**置き場所**: `~/ObsidianVault/textbook/` (構造) + Google Drive (公開PDF)
**形式**: 縦長PDF (iPhoneで読みやすい)
**対象レベル**: 「HTMLって何?」「ターミナル怖い」レベルから始める = ゼロ前提
**長さ**: 1教材あたりじっくり読める量 (A4 数枚〜10枚程度)
**コードサンプル**: 実コードベース、解説は日本語

**構造**:
```
textbook/
├── README.md (目次・進捗)
├── 00_basics/ (HTML/CSS/JS/Git/ターミナル基礎)
├── 01_web_development/ (Next.js / Vercel / WBS実例)
├── 02_video_processing/ (vidkit / FCPXML / Python)
├── 03_ai_engineering/ (Claude API / MCP / プロンプト設計)
└── 04_tools/ (Vercel / Firebase / Supabase / Git運用)
```

**統一フォーマット**:
1. 何が起きた? (実例)
2. 図解 (Mermaid / 画像)
3. キーコンセプト
4. コード解説
5. 次やる時のチェックリスト
6. 関連リンク

**第1号教材**: 「Claude Code 4並列で何が起きてるか」(YDの今の困りごと直撃)

### 4. 権限ポリシー (再確認)

既に2026-05-19朝に整備済みの権限設定をそのまま活用:
- ファイル編集・ローカルコマンド: 自動
- git add / git commit (ローカル): 自動
- git push / Vercel deploy / sudo / rm: 確認必要

**全権限バイパス (`--dangerously-skip-permissions`) は採用しない**。
代わりにプロンプト側で「自走力MAX」指示を仕込む:
- エラーに遭遇したら3回まで自力で解決を試みる
- 4回目で人間に質問せず、別アプローチを取れ
- 「権限がない」「分からない」で止まるな、迂回路を探せ
- ただしPush/Deploy/sudo/rmはYDに必ず確認
- 完了時にVault `log.md` に追記
