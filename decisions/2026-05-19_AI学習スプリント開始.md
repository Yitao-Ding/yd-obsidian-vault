### 2. 朝ブリーフィング システム

**配信時刻**: 毎朝 7:30 JST (cron自動)
**配信形式**: 図解PDF + 音声版 (TTS mp3)
**配信先**: Google Drive 自動アップロード (iPhone Driveアプリで通勤中閲覧)

**内容構成 (毎日)**:
- 業界ニュース3本 (AI / 撮影 / 開発ツール)
- ポッドキャスト新着サマリ (英: Tim Ferriss / Lex Fridman / Acquired / My First Million / All-In、日: COTEN RADIO / Off Topic / 西野亮廣 / a scope)
- 「今日読むなら」推薦書1冊 (ビル・ゲイツ最新リスト + 古典全ジャンル統合)
- 「今日のAIコース」推薦1本 (Anthropic Academyの進捗に応じて)
- (任意) 新刊・新ツール・新コース情報

**デザイン要件**:
- 縦長PDF (iPhone最適化、16:9のスライド形式は不採用)
- フルカラー、図解必須、雑誌っぽいレイアウト
- 情報量多め、スタイリッシュでかっこいい

### 3. YD専用教科書システム

**置き場所**: `~/ObsidianVault/textbook/` (構造) + Google Drive (公開PDF)
**形式**: 縦長PDF (iPhoneで読みやすい)
**対象レベル**: 「HTMLって何?」「ターミナル怖い」レベルから始める = ゼロ前提
**長さ**: 1教材あたりじっくり読める量 (A4 数枚〜10枚程度)
**コードサンプル**: 実コードベース、解説は日本語

**構造**:
```

```

**統一フォーマット**:
1. 何が起きた? (実例)
2. 図解 (Mermaid / 画像)

6. 関連リンク

**第1号教材**: 「Claude Code 4並列で何が起きてるか」(YDの今の困りごと直撃)

### 4. 権限ポリシー (再確認)

既に2026-05-19朝に整備済みの権限設定をそのまま活用:

## 2026-05-19 朝 — 方針修正 (CCA-F 撤退 / AWS AI Practitioner 採用)

### 状況

スプリント開始当日 (2026-05-19) 朝、4資格の実態を Web で調査した結果、**Claude Certified Architect Foundations (CCA-F) は Anthropic Partner Network 加盟組織のメンバー限定**で受験可能と判明。YD は個人 (進路決定済み + 大学生) なので現状受験不可。

### 選択肢

- A. 見送り・延期: 進路確定後の所属組織が Partner Network 加盟してるか確認 → 加盟してたら受験、なければ見送り
- B. 個人事業主登録 → Partner Network 申請: 時間と手間がかかる
- C. **代替の AI 資格に振り替え**: AWS Certified AI Practitioner ($100、個人受験可、Cloud Practitioner より易) / Microsoft AI-900 ($165) など

### 選んだ理由

**選択肢 C を採用 (YD判断)**。具体的な振替先は **AWS Certified AI Practitioner (AIF-C01)**。

採用理由:
- 個人受験可能、組織制約なし
- Anthropic Academy の `12_claude_with_amazon_bedrock` コースが直接の前提教材になり、スプリント本体と相性が良い (Domain 3 = 28% に直結)
- $100 と安価、有効期限 3年 (CCA-F の 6ヶ月より長い)
- 「Google + AWS の AI 資格を揃える」状態を作れる → クラウド2社対応の差別化
- AWS Solutions Architect Associate / Machine Learning Specialty へのステップアップが明確

CCA-F は `learning/ai_certifications/claude_certified_architect/` を `pending_partner_access` 状態で温存。所属組織確定後に Partner Network 加盟有無を確認 → 加盟していれば再活性化、加盟していなければ正式撤退。
