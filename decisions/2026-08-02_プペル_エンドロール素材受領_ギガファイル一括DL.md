## 確立した手順 (ギガファイル便 一括DL)
1. ページを `curl -c cookie` で取得 (JSレンダリング不要、静的HTMLに情報あり)
2. HTML内の `download(N, 'キー')` を grep で全キー抽出 (1ページに複数ファイルあり得る)
3. `curl -b cookie -OJL "https://<host>/download.php?file=<キー>"` で直接DL
4. `download(` が無いページは URL末尾キーをそのまま download.php に渡す (個別ファイルリンク、キー33桁)
5. zipで届いた場合は Python zipfile で展開 (cp437→cp932 デコードで日本語ファイル名の文字化け回避、`._` AppleDoubleファイルは削除)
6. `xgf.nu` 短縮URLは `curl -sL` でリダイレクト解決 (HEADは405で不可、GETで301)

## ✅ うまく行ったこと
- Desktop Commander経由でMac上のcurlを直接使う方式が正解だった (クラウド経由の転送は20MB/ファイル制限で不可)
- 全ファイルを `file` コマンドで破損チェック → エラーページ混入なし
- URLキーの桁数で種類を判別できると判明: 32桁=まとめページ、33桁=個別ファイル (「1文字多い=タイポ」ではなかった)

## ❌ 詰まったこと
- `curl -OJ` は同名ファイルが既にあると失敗する (curl error 23)。1ページ内に同名 IMG_4886.mov が2つあり1件DL漏れ → 別ディレクトリで再DLして回収。次回は最初からキーごとにサブディレクトリでDLすべき
- zip展開時に `__MACOSX` / `._*` のAppleDoubleゴミが混入 → 展開後に削除が必要
