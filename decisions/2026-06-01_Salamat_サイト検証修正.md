# 2026-06-01 Salamat サイト 検証・一括修正

## 背景

YD 指示「サイトの見た目の問題やバグを並列で探して修正、さらに最高パフォーマンスでブラッシュアップ」。
本番ビルドでの実機検証 (Chrome DevTools) + 7次元の並列コード解析ワークフロー (71 エージェント、確定59件) を実施。

## 重要な発見 (検証プロセス由来)

- **dev サーバは Turbopack HMR が panic を繰り返し不安定** (`Next.js package not found`)。原因は **node_modules が npm/pnpm 混在** + `pnpm-workspace.yaml` がプレースホルダ文字列のまま不正。→ 視覚検証は**本番ビルド (`next start`)** で実施する方針に切替。本番ビルドは TypeScript 含め完全に正常。
- 「ヒーローが黒い」は dev 不安定による偽陽性で、本番では mesh gradient が正しく青系描画。
- 当初疑った「フォント subset=latin で日本語が出ない」「Typewriter の texts deps バグ」「ダークモード半適用」は、実機 + 敵対的検証で**いずれも偽陽性と確定** (記録として重要)。
