# ハタチたち5 説明会動画を 4K 60p に変更

## 状況

1080p/30p で生成した FCPXML v1〜v7 に対し、YD から「画質優先にしたい、4K 60p」の指示。元素材 (A027C007) は FX30 で 4K 59.94p 撮影済みなので、プロジェクトを 3840×2160/59.94p にし直す変更。

## 選択肢と選んだもの

**4K 化のアプローチ**:
- A. 既存の 1080p FCPXML を手で直す → build_fcpxml_4k.py を新規作成して再生成
- B. 選択肢 A を採用。スクリプトは build_fcpxml.py を fork して 1080p → 4K の差分だけ変更

**Canva スライドの 4K 化**:
- A. PNG 2 倍拡大 → ぼける
- B. Canva から PDF を書き出し → pdf2png4k.py でベクター品質の 4K PNG にラスタライズ → **B 採用**。文字の輪郭が 4K でも立った

**PIP (丸窓) の 4K 化**:
- 1080p 版は 1920×1080 の ProRes 4444 を 1 本ずつ焼いていた
- 4K では 3840×2160 で焼き直し。処理量が増えるため ffmpeg を 5 分割してセグメント並列エンコード (PIP4K_seg0〜4.mov → concat)

**Canva 内の動画素材**:
- Canva Pro の書き出しは 1080p 止まり。4K プロジェクトに乗せると FCP 側で 2 倍拡大になる
- 元動画ファイルを YD からもらえれば差し替え可。現状はそのまま

## 成果物

- `_FCP納品/ハタチたち5説明会_4K_v2.fcpxml` 生成・FCP ライブラリ (`26.9.15~.fcpbundle`) に読み込み済み
- Canva PDF (`canva/ハタチたち5説明会資料.pdf`) から `canva/png4k/` に 4K PNG 生成
- PIP 4K 素材: `pip/PIP4K_seg*.mov` (5 分割) → 結合して `pip/PIP_BR_4K.mov` / `pip/PIP_BL_4K.mov`
- build_fcpxml_4k.py が v2 以降の生成器

## うまく行ったこと

- PDF からのラスタライズはスライドが Canva 内でベクター編集されているため、4K でも文字が完全にシャープだった
- セグメント並列 (5 分割) により PIP の 4K エンコードを約 3 倍速化できた
- 1080p 版との差分は project 設定・PIP 素材パス・PNG パスの 3 か所だけなので、スクリプト fork が短時間で完了した

## 詰まったこと

- fcp_probe.sh の crop 座標が 1080p ビューアの値のままで、4K FCPXML 読み込み後のプロービングでフレームが切れた。`fcp_probe.sh` の crop 行を `(1200,234,3310,1340)→resize(823,432)` に修正した
- FCP に Export XML で書き出したファイルが最初 Desktop に保存されず (`*.fcpxmld` を別ボリュームに保存しようとしてダイアログが閉じた)。`Enter` キーを OS イベントで押下して再試行した

## 次回同じことをするときのチェックリスト

1. 4K プロジェクトの Canva スライドは PNG を直接使わず、Canva から PDF → pdf2png4k.py で 3840×2160 にラスタライズする
2. PIP は 5 分割並列で 3840×2160 ProRes 4444 を焼く。concat は ffmpeg の concat demuxer で結合
3. fcp_probe.sh の crop 座標はプロジェクト解像度に合わせて変える (4K 時は 1080p 版の 2 倍エリアを指定)
4. 元素材が 4K の場合、プロジェクトを 4K/59.94p にすれば寄りのクロップロスがない (240% 拡大を 180% に緩められる)
5. Canva 動画ページは 1080p 書き出ししか取れない (Pro 限定)。元動画ファイルがあれば差し替え
