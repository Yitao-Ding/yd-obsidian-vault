# 舞台収録の画角計算 (FX30 基準)

## 基本式

```
必要焦点距離 f = センサー幅 × 被写体までの距離 ÷ 画面に写したい幅
```

FX30 の実効センサー幅 (水平):

| モード | 実効幅 | 備考 |
|--------|--------|------|
| 4K 24/30/60p | 約 22.4mm | APS-C 23.3mm を 6K クロップ (1.04x) してオーバーサンプリング |
| 4K 120p | 約 14.4mm | 1.62x クロップ読み出し。同じレンズで大きく寄る |
| フルサイズ換算 | 約 1.6 倍 | 36 ÷ 22.4 |

4K 通常時: `f = 22.4 × D ÷ W`

## 久喜総合文化会館 大ホール (2026-08-27 調査)

公式データ: プロセニアム間口 18m / 舞台奥行 15m (舞台前〜正反 10m80、緞帳〜正反 9m) / 高さ 9m /
奥の間口 13m / 天反前 9m20・天反後 5m50 / 1,218席 (車椅子4席含む) / プロセニアム形式 / 1987年開館。

客席の奥行き寸法は公式図面 (big_hall_heimen.pdf) に記載がない。舞台図面PDFは寸法が舞台側のみ。
座席表PDFは画像PDFでテキスト抽出不可。**現地でレーザー距離計による実測が必要**。

推定値 (1,218席規模のプロセニアム多目的ホールの一般値から):
- 1階最後列 → 舞台前端 約 25〜28m
- 2階最前列 → 舞台前端 約 28〜30m
- 2階後方 → 舞台前端 約 34〜36m

## 焦点距離早見表 (FX30 4K、写したい幅別)

| カメラ〜舞台前端 | 18m 幅 (開口ぴったり) | 20m 幅 (開口+余白) | 26m 幅 (花道込み想定) |
|---|---|---|---|
| 20m | 25mm | 22mm | 17mm |
| 25m | 31mm | 28mm | 22mm |
| 30m | 37mm | 34mm | 26mm |
| 35m | 44mm | 39mm | 30mm |

舞台間口いっぱい + 左右少し余白 = 横 20m前後。これが「画面いっぱいに舞台」の絵。
結論として客席後方からなら **28〜35mm (S35)、フルサイズ換算 45〜56mm**。

## 花道を入れる場合

横ではなく **縦画角** の問題。花道は舞台から客席側へ伸びるので、フレーム下方向に手前を足す必要がある。

- 1階席の低い位置からは花道が真横から見える形になり、前列客の頭で埋まる → **高い位置が前提** (2階席 or 1階後方の一段高い位置)
- 2階最前列 (客席床から高さ 8m前後、舞台前端まで水平 28m) から舞台前端の 8m手前まで花道を入れる場合、必要垂直画角 約21度 → **24〜26mm**
- 同じ位置で舞台いっぱい = 32mm前後
- つまり **1.3倍のズーム幅** があれば花道込み → 舞台いっぱいの移行ができる

## ✅ うまく行ったこと

- ホール公式サイトの `/download/` に舞台図面・座席表・照明資料・音響資料のPDFが揃っており、間口・奥行・高さの一次情報がすぐ取れた
- センサー実効幅を「カタログのAPS-C寸法」ではなく「4K読み出し時のクロップ後」で計算したので、実写とのズレが出ない

## ❌ 詰まったこと

- 座席表PDFが画像PDFでテキスト抽出できず、列数から距離を逆算できなかった
- 舞台図面PDFにも客席寸法の記載がなく、**カメラ〜舞台の距離はホール公開資料からは確定できない**と判明。ここは推定か実測しかない
- 「間口18m」だけでレンズを決めると、左右の余白・花道・演目ごとの張り出しを見落とす

## 📋 次回同じことをするときのチェックリスト

1. ホール公式サイトの「ダウンロード」ページを最初に見る (舞台図面・座席表・照明・音響が揃っていることが多い)
2. 取れるのは舞台側の寸法だけと想定し、**カメラ〜舞台の距離は下見でレーザー距離計実測**を予定に入れる
3. FX30 の場合、センサー幅は 22.4mm で計算 (23.3mm ではない)。120p を使う予定があるなら 14.4mm で別途計算
4. 「写したい幅」は開口寸法そのものではなく、余白・花道・張り出しを足した実効幅で決める
5. 単焦点で決め打ちせず、必要焦点距離の1.3〜1.5倍のズーム幅を確保する (演出変更に対応できる)
6. 4K収録 → 1080p納品なら、引き固定1本 + 編集クロップで「寄り」を作れる。ワンオペはこれが最も事故らない
7. ムービングライトのLEDフリッカーはシャッター速度で現地確認する
