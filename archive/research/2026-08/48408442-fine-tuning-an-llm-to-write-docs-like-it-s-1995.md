# Fine-tuning an LLM to write docs like it's 1995

> https://passo.uno/fine-tuning-docs-llm/

## 要約 (日本語5行)

37ミリオンワードのマイクロソフト手書きドキュメント（1977-2005）で8ドルの OCR 清掃後、192k 訓練例を作成しました。
Llama 3.1 8B と Qwen 2.5 7B で QLoRA ファインチューニングを約50ドルで完了。
Qwen 192k ランク8は 1990 年代スタイルの技術文書（man ページ、エラーコード、Windows 2000 レジスタ）を正確に生成。
人間ライターを完全に代替できないが、スタイル一貫性を大幅向上。
ローカル小型モデルで実用的な文書補助ツール実現可能です。
